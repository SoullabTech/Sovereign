## Icon Set Coherence Rules

1. **Same background darkness** — All icons share similar dark ground
2. **Same luminosity level** — Light emanates from within at consistent intensity
3. **Same line weight** — If any lines appear, same visual weight across set
4. **Same negative space ratio** — Icon occupies ~60% of frame, ~40% breathing room
5. **Distinct silhouettes** — Each icon recognizable at 32px by shape alone

## Variation Strategy

Generate each icon **4 times**. Select based on:
- Reads clearly at 32px (squint test)
- Distinct from other 4 icons in silhouette
- Luminosity consistent with set
- Feels ancient, not designed

If no variation works, simplify the prompt further. Icons should be **irreducibly simple**.
