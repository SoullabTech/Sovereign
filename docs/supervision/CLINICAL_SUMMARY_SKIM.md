# MAIA Clinical Supervision Streaming
**"Live without confusion" — cognitive load reduction with evidence anchoring**

## What it is
A supervision dashboard that streams live transcript + live insights, with honest status (live/reconnecting/fallback). Click an insight → jump to the exact transcript moment.

## What changes
- **Freshness truth**: UI shows whether you're live, catching up, or in fallback mode
- **Evidence anchoring**: Insights link to transcript segments—verify in context, not from summary
- **AI as signal**: Patterns to notice, not diagnoses to accept

## Trust calibration

| Rely on | Verify yourself |
|---------|-----------------|
| Live-state honesty | Meaning and intent |
| Exact segment jumps | Clinical significance |
| Auditability (check the transcript) | Risk interpretation |
| Workflow support | Surrounding context |

**Rule**: If you wouldn't document it without checking the moment, don't document it because the insight said it.

## How it feels (3 vignettes)

**Rupture coaching**: Supervisee misses a shift. Click insight → land on exact moment → coach repair without searching.

**Risk signal**: Phrase flags concern. System highlights segment + invites verification—not alarm, just attention.

**Post-hoc review**: Supervisor + supervisee review together. Discussion stays anchored in observed material.
