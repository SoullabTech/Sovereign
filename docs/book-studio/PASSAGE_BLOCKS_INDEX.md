# Passage Blocks Index

Source-of-truth content layer for translating *Elemental Alchemy* into a living field. Each block is a self-contained experiential unit lifted directly from Ch5–9. No rewriting. No reflection prompts. No analysis.

A passage qualifies if it can be read without context, produces a clear internal shift, and does not require explanation before or after.

Tags name what is *felt*, not what is *understood*.
