## 0. The epistemic handoff from RUN 1 (what we are and are not allowed to carry)

| Claim | Status entering RUN 2 |
|---|---|
| Air-as-content-lens (a residual perceptual jurisdiction) | Tested; NOT SUPPORTED (GOOD) |
| Air-as-function (an operation on representations) | **Candidate; untested** |
| Function-Air *supported* by RUN 1's null | **No** |
| Function-Air *compatible* with RUN 1's null | Yes — which is exactly why it is tempting, and why it must earn its own falsifiable run rather than inherit standing from a failure |

**The register confound, and why RUN 2's structure defeats it.** RUN 1's fatal caveat: blind readers converged on the corpus's uniform authoring register (flat, third-person, observational), a property shared by all situations, which can mask content. The residual design could not hold register constant — it compared residual vs. non-residual subsets drawn from one stylistically uniform corpus. **This design holds register constant by construction:** every test is a *matched pair* (A, B) authored identically except for the one manipulated variable. Register, length, syntax, affective vocabulary are equated within the pair. Any signal that moves A→B therefore moves *despite* constant register — and the RUN 1 register artifact is additionally measured as an explicit baseline (§5). The matched-pair instrument is not an escape hatch from RUN 1; it is the correction RUN 1's own confound demanded.

## 1. Construct (the decision — mostly already sealed)

**Air (this probe) = the rendering of something intelligible *across a boundary between viewpoints or frames*.** The boundary may hold between two people, or within one person across time/context (transmission to a future self, reconciliation of two held frames). The operationalizable variable is **boundary-crossing / articulation load**: how much a situation demands that something be made intelligible across such a boundary.

This is **not a new candidate.** It is the common core of the two sealed predictions: H1 ("movement *between* viewpoints") and H2 ("the meaning-space *between* minds … what makes relationship *intelligible*"). Both are inherently *between* — a crossing. RUN 2 operationalizes that shared "between" into a manipulable dose.

**Explicitly excluded (these are the kill-condition boundaries, named before the data):**
- **The relation / bond / closeness itself → Field.** (Air is the crossing, not the connection.)
- **Cognition within a single settled frame → difficulty.** (Solving a hard problem inside one viewpoint is not boundary-crossing.)
- **Feeling / emotional intensity → Water.**
- **Intelligibility-to-self within one frame** is **out of scope** under the sealed construct (H1/H2 are *between minds/viewpoints*). Extending Air to include intra-frame sense-making is a **construct change** requiring a new sealed hypothesis — not a tweak to this run.

## 2. Apparatus (neutral — presupposes no outcome)

- **Measured quantity (primary):** the *free description of the A→B difference* by independent blind readers. Each reader sees a matched pair, is told nothing of elements / Air / the manipulation, and answers only: *"What, if anything, is different about what is going on between these two situations — one thing, several, or nothing? Name it in your own words."* Recorded verbatim, primary. **Sighted mapping after** (frozen rubric, §4) asks whether the difference is independently described as *getting-something-across / made-intelligible / translated between people or frames* — and whether it is described that way **more** for the articulation manipulation than for the control manipulations.
  - *(Open-lock O2: a secondary forced-rating battery — neutral dimensions {difficulty, emotional intensity, relationship-change, getting-something-across} — may be added; its Air-proxy wording must be blind-safe and is not yet locked. Free description is primary regardless.)*
- **Manipulation:** boundary-crossing / articulation load, graded, **content held fixed.**
- **Held constant within each pair:** Fire/Water/Earth content, authoring register, length, affective vocabulary, situation domain. (This is the register-confound defeat.)
- **Controls (the second arm — what makes it a *double* dissociation, not a confirmation device):**
  - **Difficulty-only twin:** within-frame hardness, zero boundary-crossing (§6, O1).
  - **Field-only twin:** relational change with boundary-crossing held flat (Ex 4 Version C).
  - **Register baseline:** RUN 1's artifact, carried as a control — Air must move *over and above* it.

## 3. The battery and its sequencing

| Family | Role | Design |
|---|---|---|
| **Ex 3 — tacit → explicit** (expert perceives a flaw effortlessly / must convert that perception into transmissible form) | **Positive control / instrument-validity gate.** Establishes the instrument can detect boundary-crossing load *at all* in the cleanest case. | Perception held identical; only the rendering demand added. |
| **Ex 4 — shared-meaning divergence** (two people use a word and mean the same / discover they mean different things) | **The decisive test** — the Air/Field boundary. | **A** alignment · **B** divergence-discovered, bond intact · **C** divergence-discovered, bond visibly ruptures. B−C subtraction isolates Air from Field. |
| **Ex 1 — private vs. communicated knowing** | Corroborating | Paired with emotion-only + Field-only twins (B otherwise smuggles frustration + a second person). |
| **Ex 2 — translation load** | Corroborating | Paired with the difficulty-only twin (O1), which is the load-bearing control here. |

**Sequencing rule (Kelly, 2026-06-07):** Ex 3 gates Ex 4. If Ex 3 returns no detectable difference, the instrument cannot see boundary-crossing load, and **every downstream result is uninterpretable** — a null in Ex 4 could mean no-Air *or* a dead instrument; a signal could not be trusted. Ex 3 must pass before Ex 4's result is read.

## 4. Kill-conditions (committed FIRST, before success is nameable)

Stated as pre-commitments. Each is a **first-class result**, equal in standing to a positive finding.

- **K0 — instrument void (gate).** Blind readers do not converge on any clear A→B difference for Ex 3 (the cleanest articulation manipulation). → The instrument cannot detect boundary-crossing load. Run is **void, not a verdict on Air.**
- **K1 — no effect.** Readers describe no consistent difference under the articulation manipulation. → Function-Air weakens.
- **K2 — diffusion / confound.** Readers describe the articulation-manipulation difference in the *same terms* as the difficulty-twin and/or Field-twin differences ("it got harder," "they're more upset," "they're closer/further apart"). → Air is not separable; it folds into difficulty / Water / Field.
- **K3 — Field-collapse (the decisive kill).** Ex 4's boundary-crossing description for **B** (bond intact) is **indistinguishable** from **C** (bond ruptures). → The "intelligibility" signal does not survive subtraction of the relational component → **Air folds into Field, and the boundary defended across the whole arc closes.** This is a real finding, not a failure.
- **K-method — stories not signal.** The ≥2 independent blind readers materially diverge in their free descriptions. → The method generated stories; **no Air verdict is trusted**, however clean any single description looks. (Inherited from RUN 1.)

## 5. Success condition (defined LAST, as the *survivor* of the kills)

Success is not an independent positive claim; it is **what remains after every kill-condition has failed to fire.** Function-Air gains standing for this run iff **all** hold:

1. **K0 passes** — Ex 3 establishes the instrument detects boundary-crossing load.
2. Under the articulation manipulation, independent blind readers **convergently and independently** foreground *getting-something-across / made-intelligible between frames* (the construct, §1) — **not** prompted, **not** in the program's vocabulary.
3. They do **not** describe the difficulty-only, Field-only, content-only, or register-baseline manipulations in those same terms (defeats K2 — the double dissociation: *moves when it should, flat when it shouldn't*).
4. **Ex 4 B−C survives** — the boundary-crossing signal in B is distinguishable from C (defeats K3 — Air separable from Field).

**Ceiling (inherited):** a single run returns at most **"Air-as-function candidate,"** never "Air-as-function observed." Survival warrants the full observation-field battery (jurisdiction · bias · blind-spot · flourishing) that Fire and Water were held to.

## 6. Open locks before the freeze bites

Per the freeze rule, these may be set now (pre-data) and must be set before the first rating:

- **O1 — Ex 2 difficulty-only twin (Kelly's flag, 2026-06-07).** Must be **genuinely hard within a single settled frame, with zero boundary-crossing demand**, or Ex 2's kill-condition (K2) goes soft. Concrete candidate: *a teacher alone, late, working a hard problem inside her own established framework — one that resists her — with no one to explain it to and nothing to render transmissible.* High difficulty, no crossing. **Soft-kill failure mode to avoid:** any "make it intelligible to X" smuggled into the twin reintroduces articulation and the control stops controlling. **Belt-and-suspenders:** add a *non-semantic* difficulty twin (a craftsman struggling against physical resistance — a seized joint) to bracket the residual worry that private comprehension contains *internal* articulation; under the sealed construct (§1) it does not, but the second twin removes the assumption from the result.
- **O2 — blind-safe wording of any secondary rating dimension** (§2). Free description is primary; if a forced-rating Air-proxy is added it must not name the construct circularly.
- **O3 — stopping rule (inherited):** function-Air is closed for this architecture after **two independent nulls** under distinct corpora — no infinite respecification.
