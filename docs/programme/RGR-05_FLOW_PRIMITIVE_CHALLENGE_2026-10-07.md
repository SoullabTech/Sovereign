# VI · Irreducibility criteria

Flow earns consideration for primitive standing only if all of the following survive challenge.

### FP-1 · Representational non-redundancy
There exists at least one valid task family where two systems are indistinguishable under the admitted M0 representation but distinguishable when Flow-specific information is preserved.

### FP-2 · No hidden-variable rescue
M0 may not rescue itself by adding unnamed carrier/rate/conductance variables that are Flow under another name.

### FP-3 · Predictive or discriminative value
Explicit Flow representation improves a preregistered task, counterfactual discrimination, or transfer property beyond a matched M0 construction.

### FP-4 · Cross-domain recurrence without semantic collapse
The same abstract Flow grammar works across at least two materially different domains while preserving carrier typing and source standing.

### FP-5 · Counterfactual sensitivity
When Flow changes while static relation topology is held fixed as far as the task permits, the representation tracks the Flow change.

### FP-6 · Simpler-competitor survival
A simpler dynamic graph, temporal relation, state-transition, process, or standard dynamical-systems representation is allowed to defeat primitive Flow.

# VII · Strong falsifiers

The Flow-primitive hypothesis is weakened or rejected if any of these survive challenge.

- **F05-1 COMPLETE REDUCTION** — all tested Flow distinctions are represented cleanly by the ten existing headings with no hidden Flow-like variables.
- **F05-2 VOCABULARY-ONLY GAIN** — Flow improves readability but adds no formal or predictive information.
- **F05-3 CAPACITY ARTIFACT** — any apparent advantage disappears when M0 receives matched representational capacity.
- **F05-4 DOMAIN-SPECIFICITY** — Flow works only in one hand-designed domain.
- **F05-5 ELEMENTAL CIRCULARITY** — Flow succeeds only because test labels were generated from Elemental Alchemy itself.
- **F05-6 METAPHYSICAL LAUNDERING** — phenomenological or esoteric Flow descriptions are treated as empirical evidence for physical mechanisms.
- **F05-7 STATIC SUFFICIENCY** — Relation + Trajectory + Transformation fully account for target behavior.

A clean negative result is an acceptable outcome.
