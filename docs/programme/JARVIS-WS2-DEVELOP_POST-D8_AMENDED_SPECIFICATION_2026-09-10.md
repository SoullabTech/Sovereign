## 0 · The organizing statement

> **The Work is present. The writer acts. Everything else is bookkeeping the writer never operates.**

The five classes are **internal ontology, not member vocabulary.** The writer encounters ordinary things:

```text
MEMBER EXPERIENCES              SYSTEM MAINTAINS
what I'm making                 durable creative orientation
what I'm wondering about        present inquiry
what MAIA is saying now         current MAIA turn
something we talked about       historical process context
the manuscript                  manuscript / revision state
```

⭐ **These distinctions exist so the system behaves correctly — not so the writer can operate it.** That is Phase 0 in architectural form: **complexity belongs to the system; meaningful authority and choice remain visible to the writer.**

## 2 · How each inherited falsifier is answered

**1 · One observation stays one.** An observation is a **class 4 object** carrying evidence references into class 5 loci. **Identity is the observation's own; place is its evidence.** A's ingredient, correctly placed.

**2 · No accumulation.** Class 3 has **cardinality one by definition.** Not a rule to enforce — there is no second slot.

**3 · Selective retrieval.** Class 4 is addressable **per observation**, not only through the inquiry that produced it. Retrieving one does not retrieve its siblings. **This is exactly B/M3's failure, repaired by giving the observation identity independent of its container.**

**4 · Recall ≠ re-read.** Two distinct operations over two distinct classes: **recall reads class 4; re-read reads class 5.** MAIA must name which she performed. *A reconstruction of the past is not the past.*

**5 · ⭐ Comparison without a container.** A comparison is **a class 3 turn that cites several class 4 observations at once.** Because it is turn-side, it **clears.**

> **C failed comparison because its turn held one contribution. The amendment lets one contribution reference many things.** The pile was never about references — it was about accumulation *across* turns. **Co-presence is available within a turn and cannot become a container.**

**6 · ⭐ Deferral without a backlog.** *"I'll come back to that"* creates **a class 4 entry marked by a writer act.** It is historically available, never resurfacing, retrievable by meaning.

> **Deferral and history are the same class.** No queue exists because nothing presents it. **The writer returns by asking. No new mechanism is invented.**

**7 · Orientation persists, application does not.** Class 1 durable; its application is class 3 ephemeral. **C/M4's structural split, generalized.**

**8 · Provenance atomic and two-axis.** Class 5 revisions carry content ancestry **plus a reference into class 4**, written atomically at adoption. **C could not do this because it had no class 4. The amendment restores the axis D5 §6A requires.**

**9 · Place without identity.** Navigation, evidence and staleness are spatial (class 5 addresses); developmental observations remain independently addressable (class 4). **A's strengths without A's defect.**

**10 · ⭐⭐ Nothing infers attention — and this solves C's boundary problem.**

```text
Class 3 clears WHEN THE WRITER TAKES THE NEXT TURN.
```

**That is not time, not topic detection, not a declaration, not inactivity. It is the writer's own next act** — observable, and D6-lawful. And a follow-up (*"what did you mean by 'first time'?"*) is **a turn that references the prior one**, so **recall** serves it — not persistence.

⭐ **C needed an exchange boundary and every detector was forbidden. The amendment needs no boundary at all**, because class 4 carries what C was trying to keep on the surface.

**11 · ⚠️ The writer never needs to know there are five classes.** No class name, control, tab, panel or navigation exposes the ontology. **This runs across every cell of the acceptance walk and must not become an M5** — *if a special "five classes" test is needed, the criterion has already failed.*
