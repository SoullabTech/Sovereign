## B. Recovered laws that repeat across independent sources

Repeated independently enough to treat as high-confidence lineage:

1. **Work/manuscript primacy**
   - Work occupies primary surface.
   - MAIA is contextual and adjacent.
   - assistant dominance is a falsifier.

2. **One relationship, multiple scopes**
   - Work, chapter, passage, sentence are scopes of one editorial relationship.
   - changing scope should not reset context.

3. **Relationship before intervention**
   - encounter / reflection / conversation precede recommendation when meaning is unsettled.
   - the writer can disagree; disagreement must affect what follows.

4. **Simple-first, deep-available**
   - ordinary language and one relevant next act first;
   - evidence, provenance, taxonomy, craft theory, and machinery available underneath.

5. **Independent axes**
   - change latitude;
   - amount surfaced;
   - explanatory register.
   These were explicitly designed not to collapse into one difficulty or sophistication score.

6. **Macro → meso → micro**
   - Development / Arc / Structure;
   - Themes / Continuity / Coherence / Reader;
   - Meaning / Voice / Style / Revision.
   Movement may reverse when a local problem is upstream of the sentence.

7. **Writer sophistication accommodation without writer classification**
   - MAIA translates sophisticated reasoning for a non-craft writer;
   - technical/professional language available when desired;
   - do not infer education, profession, intelligence, or skill from prose.

8. **Smallest useful intervention**
   - rewriting is not default;
   - Write normally offers 2–4 concrete possibilities;
   - larger recast exceptional;
   - Apply is the authorship boundary; Undo remains immediate.

9. **Human pacing**
   - Intimate: one meaningful thing at a time, quiet valid.
   - Guided: a few connected active questions.
   - Mapped: broad architecture visible.
   - system perception may be broad while surfaced experience stays paced.

10. **Evidence does not become meaning by itself**
    - MAIA observed / MAIA wonders / Author establishes remain distinct.
    - frozen readings are evidence objects, not writer verdicts.

## C. Conversation-derived founder decisions recovered for R7 adjudication

These were explicitly accepted in prior founder conversations but are not yet all carried in one canonical R&D artifact. They enter this recovery packet as **candidate custody**, not silent canon:

- default **Intimate + Guided**;
- persistent “Working with MAIA” across Write / Develop / Review;
- current coarse relational posture **Witness / Guide / Collaborator**;
- separate explanation continuum **Plain / Guided / Craft / Deep / Expert**;
- “MAIA carries the sophistication; the writer should not have to”;
- chapter/section orientation before analysis;
- Noticings: **Talk about this / Keep nearby / Let rest**;
- relationship-first: what works, what MAIA genuinely appreciates, what is alive/inspiring/generative/original/possible, and “genius” only when evidence truly earns it;
- “relational latitude ≠ editorial authority”;
- no automatic promotion of a section-level observation into exact revision wording;
- case-study target: move a chapter toward the strongest version possible while preserving as much of the original manuscript as possible;
- Writer's Studio should serve healers/helpers/creatives, memoirists, executives, dissertations/technical work, and professional writers without forcing all of them into one editorial vocabulary.

Founder R7 decides which of these become explicit constitutional language.

## D. Historical design conflict that caused drift

Several legitimate lines evolved in parallel:

- **Develop as relational exploration**
- **Develop as actionable editorial pass**
- **Chapter-first simple review**
- **scorecard / minimal path**
- **whole-work developmental intelligence**
- **MAIA Work conversation**

Each solved a real problem. The drift occurred when they were **composed additively** rather than ranked by the earlier experience law.

The result could satisfy each capability locally while violating the whole:

> report → report → scorecard → minimal path → navigation

instead of:

> notice → relationship → dialogue → discernment → bounded intervention.

The recovery task is therefore **composition**, not capability deletion.

## E. R1 finding

The R&D is not missing.

The primary defect is **custody and precedence**: accepted principles are distributed across programme docs, runtime laws, case-study records, and conversations, while current code becomes the easiest thing to consult.

R2 must therefore identify where implementation is valid substrate and where composition contradicts recovered law.
