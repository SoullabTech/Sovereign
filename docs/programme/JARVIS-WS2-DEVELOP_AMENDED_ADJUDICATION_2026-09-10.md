## 2 · ⭐ Amended — the M4 dormancy falsifier

```text
WITHDRAWN   "the same request must produce the same answer"
            -> too strong. Model outputs vary on identical inputs, so a
               stochastic wording difference could falsely FAIL the gate,
               and coincidentally identical prose could falsely PASS
               while silent conditioning occurred.

REQUIRED    Absent explicit writer invocation, the North Star contributes
            ZERO conditioning to the developmental read.

            same Work state · same writer request · same model/routing
              North Star ABSENT     vs.     North Star PRESENT, NOT INVOKED
              -> DIFFERENCE IN INPUT AVAILABLE TO COGNITION = ZERO
```

⭐ **Input-path invariance is the architectural law.** Deterministic replay proving identical output is a welcome bonus, never the gate.

**Note for whoever registers this as an implementation test**: this is an assertion over **assembled context**, not over generated text — the same idiom the codebase already uses for tracing what enters a prompt. It is checkable by inspection and immune to model stochasticity.
