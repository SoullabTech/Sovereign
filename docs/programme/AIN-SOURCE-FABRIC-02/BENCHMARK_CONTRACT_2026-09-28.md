# AIN-SOURCE-FABRIC-02 — Sovereign Retrieval Benchmark Contract

**Date:** 28 September 2026
**Class:** benchmark harness only · synthetic queries + existing non-member corpus
**Parent:** AIN-SOURCE-FABRIC-01

## Purpose

Test which retrieval architecture best feeds MAIA's relational intelligence without changing MAIA runtime behavior.

The benchmark must evaluate two complementary retrieval modes in parallel.

### Analytic lane

Optimized for:
- permission;
- exact source identity;
- lexical precision;
- provenance;
- temporal validity;
- supersession;
- claim-support boundaries;
- exact returnability.

### Associative lane

Optimized for:
- semantic similarity;
- graph bridges;
- distant conceptual relations;
- metaphorical resonance;
- community context;
- cross-domain analogies;
- counterintuitive but relevant sources.

The labels **analytic** and **associative** are architectural roles. The founder's corpus-callosum metaphor is used to describe coordination between them; it is not a literal claim that the software has biological hemispheres.

## Corpus-callosum coordination law

The lanes run in parallel and remain distinguishable.

The coordination layer may:
- exchange candidate identities;
- expose why each lane nominated a source;
- identify overlap and divergence;
- preserve contradiction;
- request a bounded second look from the other lane;
- merge provenance without merging epistemic standing.

It may not:
- let associative relevance bypass permission;
- let lexical exactness erase semantic bridges;
- let graph centrality become truth;
- average contradictions into false agreement;
- convert retrieval novelty into factual certainty.

The coordination target is **complementarity without collapse**.

## Aether / fifth-element synthesis

Aether is not another retriever.

Aether names the later creative synthesis in which the admitted field can produce a relation not explicitly stated in any one source while remaining grounded in the source constellation.

A candidate Aether synthesis is acceptable only when:
- every materially supporting source remains identifiable;
- no prohibited claim type is introduced;
- contradiction remains visible where material;
- removing a crucial source changes or weakens the synthesis;
- the synthesis is presented as provisional relation, not discovered essence;
- member correction can revoke it.

In short:

> analysis constrains imagination;
> imagination expands analysis;
> synthesis remains answerable to provenance.

## Benchmark families

The harness should include:
1. exact lexical lookup;
2. semantic paraphrase;
3. cross-source synthesis;
4. graph-bridge discovery;
5. temporal supersession;
6. contradiction / counterevidence;
7. metaphorical or analogical resonance;
8. broad community / whole-corpus inquiry;
9. negative control;
10. permission control;
11. source-diversity / redundancy control;
12. source-ablation sensitivity.

No member data is required for these tests.

## Evidence labels

Each query fixture may label sources as:
- **must_retrieve**
- **helpful**
- **counterevidence**
- **bridge**
- **redundant**
- **stale_or_superseded**
- **forbidden**
- **irrelevant**

These labels evaluate Crystal Center readiness rather than simple document recall.

## Primary metrics

- must-source recall;
- precision;
- exact-term success;
- semantic discovery;
- bridge precision;
- counterevidence recall;
- temporal correctness;
- permission integrity;
- provenance integrity;
- source diversity;
- redundancy rate;
- context efficiency;
- latency;
- ablation sensitivity.

## Callosal metrics

The benchmark adds four coordination-specific measures.

**Analytic unique yield** — useful evidence found only by the analytic lane.

**Associative unique yield** — useful evidence found only by the associative lane.

**Complementarity gain** — quality improvement of the coordinated field over the better single lane.

**Grounded novelty** — whether a later synthesis can form a useful new relation that depends on multiple admitted sources without inventing unsupported content.

A system that simply duplicates the same results in both lanes has low callosal value.

A system that finds wild associations without provenance has low callosal integrity.

## Failure conditions

A run fails regardless of average score if:
- a forbidden source enters the field;
- source identity is fabricated;
- a superseded claim is presented as current;
- a symbolic source is upgraded into causation/prediction;
- a material contradiction is silently discarded;
- a graph-expanded source appears without an explainable path;
- a source-use receipt cannot be produced.

## No-build boundary

This benchmark act changes no MAIA runtime, Obsidian index, embedding model, graph store, production corpus, or member retrieval path.

It builds the proving ground only.
