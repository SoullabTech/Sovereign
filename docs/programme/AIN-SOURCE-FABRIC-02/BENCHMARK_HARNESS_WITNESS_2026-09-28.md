**Date:** 28 September 2026

## Standing

The first benchmark harness now models three distinct acts:

1. **analytic retrieval lane**
2. **associative retrieval lane**
3. **corpus-callosum coordination**

Aether / fifth-element synthesis remains downstream. It is not implemented here as another retrieval score.

## Coordination witness

The synthetic bilateral test field included:

- exact canonical evidence found by the analytic lane;
- current counterevidence found by the analytic lane;
- one jewel discovered by both lanes for different reasons;
- a distant conceptual / graph bridge found only by the associative lane;
- a second semantically relevant source found only by the associative lane.

The coordinator preserved all lane identities and retrieval reasons.

## Callosal measures

The harness computes:

- analytic useful yield;
- associative useful yield;
- coordinated useful yield;
- analytic unique yield;
- associative unique yield;
- shared useful evidence;
- complementarity gain;
- forbidden leakage;
- counterevidence presence;
- bridge presence.

A system with two lanes that return the same evidence receives little complementarity credit.

A system with novel associative retrieval that violates permission receives a hard integrity failure.

## Retrieval scoring witness

The benchmark scorer separately measures:

- must-source recall;
- helpful recall;
- counterevidence recall;
- bridge recall;
- forbidden leakage;
- irrelevant rate;
- stale-current rate;
- source-class diversity;
- redundancy rate;
- useful evidence per thousand context tokens.

## Synthetic acceptance cells

**6 / 6 PASS**

- shared jewel preserves analytic + associative reasons;
- coordinated field gains useful unique evidence from both lanes;
- forbidden graph/associative expansion remains visible as leakage;
- diverse grounded constellation scores strongly;
- redundant evidence is penalized despite apparent relevance;
- permission leakage is a hard failure.

## Right-hemisphere / associative interpretation

The benchmark intentionally rewards distant but grounded association.

It does not reward free association detached from source identity.

The target is:

> **wide association under disciplined provenance**

rather than:

> narrow exactness alone

or:

> unconstrained associative fluency.
