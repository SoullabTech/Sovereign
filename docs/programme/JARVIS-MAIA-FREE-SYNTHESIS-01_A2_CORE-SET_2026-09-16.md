## Sufficiency claim — deliberately narrow

The Core Set is sufficient to prevent A3/A4 from designing against one undifferentiated notion of "continuity."

Any candidate architecture must already distinguish:
1. absent context from present-but-unintegrated context;
2. useful synthesis from authorship laundering;
3. relational initiative from forced continuation;
4. coherent reconstruction from correct source standing;
5. local quality from whole-arc organization;
6. one good session from independent evidence.

It is **not** sufficient to estimate prevalence, population performance, effect size, or general member preference.
