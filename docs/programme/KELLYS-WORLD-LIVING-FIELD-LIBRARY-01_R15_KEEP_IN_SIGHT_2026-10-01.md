# KELLY'S WORLD — LIVING FIELD LIBRARY 01 · R15 Keep in Sight · 2026-10-01

## Purpose

Let Kelly explicitly keep selected fields, unfinished-thread recovery candidates, and governed Work Units visible without changing their programme, epistemic, or authority standing.

## Law

> **Attention preference is not authority.**

A pin means only: **Kelly wants this kept in sight.**

It does not:
- reactivate a dormant programme;
- change a Work Unit lifecycle;
- authorize work;
- elevate a recovery candidate into importance;
- alter source custody;
- create shared/community priority.

## Persistence boundary

Pins are local Kelly's World presentation memory under:

`kellys-world:field-library:pins:v1`

Only stable references are persisted:
- kind;
- key;
- display label.

No source text, programme standing, Work Unit state, synthesis, or evidence snapshot is copied into the pin store.

Every pinned item resolves fresh against current Library / governed-work facts on render.

## Supported pins

R15 supports:
- **durable fields** — keyed by conceptual group + field title;
- **recovery candidates** — keyed by programme lineage;
- **governed Work Units** — keyed by canonical Work Unit id.

If a pinned target can no longer be resolved, Kelly's World shows the unresolved pin explicitly and substitutes nothing.

Unpinning is immediate and removes only the attention preference.

## Verification

R13–R15 focused suite: **11/11 PASS**.

It proves:
- local persistence survives reload;
- duplicate pin state is idempotent;
- unpin is lossless to source custody;
- unresolved pins remain unresolved;

- the pin handler calls no Work Unit, model, create, authorize, or execution path.

No merge or deploy is authorized.
