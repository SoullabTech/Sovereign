# HOUSE-CABIN-CONTEXT-SPINE-01 · H4.0 — Cabin Arrival Experience Contract

## Archaeology

H3.10 established the mounted experience bridge. The repository already establishes the House as the orientation layer: arrival is a human experience, not a capability inventory.

H4.0 therefore does not add another context transport layer.

It defines the first consumer of the mounted field.

## Core ruling

Cabin Arrival is:

    orientation → recognition → choice

not:

    context dump → ranking → recommendation

The mounted field is present to support continuity, not to become a dashboard.

> Here is everything the system knows about you.
