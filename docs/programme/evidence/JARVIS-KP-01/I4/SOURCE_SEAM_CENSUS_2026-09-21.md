boundary by refusing a one-endpoint request as malformed.

- operation: `HYPOTHESIZE`;

## Persistence ruling for I4

I4 does **not** call the canonical I3 epistemic persistence writer.

The purpose of this act is integration shadow: measure how I2 classifies a real
proposal path without creating durable semantic-join custody.

Only structural telemetry is persisted:

- proposal count;
- evaluated count;
- admitted-standing counts;
- refusal-code counts;
- representation-closure boolean;
- error count.

The telemetry lives in a separate child research table whose parent is the
ordinary relational-field shadow row.

No member id, evidence id, join id, proposition text, evidence text, response
text or semantic payload is present in the I4 telemetry schema.
