## 1. The question this run answers

*Can a writer, in their own words, get MAIA to help with their work — through an edit, navigation and
learning — and can MAIA answer how best to work in the Studio?* The result decides which Studio surfaces
fold into conversation first. Nothing is designed ahead of it.

## 2. Preconditions (each recorded before the first question)

1. Production `GIT_COMMIT` read and equal to the deployed canonical SHA; `/api/health` fresh.
2. Work: ELEMENTAL_ALCHEMY (manuscript `55742458-…`, Living Work `2211661a-…`).
3. MAIA relationship for this Work exists (`158bb480-…`, begun 2026-11-01) and is the one selected.
4. Session posture: Ordinary. If the Studio asks, answer Ordinary; record that it asked and where.
5. Passage for the passage-level questions: *"Integration is a universal human psychological need…"*
   in "Integrating the Elements" (no prior editorial conversation; verify the room opens without the
   older-conversation notice — if it shows, record it and continue).

## 3. Rules of the run

- **Own words only.** Questions are typed exactly as written in §4. No Studio vocabulary is added
  ("lens", "Focus", "Craftsman's Table", "proposal") unless the question already contains it.
- **One question per turn**, in a fresh conversation for each verb, so earlier answers don't steer later
  ones.
- **Nothing is applied, saved, undone or typed into the manuscript.** If MAIA offers wording, it is
  recorded, not used. ⛔ Apply, Save my version and Undo are not pressed.
- **Read permission** (MAIA asking to read named sections): grant it once if asked, and record that it
  asked, which sections, and whether the answer then used them.
- **Verbatim capture**: the full question, the entry point, MAIA's full reply, every control she
  surfaced, and time to first visible reply. Screenshots for each reply.
- **No retries to get a better answer.** A second phrasing is allowed only where §4 lists it, and both
  are recorded.

## 5. How each answer is classified

Each reply gets one class per row. Classes describe capability, not quality of prose.

| Class | Meaning |
|---|---|
| **DOES** | MAIA performs the act inside the conversation (offers wording; names and links/takes the writer to other places; explains the craft using these words; explains the Studio method concretely). |
| **POINTS** | MAIA does not perform it but tells the writer accurately which control to use and where. |
| **DEFLECTS** | MAIA stays on the passage or asks a clarifying question instead, without performing or pointing. |
| **WRONG** | MAIA describes a control, place or behaviour that does not exist, or claims to have done something she did not. |
| **REFUSED / FAILED** | A gate, error, silent no-op or missing input. Record the exact message (or its absence). |

Per-verb pass bar for "the field holds this verb" (all must hold):

- **Edit (Q1)**: DOES at the primary entry; wording stays a proposal (nothing applied); voice-preservation
  claim is visible or stated.
- **Navigation (Q2)**: DOES — names at least two concrete other places (section/heading or quotation)
  that exist in the manuscript, and offers a way to go there. POINTS is a partial.
- **Learning (Q3)**: DOES — explains with reference to these exact words; teaching describes technique,
  ⛔ not an external quality standard (WRITERS-STUDIO-FACETS-01 condition).
- **Studio method (Q4, Q5)**: DOES or accurate POINTS. ⛔ WRONG is the most serious result in this row:
  MAIA inventing Studio features would mislead every writer who asks.

Sovereignty checks recorded for every reply: no automatic change to the manuscript · no claim of having
read text she was not authorized to read · writer's authorship preserved · any gate she meets is
explained in words, not left as a silent stop.

## 6. Output

A result record, `WRITERS-STUDIO-SEMANTIC-FIELD-01_MAIA_FIELD_WITNESS_RESULT_<date>.md`, with: the
preconditions as read; for each question and entry point the verbatim reply, controls surfaced, class,
time; per-verb pass/partial/fail; sovereignty checks; and a short list of *surfaces that could fold into
conversation* and *capabilities MAIA lacks*, each tied to a specific reply. ⛔ No design or build
proposal is made inside the result; those go to the founder as separate questions.

## 7. Stop conditions

Stop and record, rather than continue, if: the deployed SHA does not match; the relationship or posture
cannot be established in the ordinary way; any reply changes the manuscript or claims to have; MAIA
reads text without the permission step where one is required; or an error repeats on two consecutive
questions.
