# RELATIONAL-GEOMETRY-INTEGRATION-01 — R18 / H4a Result

**Status:** EXECUTED · PROOF-OF-CONCEPT PASS  
**Date:** 2026-09-16  
**Authority:** offline research only

## Question

Can a 3+ node configuration carry information that is not recoverable from the complete set of pairwise relations among those same nodes?

## Design

Six frozen fixtures were used. Four contained explicit group-level effects; two were controls. Two collision pairs were deliberately constructed so each pair had an identical pairwise graph but a different whole-group outcome.
## Result

Pairwise collision test:
- distinct higher-order cases: **4**
- distinguishable from pairwise signatures alone: **0/4**
- distinguishable with higher-order configuration: **4/4**

Acquisition:
- total runs: **12**
- correct: **12/12**
- true-positive configurations: **8/8**
- true negatives: **4/4**
- false positives: **0**

The admitted higher-order predicates were `COLLECTIVE_CONSTRAINT` and `COLLECTIVE_SYNERGY`; both required exact group-level member-language evidence naming the 3+ member effect.
## Interpretation

H4a supports the narrow proposition that a relation field may need first-class higher-order configuration objects. Pairwise completeness does not imply configuration completeness.

This does **not** justify a generic hypergraph everywhere. A higher-order object is admissible only when evidence supports a group-level effect that cannot be reduced to one constituent pair.

Constitutional law:

> **A configuration may carry information not present in any single edge, but configuration standing must descend to evidence of the group as a group.**
