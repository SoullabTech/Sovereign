⭐ Fixed before the returns land, for the same reason the P1-03 gate was: **a gate written after
seeing the artifact is a gate shaped by it.**

---

## 1 · ⭐⭐ The governing condition

> **A graph must not increase the claim strength of any source row merely by visual compression.**

```text
✅ SAFE                                  ⛔ NOT SAFE
DECIDES                                  DECISION AUTHORITY: NONE
AUTHORITY: NONE LOCATED
SCOPE OF GOVERNANCE: UNKNOWN
```

The forbidden form **fuses two axes into a stronger negative than the record supports.** Three
separately-evidenced facts become one unevidenced verdict, and the compression is invisible to a
reader who never sees the row. ⭐ *Compression is where `INF-7` will actually be broken, if it
is — not in a sentence saying "unauthorized", but in a label that means it.*

---

## 2 · ⭐ Nodes and edges have OPPOSITE omission rules

This is the distinction most easily lost, because both involve the word *unknown*:

```text
UNKNOWN EDGE   →  ⛔ NOT DRAWN, and preserved in "Edges NOT drawn"
                  (drawing it would assert a relation the evidence does not support)

UNKNOWN NODE   →  ⭐ DRAWN, labelled UNKNOWN
                  (omitting it would assert a negative the evidence does not support)
```

⛔ **`PARTICIPATION: UNKNOWN` must never become an omitted node** where omission reads as *"does
not participate."* ⚠️ This binds hardest on the empty `PARTICIPATES` rung across A/B/C, which is a
**vocabulary-evidence gap** and not a finding.

---

## 3 · The four acceptance checks

Run on every map, after freezing, before P1-05 opens.

```text
1   every DRAWN EDGE carries an explicit SYN standing
2   every OMITTED / UNKNOWN EDGE is preserved in "Edges NOT drawn"
3   node labels preserve NONE LOCATED / UNKNOWN / GOVERNED SCOPE exactly
4   VISUAL COMPRESSION HAS NOT STRENGTHENED any underlying claim
```

⭐ **Check 4 is the only one that cannot be run by pattern-matching.** It requires reading labels
against their source rows and asking whether the label says more than the row did. Checks 1–3 are
mechanical; check 4 is the reason the gate exists.

## 6 · ⭐⭐ Check 4's scope — TEXTUAL **and** VISUAL compression (founder, 2026-09-14)

⛔ Check 4 is **not** a node-text check. A map can satisfy checks 1–3 perfectly — every edge
`SYN`-tagged, every unknown handled, every scope label exact — and still strengthen a claim
through **structure**.

Check 4 therefore evaluates **all** of:

```text
node text          the label against its source row
HEADINGS           ⛔ "Unauthorized Decision Paths"
LEGENDS            ⛔ a key that renders NONE LOCATED as a failure state
GROUPING LABELS    ⛔ DECIDES + NONE LOCATED collected under "Authority Failures"
VISUAL PROXIMITY   ⛔ arrangement that implies a relation no edge asserts
ORDERING           ⛔ a sequence that implies causation or severity
```

⭐ **Every one of those examples can be true of each individual node and false of the map.** The
nodes say *effect observed, authorization not located*; the region label says *failure*; and a
reader takes the region label away with them.

### The operative question, applied at every altitude

> **Does the rendered artifact say more than its source rows said?**

⛔ If a heading, legend, grouping or arrangement carries a claim no row carries, **check 4 FAILS**
— even where every node is individually correct. ⭐ *Especially then, because that is the failure
mode the other three checks are blind to.*
