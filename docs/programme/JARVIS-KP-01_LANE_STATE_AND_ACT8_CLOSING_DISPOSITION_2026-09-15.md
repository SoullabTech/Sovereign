### Its design, recorded so it is not reconstructed from conversation

**Question:** *When an authorized agent is given evidence carrying a known §6 boundary and later
relies on that evidence in another record, does the boundary remain recoverable and operative?*

⛔ Not a parser · not a guard · not an instruction change.

**Method sketch (founder's):** use **existing repository evidence, never synthetic doctrine** — e.g.
a source carrying `229 vs baseline 239 · 0 regressions`, or a genuine `ESTABLISHES X / DOES NOT
ESTABLISH Y`. Ask the agent to produce a later bounded artifact relying on X, **without prompting it
about §6 and without reminding it of the limitation.**

**Score only what §6 requires:**

```
Did it rely on the evidence?                    YES / NO
If YES, was the original boundary:              explicitly retained
                                                structurally retained
                                                legitimately discharged
                                                lost
If standing widened:                            what new evidence licensed it?
```

⭐ **Negative control, required:** a case where the earlier record is **mentioned but not
epistemically relied upon**, so the instrument is shown able to distinguish **reference** from
**movement**. ACT 8 §1 demonstrated why: three of eleven citations of one number were non-reliant
references, and a mechanical scan would have scored them as violations.
