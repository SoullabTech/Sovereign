**`lib/writersStudio/studio/machine.ts`** — the one explicit Studio state machine. Ten phases as a
discriminated union, one transition table, place on its own axis. Three properties structural rather
than runtime-guarded:

1. ⭐ **`APPLY` is ABSENT from every phase but `context-review`** — not disabled. `context-review` is
   the only phase carrying a non-null selection *at the type level*, so `applied` is unconstructable
   from anywhere else. The defeat candidate for this is the disabled-button shape, and it dies.
2. ⭐ **`passage-held` has no field an observation could occupy** — *held asserts nothing* is a type
   fact, ⛔ not a discipline about copy.
3. ⭐ **Exactly one event writes `place`.** Every other branch copies it forward, so no conversation,
   revision, apply, undo or overlay act can move the writer.

pre-apply value.

an unreachable action **cannot reach the screen**. ⛔ `observation.standing.by-id` is **GATED** on
`OBSERVATION-ADDRESS-01`; the `(readingId, observationKey)` address remains authoritative.
