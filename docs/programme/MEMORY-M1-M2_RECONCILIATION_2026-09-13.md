## 1 · ⭐⭐ M1 — the divergence substantially dissolves: **they are different objects**

Census finding D5 set two things against each other as if they answered one question. **They do not.**

| | `TEMPORAL_MEMORY_DIRECTION` Decision 2 | `interpretiveLedger.ts` |
| --- | --- | --- |
| **Object** | an **assertion** with a validity interval — *"I live in New Orleans", valid_from, valid_to* | a **hypothesis promoted to a durable entry**, with `routing_influence_weight` |
| **Lifecycle** | bitemporal validity; episode time vs assertion time | decay of influence weight; **surfacing status transitions** (`declined → held_lightly`) |
| **Member acts** | ratifies a succession transition | **contest · clarify · confirm · clear_influence** |
| **What is mutated** | ⛔ nothing on the predecessor — `superseded_by` and `valid_to` **derived** | `status = 'superseded'` on the parent, when lineage is provided |

> ⭐ **The ledger has no validity interval to close.** Decision 2's prohibition is specific:
> *"any implementation that closes an assertion by mutating a `valid_to` column on the predecessor has
> re-opened the escape hatch."* **The ledger mutates a surfacing `status` on a hypothesis. It is not
> the addressed case.**

**D5 was a real observation of two real things, compared across a category boundary.** ⛔ It is not a
contradiction between two answers; it is one design for assertions and one implementation for
hypotheses.

### 1.2 · The irreducible choice, with consequences

**M1 is genuinely open in exactly one place:** does Decision 2's *principle* — **never rewrite the
predecessor; succession is carried by the successor** — extend beyond assertions to **any
lineage-bearing memory object**?

| | Reading | Consequence |
| --- | --- | --- |
| **M1-a** | **Object-scoped.** Decision 2 governs assertions only. Hypothesis ledgers may mutate a surfacing status. | The ledger is correct as built. ⛔ Two supersession semantics coexist permanently, and each new memory object must be classified before it can be built. |
| **M1-b** | **Principle-scoped.** Never-rewrite-the-predecessor is a general memory law. | One semantics everywhere. ⛔ The ledger becomes non-conforming — **a finding about existing code this pass is not authorized to act on** — and the cost falls on an object whose member acts (*contest · clear_influence*) may genuinely need a mutable current status. |

⭐ **For SPM specifically:** its claims are **assertions about a person**, carrying `ORIGIN · BASIS ·
STATUS` — structurally the Direction's object, not the ledger's. **Under either reading, SPM's
`superseded` question is answered by Decision 2's model** — ⛔ **but as *design*, not as binding
authority**, because the Direction is unauthorized. **SPM may adopt it; SPM may not cite it as
ruled.**

## 2 · M2 — `stale`: the answer is clearer, and it has indirect canonical support

**Direction Decision 3:** *staleness is detected and surfaced; **status change requires the member***.
*"The system may detect temporal uncertainty. It may not manufacture the correction."*
**detect → ask → record**, inverting the source tutorial's *detect → propose → repair*.

⭐ **Unlike M1, this is not resting on an unauthorized document alone.** It is a specialization of
**ratified canon**:

- `RIGHT_TO_REMAIN_UNPOSSESSED` — the system **"must refuse to guess"**; non-pursuit; *care must not
  become surveillance*; inference declined even when evidence exists;
- `DISCIPLINED_NON_COLLAPSE` — *reflection, not interpretation*; the questions **"keep the human
  sovereign over their own material"**;
- `LONGITUDINAL_MEMORY_CATEGORY_GRADIENT` — memory the system constructs **ahead of** the member is
  not permissible.

> **A system-set `stale` is the system deciding a member's assertion has stopped being true, on a
> clock, without asking. Three ratified canons independently forbid that shape.**

**Answer, as far as this pass may state it:** `stale` is **not a legitimate system-set status.**
Temporal uncertainty remains **detect → ask → record**. ⛔ A *detected-uncertainty signal* — visible,
non-authoritative, prompting a question — is a different object and is **not** what M2 asked about.

⚠️ **Authority note:** the *conclusion* is supported by ratified canon; the *mechanism* (Decision 3's
exact shape) remains Cat 1. **The prohibition is canonically grounded; the replacement design is
not.**
