## Three possible responses, and frozen C admits only one

```text
1  RECALL    retrieve what MAIA actually said earlier
             -> not available. C stores no contribution.
2  RE-READ   read the current manuscript and produce a fresh observation
             -> the only option C has.
3  RESTORE   bring the prior exchange back onto the surface
             -> recreates precisely what C exists to prevent.
```

## Pressure 1 · ⛔ Historical continuity — **C satisfies half of D6 by making the other half impossible**

```text
D6   the past remains reachable    ✗  no history exists to reach
D6   the present remains free      ✓  structurally guaranteed
```

⭐ **Each candidate secures one half of D6 well:**

```text
A   present free STRUCTURALLY (nothing can move) · past reachable LOCALLY only
B   past reachable BROADLY · present freedom ENDANGERED (container reopens)
C   present free STRUCTURALLY · past NOT REACHABLE AT ALL
```

## Pressure 2 · ⭐ Freshness — a real strength, with a cost that lands on Develop specifically

**No stored observation can masquerade as current.** The prose changed; MAIA looks again. **Excellent for present truth**, and it dissolves the staleness problem A had to show and B had to assert.

⛔ **But the cost is precise.** C retains the Work's history — the revision store is append-only and persists — so C *can* compare versions of the text. What C loses is **the history of its own reading.**

```text
C CAN answer    "how has this text changed?"        (the Work remembers)
C CANNOT answer "what did we think about it before?" (MAIA does not)
```

⚠️ **Development is change over time, and one of the seven lenses is literally *how is it developing?*** C can observe **states** and textual difference; it cannot observe **the relationship's development** — what was noticed, what the writer was working on, what they responded to.

## Pressure 3 · ⭐⭐ Recovery by description — **fresh inference impersonating memory**

```text
B   description -> retrieves the historical observation
C   description -> triggers a fresh read
```

**Same experience. Different epistemic act.**

> ### A reconstruction of the past is not the past.

⭐ **This is the easiest failure in the entire walk to mistake for success.** The writer asks for the past and receives an intelligent, relevant answer. **A good current answer is not evidence that continuity survived.**

⛔ **And there is a truthfulness obligation C cannot meet structurally.** If MAIA answers *"the transition still appears around 9"*, she has answered **a different question than the one asked** while the writer believes they received a memory. **C must disclose that it is re-reading rather than remembering** — and that disclosure is an *assertion*, not a structural fact. **C inherits B's pattern here**: the protection must be enforced, not relied upon.

## Pressure 4 · ⛔⛔ The rationale problem — **C is incompatible with the ratified provenance model**

The revision persists. The content ancestry persists — `proposal_adopted`, `writer_modified_proposal` are all recordable. **What disappears is the developmental exchange.**

```text
"Why did we change this?"
   -> C knows MAIA helped seed the edit
   -> C does not know what the writer was responding to
```

⭐⭐ **D5 §6A ruled provenance as two axes.** C can populate one and **permanently cannot populate the other:**

```text
CONTENT ANCESTRY   writer_direct · proposal_adopted · proposal_modified
                   ✓ RECORDABLE in C

PROCESS CONTEXT    live question · thread id · observation id ·
                   conversation lineage
                   ✗ STRUCTURALLY EMPTY IN C — the architecture destroys
                     its contents by design
```

⛔ **This is not a gap C could fill later. The ruled model requires a process-context axis whose contents C is built to discard.** D5 also ruled *every new revision states what is known about how it came to exist* — in C, what is known is permanently half.
