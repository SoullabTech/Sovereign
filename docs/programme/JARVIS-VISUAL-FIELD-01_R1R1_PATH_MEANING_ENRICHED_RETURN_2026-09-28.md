## New experiential contract

### 1. PATH becomes JOURNEY in member-facing language

“Path” remains the internal semantic object.

The visible surface becomes **Journey** because it describes lived movement rather than a technical route.

### 2. Journey has three movements

#### WHERE THIS BEGAN
Preserve the person's original words.

#### WHAT CAME INTO VIEW
Show the movement as one human sentence, derived only from the authored transitions already traversed.

Example:

> The journey moved from **change and feeling** toward **relationship continuing in a new form**.

This is orientation, not interpretation.

#### WHERE TO GO FROM HERE
Offer spatially meaningful choices:

- **Stay here** — return to the current field and linger.
- **Return to Water** — return one containing level with the travelled region still visible.
- **Widen the view** — return toward the whole field with the journey trace preserved.
- **Follow another opening** — return to Water and let another nearby region become available.

No “Next step.” No recommendation ranking.

### 3. The journey remains visual

The current vertical audit trail should become secondary.

Primary representation:

```
BEGINNING
    ·
    ↓
  WATER
    ·
    ↓
CONTINUING RELATION
        ◉ here
```

The trace should feel like a remembered route through a landscape.

### 4. Enriched Return is visible in WORLD

When returning to Water:
- Continuing Relation remains gently marked;
- the travelled connection remains visible;
- Grief, Surrender, and Dissolution remain available;
- the person can see both where they went and what other directions still exist.

When widening to the whole:
- Water carries the subtle visited trace;
- the journey remains inspectable without dominating the field.

### 5. Reflection is optional

A quiet invitation may appear:

> **What feels different from where the journey began?**

A response is optional.

The field remains usable through spatial movement alone.
