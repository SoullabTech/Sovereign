```text

```

re-verified against the present tree**, never as a settled finding. Its citation must carry its
status. The correct citation shape is:

> pending) recorded *…*; **re-read at `1a555430`:** *…*

## 5 · One thing deliberately not done

⛔ **The predecessor's own files were not edited.**

A one-line status banner on `MAIA_WHOLE_ORGANISM_MAP/00_RANKED_MAP.md` pointing at this ruling
would make the standing legible to a reader who arrives at that file first — and that file
currently still reads `Status: CENSUS IN PROGRESS`.

It was not added, for two reasons:

1. The founder's authorization for this act lists **`cross-lane absorption ⛔`**. Editing another
   lane's record is the clearest instance of it, and a ruling that opens by breaching its own
   boundary is not a ruling.
2. That file carries its own rule: *"This file is not edited past this header until the Phase-1
   census acceptance gate … passes on all thirteen pages."*

⚠️ **The legibility gap is therefore real and is named rather than closed.** A reader arriving at
`00_RANKED_MAP.md` without this ruling in hand will read a live census. That is documentation drift
of exactly the kind P1-05 exists to classify — and this lane now knows about one instance before it
starts. Routed as **D-P1-05**.
