# WRITERS-STUDIO-CONVERGENCE-01 · H1-R5 — No-Manuscript Orientation Census

## Gate question

When a member explicitly chooses a Work in House but that Work has no declared
manuscript, does Writer's Studio preserve the Work identity without inventing a
manuscript or silently entering Write?

## Governing ruling

D-03:

- exactly one legitimate manuscript → direct Write;
- zero manuscripts → Studio Home;
- more than one manuscript → Studio Home and member choice;
- no silent manuscript inference.

## Acceptance

1. House exposes the member's Work.
2. Clicking it carries the Work identity.
3. Studio does not add an m= parameter.
4. Studio Home visibly names the selected Work.
5. The Studio offers a lawful next action (for example Start writing) rather
   than pretending a manuscript already exists.
6. No manuscript is created merely by crossing the threshold.

## Behavioral witness

A real Chromium walk seeded a member-authored Living Work with zero declared
manuscripts.

Observed:
- House carried the explicit Work identity.
- Studio remained at the Work-oriented Home state.
- No m= parameter appeared.
- The Work title was visible.
- Start writing was offered as the lawful next action.
- mode=write was not entered.
- Database count of member manuscripts remained exactly zero.

**H1-R5 disposition:** IMPLEMENTATION NOT REQUIRED · BEHAVIORAL EVIDENCE
COMPLETE.

**Stop boundary:** no automatic manuscript creation, no inferred identity, no
persistence from navigation.
