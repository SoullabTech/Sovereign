# Writer’s Studio — KDP Source Fidelity R1

## Founder ruling
A finished manuscript that enters Writer’s Studio already professionally structured is authoritative source material. Writer’s Studio may reflow it responsively, but must not collapse authored paragraphs, absorb folios into prose, merge epigraphs into body text, or visually truncate authored headings.

## Repair boundary
This lane changes presentation projection only. It does not migrate, normalize, or rewrite Source/Draft manuscript content. Explicit source structure remains primary; recovery heuristics are fallback behavior for flattened text.

## R1 changes
- recognize a finished-manuscript paragraph-line profile when complete authored paragraphs arrive on successive source lines without blank separators
- retain standalone folios/subheads as structural blocks even when the body does not satisfy the PDF hard-wrap profile
- preserve exact source text across the block projection
- allow manuscript-rail titles to wrap instead of appearing clipped

## Acceptance witness
Chapter 10 is the founder witness. Pass requires visible paragraph rhythm, quiet standalone folios, separated epigraph/body treatment where represented in source, complete rail titles, and exact manuscript text preservation. No source mutation is permitted merely by opening Write.

## Non-goals
This is not a KDP export engine and does not claim pixel-identical pagination. Responsive reflow is allowed. Authored semantic structure is not.
