## Repair

The rejected experience exposed Soullab's internal seven-movement architecture as seven member-operated tabs. The founder identified the resulting problem accurately: the fields did not feel like a Future Self journey and there was no threshold preparing the person for an imaginal encounter.

UX-01R1 keeps the underlying logical grammar but reverses the experience hierarchy. **Journey is primary; Across Time is secondary.** The member is first taken somewhere and only later offered a way to understand what the encounter may touch across time.
## Member-facing journey

The first-use path is now:

**Prepare → Arrive → Let time open → Encounter → optional Dialogue → Discern → Return → optional Carry.**

The threshold asks only whether the member already has something in mind or wants to let something emerge. The journey itself shows four quiet phases — **Here / Opening / Encounter / Return** — instead of seven operator controls.

Future taxonomy is optional disclosure rather than a required step. Dialogue appears only after an encounter and both voices are entered by the member. Initial Keep is unavailable until an explicit Return has been recorded. Carry can be a way of being, a question, something to try, or **Nothing yet**.

Across Time is hidden before any journey is kept. Once available, it uses the member-facing language **What brought you here / What is true now / What is opening / What feels connected / And what does not fit?** The internal has-been / is-being / is-becoming distinction remains architectural rather than instructional.
