## 2. The evidentiary grammar (ratified)

```text
VISIBILITY     readdir · lstat            → exact          → zero structural failures required
READABILITY    text · hash                → thresholded    → ≥95% per content channel
OBSERVATION    unread / unattempted       → UNKNOWN        → never absence
APPLICABILITY  wrong metadata carrier     → NOT APPLICABLE → never absence
IDENTITY       sidecar ≠ corpus document  → carrier never becomes evidence
CLAIM SCOPE    report states the population actually measured → no hidden denominator changes
```

Six distinctions, each with its own semantics. ⛔ None of them may be collapsed into another.
The instrument can no longer say *absent* about anything it did not look at, and can no longer
count a description of a document as a document.

Report language reflects them: Markdown frontmatter is scoped to Markdown · non-Markdown
sidecar compliance is explicitly **not measured** · incomplete hash coverage becomes an
**observed lower bound** · domain and authorship results are scoped to the corpus documents
actually read.
