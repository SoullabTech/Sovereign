## II. Seam adjudication rule

I4's first real ingress must already carry enough explicit relational structure
that the I4 adapter can **mirror** a proposal into I2 rather than invent the
relation it is supposedly evaluating.

For the first ingress, the producer must already provide:

1. an explicit provisional proposition or synthesis;
2. explicit basis evidence references;
3. member scope and authorship sufficient to map without prose classification;
4. jurisdiction that maps to the closed I2 vocabulary without relabeling;
5. no need for the adapter to invent semantic force, warrant, motive, causation,
   identity, diagnosis, or member adoption.
