# JARVIS — WRITER'S STUDIO FLAGSHIP FLOW 01
# F8 / FIRST ARRIVAL + WORK-ROOT — CONTRACT + FALSIFIER FLOW v1

Programme: `JARVIS-WRITERS-STUDIO-FLAGSHIP-FLOW-01`

Status: PRODUCT-CONTRACT / TEST-DESIGN AUTHORITY  
Implementation authority: NOT GRANTED by this document.

Purpose:
Turn the First Arrival + Onboarding canon into an executable Writer's Studio contract so the first encounter is governed by the Work, not by feature explanation, a generic dashboard, or a false `Home` destination.

---

# 1. North Star

> **Writer's Studio does not onboard the member into software. It welcomes the member back into relationship with their Work.**

The first experience should answer:

```text
What Work is this?
Where am I?
What can I do now?
What has MAIA actually read?
Can I simply keep writing?
```

before it explains features.

---

# 2. Primary Product Law

First Arrival is:

> **a Work-root state**

not automatically:

> a fourth Writer's Studio room.

Primary Studio modes remain:

```text
Write · Develop · Review
```

No `Home` mode is authorized by F8.

---

# 3. First-Arrival State Classes

The initial contract must distinguish:

```text
NEW_WORK
EXISTING_WORK
RETURNING_WORK
IMPORTED_INCOMPLETE_WORK
UNREAD_WORK
STALE_READ_WORK
```

These states may share visual composition.

They must not share false copy.

---

# 4. Work Recognition

The first surface recognizes the Work using only lawful sources, in preference order:

1. member-declared purpose;
2. exact Work line with factual reason for surfacing it;
3. Work facts.

Never fabricate:
- what the Work is "really about";
- what the writer intended;
- what matters most.

---

# 5. NEW_WORK

Member-facing opening:

> **What are you beginning?**

Allowed:
- title;
- optional member-written description.

Then:

> **Where would you like to start?**

Possible actions:
- Start writing
- Bring in something I've already written
- Make a simple map of what I know
- I don't know yet

No mandatory:
- genre classification;
- skill level;
- outline;
- AI-generated premise;
- developmental lens.

---

# 6. EXISTING_WORK

If the member explicitly opened a Work and no lawful resume state is present:

Show:
- Work identity;
- current authoritative place if route provides one;
- manuscript;
- plain next actions.

Allowed:

> **The River Between**

> **Chapter 6 — The Current Changes**

Then:

- Keep writing
- Help me understand something
- See the shape of this chapter
- Show me what keeps appearing
- I don't know — help me look

Do not invent "last worked here" from absence.

---

# 7. RETURNING_WORK

The Work must already have been selected through an authoritative context.

A lawful per-Work resume state may then support:

> **Welcome back to The River Between.**

> **You last worked in Chapter 6.**

Only when durable evidence supports it.

Resume may restore:
- mode;
- stable chapter/section;
- meaningful durable place where lawful.

Resume may not:
- select the Work globally;
- infer emotional or editorial intent;
- reconstruct a behavioral timeline.

---

# 8. COLD START

On cold start:

> **No global last-Work guess.**

The product may show a lawful Work chooser/shell if one exists elsewhere.

F8 does not authorize one.

If a Work is not yet selected:
- do not use per-Work resume state to choose one.

---

# 9. IMPORTED / INCOMPLETE WORK

Be literal.

Example:

> **Your manuscript is here.**

> **Writer's Studio identified 9 chapters. Two sections still need names.**

Allowed actions:
- Start reading
- Review the structure
- Fix section names
- Not now

Do not claim:
- MAIA understands the whole Work;
- imported structure is member-declared;
- detected headings equal authored structure.

---

# 10. UNREAD_WORK

Exact state:

> **MAIA hasn't read this Work yet.**

Supporting:

> **You can write without her. When you want another set of eyes, invite her to read a chapter or passage.**

Allowed:
- Keep writing
- Ask MAIA about this passage
- Read this chapter with MAIA
- What would MAIA read?

No auto-read on arrival.

---

# 11. STALE_READ_WORK

If a reading exists against an earlier version:

> **This chapter has changed since MAIA last read it.**

Arrival may expose:
- last reading time;
- current update state;
- Read again;
- Not now.

No silent refresh.

---

# 12. Arrival Does Not Commission

Entering Writer's Studio may not automatically:

- read manuscript;
- refresh stale reading;
- run Develop lens;
- generate observation;
- create summary;
- create member observation;
- mutate Work.

Arrival is orientation.

---

# 13. First Primary Actions

For an existing Work, the first action set should preserve:

```text
Keep writing
Help me understand something
See more of the Work
Return to what I've noticed
```

Exact labels depend on context.

Do not force the member into:
- Develop;
- Review;
- MAIA;
- a tutorial.

---

# 14. Keep Writing

`Keep writing` is always lawful.

Expected:
- enters/restores Write;
- preserves exact lawful place;
- commissions nothing;
- dismisses first-arrival framing;
- does not nag again in the same flow.

---

# 15. First Trust Moment

Trust language appears at the moment it matters.

Examples:

> **Your original is always preserved.**

> **MAIA will not read more of your Work until you ask.**

> **You can undo any revision you apply.**

Only say what implementation can prove.

No legal/trust wall on first load.

---

# 16. Onboarding Prohibition

Default first experience must not require:

```text
1 of 7
Next →
```

No feature carousel before Work value.

Optional later:
> Show me around

but:
- dismissible;
- never prerequisite;
- only explains Work/place/modes/MAIA/return.

---

# 17. First Discovery

If an admitted observation already exists, First Arrival may surface one concrete, low-claim discovery.

Example:

> **The river image appears three times in this chapter.**

Required:
- evidence;
- exact place;
- provenance;
- next move.

No:
- score;
- severity;
- "important insight";
- generic AI-generated welcome insight.

---

# 18. No Existing Evidence

If no admitted observation exists:

Do not create one merely to make onboarding feel alive.

Instead:

> **What are you trying to understand?**

or:

> **Keep writing**

F8 delegates the human-question flow to F7 Intent-First.

---

# 19. First MAIA Appearance

MAIA is not introduced with a capability catalogue.

Avoid:

> Hi, I'm MAIA, your AI writing assistant.

Prefer relationship through context:

> **I can look with you.**

If no read exists:
> ask before reading.

# 33. Human First-Arrival Test

Do not explain Writer's Studio.

Say:

> **You've come back to your book after some time away. Take a look around and do whatever feels natural.**

Observe:
- what participant looks at first;
- whether they recognize Work;
- whether they know current place;
- whether they can write;
- whether they understand how to ask for help.

Do not coach.

---

# 34. New-Work Human Test

Prompt:

> **You have an idea for something you want to write. Start however you would naturally.**

Pass if:
- product does not force planning taxonomy;
- member can begin writing quickly;
- optional structure/import routes remain understandable.

---

# 35. Returning-Work Human Test

> **Where do you think you are?**

Then:
> **Why do you think the Studio brought you here?**

Pass:
- member understands resume;
- does not believe MAIA inferred their emotional/editorial state;
- can choose another place immediately.
