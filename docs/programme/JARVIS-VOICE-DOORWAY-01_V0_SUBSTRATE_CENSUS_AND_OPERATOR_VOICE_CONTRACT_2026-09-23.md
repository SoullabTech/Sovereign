## 0 · Headline

The most reusable voice substrate for an Electron doorway is **not** `lib/voice` or `components/voice` (MAIA member runtime, React/Next/Capacitor-bound, several with cloud escapes). It is **`maia-desktop/src/**`** — the MAIA Desktop Electron app already carries an AudioWorklet capture, a main-process VAD, 16 kHz WAV encoding, an accounted utterance buffer and a frame-receipt liveness machine, all plain CommonJS with no Electron or MAIA dependency **(V: files exist)**. Its *transport* posts to production MAIA routes and ⛔ may not be reused. JARVIS Desktop itself has **no voice code and no media permission handler** **(V)**.

## 2 · JARVIS Operator Voice Contract — `jarvis-operator-voice.v1` (CANDIDATE, for V1 ratification)

**One mind, two capture modes.**
```
push-to-talk (button · hold-key) → AudioWorklet frames (16 kHz mono) → main process → local whisper.cpp 127.0.0.1:8080 /inference
      → transcript string → THE SAME string seam the textarea feeds → (plan | answer | work state) → text response [always]
      → optional local Kokoro localhost:8880 /v1/audio/speech → one Audio element, interruptible
```
1. **Capture** is opened only by a founder gesture (button press or key hold) and closed on release; frames are held in memory only (`utterance.js` pattern) and **discarded after transcription** — no file, no log, no store. The listening indicator is driven by frame receipt (`capture-liveness` rule), never by button state.
2. **STT endpoint is a constant in main** (`http://127.0.0.1:8080/inference`); the renderer can neither read nor supply it. A non-loopback URL is refused by a static guard. Production `maia-whisper` is unreachable by construction.
3. **Identity law:** `transcript` is submitted through exactly the function the typed box uses (`submitOperatorIntent` today; `compileIntent` once B6 wires O1). Falsifier: for any string `s`, voice(`s`) and typed(`s`) yield deep-equal task/intent objects. `[BLANK_AUDIO]`/empty → *nothing heard*, no submission.
4. **No voice-only authority:** a spoken utterance can reach no capability the same words typed could not; there is no command grammar. Static guard: no keyword→action table in the voice path.
5. **TTS is optional, off until the founder turns it on, local-only, fail-closed:** Kokoro called directly with a bounded timeout (proposed 10 s); unavailable → the text is shown with *voice unavailable*; ⛔ no router, ⛔ no `speechSynthesis`, ⛔ no cloud host. Static guard: `jarvis-desktop/src/**` contains no `openai.com`, `deepgram`, `elevenlabs`, `googleapis` hostname and no `speechSynthesis` reference.
6. **Interruptible:** a new gesture, a new utterance or Escape stops playback immediately; the text stays.
7. **Visible state:** `idle · listening (frames arriving) · transcribing · thinking · speaking · voice unavailable`; each names its source (frame receipt · STT response · Kokoro response).
8. **Failure is legible:** STT unreachable → "JARVIS can't hear right now — type instead" and the textarea stays usable; the whisper-server log is treated as a retention channel until proven transcript-free.
9. **IPC (five-question law, B5-era act, ⛔ not spent by V0):** at most two new invoke verbs — `jarvis:voice-utterance` (`{pcm16k, sampleRate}` → `{ok, text|null, reason}`) and `jarvis:speak` (`{text}` → `{ok, audio|null, format, reason}`) — plus a `session.setPermissionRequestHandler` granting `media`/`audioCapture` only, for the app's own `file://` origin (precedent `maia-desktop/src/main.js:660–664`). No push channel is required for push-to-talk.
10. **Wake phrase** is out of contract until the Q10 evidence exists.

**Falsifiers for V1 (each with a defeat candidate to be built before V2):** V-F1 identity (defeat: a voice path with its own trimming) · V-F2 loopback-only STT (defeat: URL from renderer) · V-F3 no retention (defeat: debug WAV dump) · V-F4 fail-closed TTS (defeat: `speechSynthesis` fallback) · V-F5 no voice-only authority (defeat: "Jarvis, run it" grammar) · V-F6 indicator from frames (defeat: indicator from button) · V-F7 blank-audio not submitted (defeat: submits `[BLANK_AUDIO]`) · V-F8 interruptible (defeat: queued playback that finishes first).
