## Laws preserved from this lane

> ### MI-LAW-1 — Warrant, not validation
> A consequential interpretation must have an adequate warrant. **Runtime validation is one possible
> warrant, not a universal requirement.** The warrant may instead come from closed producers plus a
> stable contract · compatible historical evolution · version-dispatched parsing · database
> guarantees · structural discrimination · independent outcome verification · or keeping the value
> opaque.
>
> The question is never *"was this runtime validated?"* but ***"why is this particular proposition
> safe to rely upon here?"***

> ### MI-LAW-2 — Proof is proposition-local
> A warrant proves only the proposition it actually establishes; **proof does not transfer sideways
> across an object.** `recoverEvidence` warrants the recovered prose — not `lens`, not `phenomenon`,
> not any sibling field.

> ### MI-METHOD-1 — Instruments nominate; they do not adjudicate
> **Textual occurrence is evidence of where to inspect, never evidence by itself of runtime
> reachability, dependency, semantic classification, or authority.**
>
> ```
> grep / search          →  candidate locations
> direct source reading  →  semantic classification
> type / schema / runtime evidence  →  adjudication
> ```
>
> Earned by four falsifications, kept in the record. The fourth is the one that promoted it:
> column-name grep found **5** writers, symbol/call-graph found **7**. ⚠️ **That is not noise — it
> is false reassurance**, and it was already published when it was corrected.

## Where the two lanes leave the architecture

```
BW  established:   a REFERENCE does not prove AUTHORITY
MI  established:   a REPRESENTATION does not prove MEANING

and outcome-verification adds the subtler third:
    sometimes the system need not prove an entire representation
    if it can independently prove the exact consequence it intends to assert.
```

> ⭐⭐ **Trust belongs to claims, not containers.**
>
> A database row is not "trusted". A JSON object is not "trusted". A memory is not "trusted". A
> model response is not "trusted". **Specific propositions are warranted by specific evidence under
> specific conditions.**

That scales toward memory, cognition, provenance, agent action, authorship and relational
intelligence — and it is the same discipline, one layer deeper, that BW applied to authority.
