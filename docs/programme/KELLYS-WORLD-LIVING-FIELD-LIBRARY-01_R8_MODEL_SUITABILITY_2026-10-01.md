R8 does **not** choose a preferred long-form Grokker model.

It establishes a two-dimensional constraint:

```text
fast enough for C1
≠
semantically strong enough for unattended synthesis
```

and:

```text
stronger local model
≠
permission to widen C1 latency / authority
```

The next boundary should therefore inspect the existing canonical Work Unit / local-provider substrate for a **deliberative Grokker synthesis work unit** rather than turning C1 into a long-running lane.

- the R5 source packet;
- exact source descent;
- candidate/unestablished standing;
- independent evidence containment;
- semantic review as a separate act;
- no silent relation warrant;
- no new cost-class vocabulary if existing Work Unit mechanisms already suffice.

No C1 timeout change, model replacement, merge, or deploy is authorized here.
