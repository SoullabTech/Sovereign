## Today hierarchy

```text
Needs Kelly
In motion
Watching
Everything else
```

**Needs Kelly** contains only evidence-backed work that explicitly asks for Founder action.

**In motion** contains open work that is running, routed, drafted or otherwise active without asking Kelly for a decision.

**Watching** contains programme conflicts and observed Monitor warnings/failures.

**Everything else** is secondary context and recent change, collapsed by default where practical.
