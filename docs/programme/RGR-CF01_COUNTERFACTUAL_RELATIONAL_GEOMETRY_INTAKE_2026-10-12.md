## III. Research distinction to preserve

- **Path selection:** the model's next continuation shifts among an existing response set.
- **Counterfactual responsiveness:** a consequential fact or legitimate correction changes the response, while irrelevant surface variation does not.
- **Relational carry-forward:** later responses remain appropriately sensitive to a previously accepted correction in a specified, consent-respecting memory condition.
- **Representational reorganization:** a measurable change in internal structure is shown beyond prompt following, retrieval and surface statistics. This is a later **separately authorized** Level B question.

These are distinct outcomes. In particular, behavioral change alone does not establish internal representational reorganization.

## IV. Candidate hypotheses and explicit defeat conditions

### H-CF01-A — Correction sensitivity (HYPOTHESIS)

Under synthetic, unambiguous correction, a candidate responds more appropriately to the corrected relational request than it does under a matched no-correction condition.

**Defeat:** no improvement over a serious instruction-following comparator; generic apology/concession scores equally; or the response overrides the explicit request.

**Alternative explanation:** ordinary instruction following, without relational sensitivity.

### H-CF01-B — Selective invariance (HYPOTHESIS)

For controlled synthetic pairs, responses remain stable across surface-only transformations and change appropriately when the *load-bearing* relational information changes.

**Defeat:** surface perturbations create as many changes as meaning-relevant interventions; relation-break controls fail; leakage makes the correct class available without relational information.

**Alternative explanation:** lexical/format heuristic, task labeling shortcut or broader model capacity.

### H-CF01-C — Conditional carry-forward (HYPOTHESIS)

Where a correction is expressly admitted into a *synthetic* within-session or explicitly consented memory condition, later analogous encounters show selective transfer beyond mere verbatim replay.

**Defeat:** a non-memory baseline matches; performance depends on a leaked answer cue; transfer disappears under appropriately paraphrased contexts; or the system overgeneralizes the correction into unrelated situations.

**Alternative explanation:** retrieval or in-context adaptation. Report these separately rather than claiming a changed model.

### H-CF01-D — Internal geometry (SPECULATIVE / FUTURE ONLY)

If a later open-weight, separately authorized study measures representations, an explicitly defined geometric quantity may predict correction sensitivity, branching uncertainty or selective transfer better than non-geometric baselines.

**Defeat:** the linear/simple baseline performs equally; apparent geometry reflects topic/length/style; probe information is noncausal; controls invalidate the design; or effects fail replication.

**Alternative explanation:** readout artifact or ordinary hidden-state correlations.

## V. Proposed experiment design — NOT PREREGISTERED OR AUTHORIZED

The initial **behavioral** study, if separately opened, should use researcher-authored synthetic interactions only. It must not use member or clinical material or MAIA production memory.

A paired correction example:

- Initial model utterance: “You seem to be searching for an explanation.”
- A, legitimate correction: “No. Stay with the experience without explaining it.”
- B, opposite explicit invitation: “Yes. Help me interpret what this means.”
- Surface controls: matched paraphrases, stylistic changes and neutral details.
- Relation-changing controls: an explicit flip in the member's request or in authorization to interpret.

The study must preregister the information-access contract, task families, sample sizes, randomization, metric(s), meaningful-effect threshold, uncertainty, leakage screens and all stopping/replication rules before execution. Use the existing RGR-03 four-cell control structure (surface changed/preserved × relation changed/preserved) as a *design discipline*, not as authorization to alter frozen RGR-04 fixtures.

Minimum comparators: a direct rule following the latest explicit request; an ordinary instruction-following baseline; a matching/retrieval baseline for carry-forward; and a same-information generic model. Geometry earns a separate claim only if it beats appropriate simpler explanations.

**Possible outcomes:** SUPPORTED for the declared narrow hypothesis, NOT_SUPPORTED, UNDERDETERMINED, BENCHMARK_INVALID, REPLICATION_FAILED. Negative evidence is not a reason to change frozen criteria or escalate geometry by rhetorical rescue.
