# RELATIONAL-GEOMETRY-INTEGRATION-01 — R1 Research Crosswalk

## 1. Typed relational reasoning

**MAIA finding:** similarity is evidence for relation, not relation itself. `REFERS_TO`, `CORRECTS`, `ADOPTS`, `RETURNS_TO`, `GROUNDS`, and `CONTESTS` are distinct relation kinds.

**Research support:** Battaglia et al., *Relational inductive biases, deep learning, and graph networks* (2018), argues for entities, relations, and compositional rules as structured inductive biases.

**Candidate primitive:** directed typed edge with provenance, process scope, temporal scope, standing basis, and correction history.

**Prediction:** typed relation models should outperform scalar-similarity-only models on antecedent identity, correction, and continuity tasks.

**Falsifier:** if relation typing adds no measurable accuracy or causes no distinct errors when collapsed to similarity, the extra grammar is not earned.

## 2. Multilayer / Elemental differentiation

**MAIA finding:** affective, cognitive, somatic, volitional, and relational signals should remain differentiated long enough for their relations to become intelligible.

**Research support:** Kivelä et al., *Multilayer networks* (2014), formalizes systems whose distinct relationship layers should not be collapsed into one ordinary graph.

**Candidate primitive:** separate process layers with cross-layer edges; no person-level Element score.
**Elemental analogue:** FIRE / WATER / EARTH / AIR as differentiated observation layers; AETHER/FIELD as organization among layers, not a fifth content score.

**Prediction:** preserving layer identity should improve detection of contradiction, transition, and integration compared with a single flattened semantic summary.

**Falsifier:** if a flattened representation matches or exceeds multilayer performance while preserving correction and freedom, Elemental multilayer complexity is not justified.

## 3. Higher-order configuration

**MAIA finding:** meaning can belong to a configuration rather than to any pairwise relation alone.

**Research support:** Battiston et al. (2021) and subsequent higher-order-network work distinguish pairwise graphs from hypergraphs / simplicial complexes for group interactions.

**Candidate primitive:** configuration object or hyperedge whose membership and standing descend to the constituent evidence/relations.

**Astrological structural analogue:** T-square, grand trine, grand cross, yod — treated only as examples of grammars in which a whole configuration has properties not reducible to one aspect.

**Prediction:** explicit configuration representations should improve recognition of multi-process tensions or coherence where pairwise-edge aggregation loses information.

**Falsifier:** if configuration labels are reconstructible without loss from pairwise relations and add no predictive value, do not persist them as separate objects.
## 4. Temporal geometry

**MAIA finding:** recurrence, correction, development, and return are directional events; sequence carries information that a static snapshot loses.

**Research support:** relational-event modeling treats temporal ordering of relational events as informative rather than collapsing events into static aggregates.

**Candidate primitive:** temporally ordered relation events plus derived trajectory descriptors such as strengthening, weakening, recurrence-with-change, correction, and transformation.

**Astrological structural analogue:** applying / separating aspects as a hypothesis about relation directionality through time, not as inherited causal truth.

**Prediction:** temporal relation sequences should outperform unordered history on developmental-return and correction-sensitive continuity tasks.

**Falsifier:** if event ordering adds no useful predictive or adjudicative information beyond current standing, temporal-geometry complexity is not earned.

## 5. Binding and antecedent identity

**MAIA finding:** reaching back is not the same relation as reaching back to this; claim identity must survive fluent prose.

**Research support:** variable-binding work formalizes role–filler identity; coreference research distinguishes reference detection from antecedent resolution.

**Candidate primitive:** stable claim identity + typed `REFERS_TO` relation, with ambiguity represented explicitly rather than guessed.
**Prediction:** stable identity + explicit relation binding should reduce false confirmation, correction spread, and opaque-reference hallucination compared with whole-turn or similarity-based binding.

**Falsifier:** if exact claim identity does not materially improve these tasks, the binding layer is over-specified.

## 6. Integration without homogenization

**MAIA finding:** differentiated processes must communicate without collapsing into one interpretation.

**Research support:** corpus-callosum research supports interhemispheric transfer and integration while preserving differentiated processing; both excitatory and inhibitory functions have empirical support.

**Candidate primitive:** mediated cross-layer exchange that may amplify, inhibit, gate, or leave a process independent.

**Corpus-callosum analogue:** architectural only. No left/right-brain content mapping is imported.

**Prediction:** mediated cross-layer exchange should preserve contradictory but jointly relevant signals better than early fusion.

**Falsifier:** if early fusion performs equally well on contradiction, correction, and member-freedom tests, the integration membrane adds no value.

## 7. Geometric relation operators

Astrological aspect geometry is admitted only as a source of candidate structural operators:

- conjunction → low differentiation / co-location
- opposition → polarity
- square → cross-pressure / incompatible constraints
- trine → facilitative resonance
- sextile → compatible but non-compulsory coupling
- orb → tolerance / fit band
- applying / separating → strengthening / weakening relation

None of these names receives runtime authority. Each must be translated into measurable features and survive independent falsification before it can enter a computational grammar.
