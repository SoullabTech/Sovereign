# 0. Programme Law

The authority ladder never collapses:

```text
FOUNDER
  ↓ authorizes act
JARVIS
  ↓ composes bounded work packet
AGENT / CC
  ↓ implements or investigates only that packet
EVIDENCE
  ↓ proves only what it witnessed
FOUNDER
  ↓ adjudicates human/product gates
ADMISSION
  ↓ canonical custody
RELEASE
  ↓ exact candidate freeze
DEPLOYMENT
  ↓ separate production act
POST-DEPLOY
  ↓ independent witness
```

Never infer:

```text
specified = implemented
implemented = tested
tested = human-accepted
human-accepted = canonical
canonical = deployed
deployed = post-deploy witnessed
```
