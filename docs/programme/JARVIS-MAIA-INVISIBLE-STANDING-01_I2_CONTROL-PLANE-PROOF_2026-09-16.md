# JARVIS-MAIA-INVISIBLE-STANDING-01 — I2 Control-Plane Proof

## Result

The first deterministic Invisible Standing prototype passes **9 / 9 executable tests**.

Most importantly, the exact ten responses preferred in the sealed S5 human review all pass the control plane **byte-for-byte unchanged**.

## What the prototype can prove

The prototype refuses only named rule violations with deterministic proof:

- existing constitutional identity-predicate authority violations;
- existing false memory-capability claims;
- an exact quote attributed to the member when the exact source text is system-authored;
- an exact superseded member claim presented as a current member claim, but only when claim standing is actually supplied by the substrate;
- draft/audit mismatch (the emitted draft must be the same bytes that were audited).

It permits:

- ordinary MAIA first-person speech (`I hear…`, `I want to respect…`);
- exact current member quotation;
- historical quotation of superseded member evidence;
- unknown attribution when the evidence population is incomplete (observe only, never block).

## Structural property

The auditor's result type has **no replacement-text field**. It cannot turn MAIA's response into Standing Envelope prose. A separate emission gate may only:

- return the original bytes unchanged; or
- refuse emission.

## Evidence ceiling

This does not solve semantic entailment. A natural-language synthesis may still rely on stale or unsupported meaning without making an exact quote or another substrate-provable violation. That class remains outside deterministic enforcement.
