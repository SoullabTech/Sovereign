# JARVIS-MAIA-INVISIBLE-STANDING-01 — I5 Minimal Sidecar

## Change from v2

The model no longer classifies witness / synthesis / attribution / question. It only selects from closed response sentence ids and nominates candidate evidence ids. This removes another unnecessary semantic authority surface.

The sidecar is therefore useful as an attention instrument but decoding-variable at the sentence/evidence-link level. That variability is disqualifying for enforcement authority.

## Standing

Every sidecar evidence link remains a **candidate relationship only**. It cannot prove entailment, authorship, correction, or claim standing.
