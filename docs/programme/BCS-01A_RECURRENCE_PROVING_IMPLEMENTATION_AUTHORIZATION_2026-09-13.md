## 5 · Coverage falsification — **mandatory**

A partial run may truthfully establish `partition 1 processed · partition 2 processed ·
partition 3 pending`. ⛔ It may **not** establish **whole-Work recurrence** merely because
recurrence appears in completed partitions.

> **A checkpoint is execution state. Progress is not a finding.**

⭐ The recurrence contract's existing prohibition is an **independent acceptance gate** —
satisfied or failed before any FR-J9 falsifier is applied.

## 6 · Uniformity trap — **mandatory**

A fixture where the same property occurs uniformly across every unit read must yield
**REGULARITY**, not **RECURRENCE**. ⛔ An implementation that turns repeated identical local
classification into recurrence **by aggregation** fails the proving workload *even if the job
substrate itself works.*

## 7 · Crash and resume — two separate witnesses

```text
CRASH RECOVERY    kill an active worker after claim → the stale execution becomes executable again
CHECKPOINT RESUME kill after durable checkpoint N → units 1…N stay complete; execution resumes
                  at the first unfinished unit, NOT from zero
```

⛔ **The witness must identify which behavior is which. The word `resumability` alone is not an
acceptable result.**

## 8 · Frozen input lineage witness

```text
observation → EvidenceRef → frozen revision / range / digest
```

⛔ The record establishes **frozen input lineage**. It may not claim *"this passage caused the
observation"* absent a separate legitimate causal witness. **Lineage is not causality.**

## 9 · Output classification

⛔ The execution receives **no producer identity**. Each durable output is classified by what the
material actually is. If no existing CMT producer truthfully fits: **the output persists and
remains outside CMT participation.** ⛔ The lane may not register a producer to make the proving
flow convenient — a discovered registration need is **returned as a separate founder act.**
