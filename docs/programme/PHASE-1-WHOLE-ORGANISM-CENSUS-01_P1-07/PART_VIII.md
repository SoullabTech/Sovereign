☐ OPTION B   POLYCENTRIC BY SUBJECT, UNRANKED BY DESIGN
             Authority is held by the subsystem that exercises it. Total-scope texts deferring to

☐ OPTION C   A RESERVED CORE, LOCAL EVERYWHERE ELSE
             A small, named, centrally ratified core binds absolutely and outranks everything;
             outside that core, authority is local to the subsystem that exercises it. Conflict
             inside the core resolves by the core's order; conflict outside it resolves locally.

☐ OPTION D   DEFER — preserve present uncertainty; make no strategic ruling yet
