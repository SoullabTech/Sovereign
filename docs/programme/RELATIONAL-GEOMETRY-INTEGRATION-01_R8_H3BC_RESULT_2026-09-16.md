## Question

Can a mediation layer preserve real cross-channel relations while refusing relations that are merely plausible, and can relation-specific evidence constrain which predicate is admitted?

## H3b — edge admission

Conditions used differentiated AIR / WATER / EARTH / FIRE nodes and production-equivalent `claude-sonnet-4-6` relation proposals.
H3b result:

| Measure | Result |
| --- | ---: |
| Runs | 12 |
| Model proposal correct | 7/12 |
| Final correct after generic edge gate | 9/12 |
| False relations before gate | 2 |
| False relations after gate | **0** |
| True relations preserved | 5/8 |
| Correct abstention | **4/4** |

The generic mediation gate successfully prevented unbound cross-layer relations, but it could not distinguish `TENSION` from `INHIBITS` or `ALIGNMENT` from `EVOKES` when the model blurred the operator.
## H3c — predicate-specific admission

The exact H3b proposals were replayed through a stronger law: binding evidence constrains both edge existence and the admissible predicate.

| Measure | Result |
| --- | ---: |
| Runs | 12 |
| Final correct | **12/12** |
| Wrong model predicates canonicalized from binding evidence | 3 |
| Unbound relations rejected | 2 |
| False relations after gate | **0** |

Constitutional law:

> **An admitted cross-layer edge must have relation-specific evidence sufficient for its predicate. Generic plausibility may propose an edge; it cannot authorize one.**
## Adjudication

**H3 is conditionally supported as a mediation architecture, not yet as a complete acquisition mechanism.** The evidence supports selective integration after differentiated processing: allow only cross-channel relations with relation-specific binding evidence, preserve unresolved channels independently, and reject unsupported synthesis.

This earns the corpus-callosal analogy only at the level of **selective mediation without homogenization**. It does not establish a neuroscientific mapping between Elements and hemispheres.

## Remaining falsifier

This experiment assumed the binding-evidence class was already known. The next required test is whether those evidence classes can themselves be acquired from raw language without importing the answer key.
