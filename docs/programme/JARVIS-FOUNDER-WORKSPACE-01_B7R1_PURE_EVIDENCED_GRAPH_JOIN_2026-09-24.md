## 1 · Pure graph join

The join consumes only already-read governed rows:

- B4 projected programme rows and their exact association records;
- B2 Work Units, sessions, results;
- existing canonical execution-grant standing resolvers;
- exact canonical relation statements admitted by the narrow B7 relation parser;
- B7R1 bounded partner-handoff read rows.

The pure join module performs no filesystem, process, network, model, provider, or IPC action.

Every graph id is namespaced by kind:

```text
programme:<id>
record:<path>
work:<id>
grant:<id>
session:<id>
branch:<recorded-branch>
result:<id>
partner:<handoff-id>
```

A field remains a focus, not another node kind.

## 2 · Live relation families

B7R1 emits only the frozen relation families whose exact targets exist:

```text
programme → has record / supported by record → record
programme → governed by founder decision → record
work unit → belongs to programme → programme
work unit → child of → work unit
work unit → has execution grant → grant
session → recorded branch → branch
session → for work unit → work unit
result → for work unit → work unit
partner handoff → orients → programme
programme → supersedes → programme
```

Missing targets produce no dangling edge.

Historical session custody is labelled **recorded branch**, never “current branch.”

## 3 · Explicit programme relation parser

B7R1 does not infer relations from shared prefixes, names, or co-occurrence.

The first canonical relation parser is deliberately narrow:

> one canonical line containing two exact backticked programme ids with the literal relation verb **supersedes**.

That is sufficient to admit the witnessed Writer's Studio relation:

```text
WRITERS-STUDIO-NEXT-01
    supersedes
WRITERS-STUDIO-CONVERGENCE-01
```

from the exact canonical source line.

A paragraph that merely mentions both ids emits no edge.

## 4 · Partner-handoff read organ

B7R1 adds one bounded read organ over:

```text
~/.jarvis/context-handoffs/*.json
```

It:

- reads only regular JSON files in that exact directory;
- refuses symlinks;
- refuses files above the bounded size;
- accepts only `jarvis.partner-context.v1`;
- accepts only MAIA, ChatGPT, or Claude Code;
- requires `authority: orientation_only`;
- performs no write.

The Graph evidence viewer recognizes only exact admitted refs of the form:

```text
partner-handoff:<filename>.json
```

It cannot use this prefix to read arbitrary files.

Partner context remains orientation only and cannot satisfy repository evidence.
