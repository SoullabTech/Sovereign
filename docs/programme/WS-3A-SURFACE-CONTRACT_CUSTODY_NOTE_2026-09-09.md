## The one finding this lane sends back to §3a's owner

⭐ **S6 — "crossed but confirmation failed" must be a first-class state.**

```text
NOT CROSSED
  safe to say disclosure did not occur

CROSSED + CONFIRMED
  ordinary successful boundary record

CROSSED + CONFIRMATION FAILED
  ⛔ EXCEPTIONAL. Must truthfully say the context crossed.
  ⛔ Must NOT masquerade as a pre-crossing refusal.
```

⛔ **This is the assertion most likely to rot, and the reason is structural, not
careless.** Every failure state looks alike on a screen, and the copy that fits
all the others — *"nothing from this Focus was sent"* — is precisely the sentence
that is **false** here. A later tidy-up that unified the failure copy would pass
review, read as consistency, and make the system lie about a disclosure that
actually happened.

an already-crossed state onto the simple "nothing was sent" copy and prove the
falsifier goes red. ⭐ **A falsifier that has never failed on this exact
substitution has not been shown to detect it.**
