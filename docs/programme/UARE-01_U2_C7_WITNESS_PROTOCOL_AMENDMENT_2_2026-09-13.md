## 1 · Withdrawn — my declared carryover-bias direction

**Withdrawn proposal (Amendment 1 §6), preserved verbatim as a proposal:**

Nothing in this lane establishes that an in-corpus first-person answer primes **fabrication** rather
than, equally plausibly, **stronger source discipline**, **generic conversational conformity**, or
something else entirely. ⛔ **Predeclaring an unsupported bias does not make it less unsupported** —
and predeclaring it in advance made it *look* rigorous, which is worse, not better.

⭐ Recorded as the same error shape the lane keeps finding, this time in the instrument's own
compensation logic: **an inference dressed as a control.**

## 2 · The replacement — isolation is a validity requirement

```text

```

> **Fresh-conversation isolation is a validity requirement.** If the product does not permit
> independent conversations against the same frozen Individual AI, **C-7 stops without producing
> `[O]` evidence capable of adjudicating §4.**

```text
CARRYOVER UNAVOIDABLE  →  STOP  →  C-7 NOT RUN / INVALID FOR §4
```

⛔ **Do not run the sequence and then discount A or strengthen B/C.** Once the trials condition one
another, the instrument no longer knows whether it is observing **corpus discrimination** or
**conversation-history effects**:

```text
control → later trials   UNKNOWN EFFECT
Q1 → Q2                  UNKNOWN EFFECT
Q2 → Q3                  UNKNOWN EFFECT
```

⭐ **This prevents a platform constraint from becoming an excuse to weaken the experimental standard.**
