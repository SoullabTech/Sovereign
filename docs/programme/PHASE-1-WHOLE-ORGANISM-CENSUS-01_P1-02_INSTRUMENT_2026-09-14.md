1. **Actual organism first.** Trace what exists; ⛔ do not infer implementation from governing
   aspiration.
2. **Named object, not vocabulary.** Every finding identifies the concrete artifact, path or object.
3. **No invented cognition boundary.** Domain A reports actual **entry · convergence · delegation ·
   return · termination** points. The canonical cognition boundary remains **`UNKNOWN`** — P1-01
   established that only a target exists, not a completed boundary.
4. **Checkable means checkable.** ⛔ Do not manufacture proxy metrics for the Oath, felt qualities,
   relational claims or other judgement-language. Slice 01 already separated structural checks from
   non-computable claims; that split is binding.
5. **Citation ≠ implementation.** The eight canon-named code artifacts must be **verified directly**;
   a document naming one proves nothing about its present existence or behaviour.
6. ⭐⭐ **Governance absence survives implementation discovery.** Finding code that grants
   practitioner visibility, evaluates a freeze, routes a fallback, or computes *"field"* **does not
   make that behaviour governed.**
7. **C-2 remains evidence-input only.** ⛔ No predecessor-census claim becomes present truth without
   re-reading at the census subject.
8. **E-1 remains hard.** Current-tree evidence is usable; history claims beyond the shallow evidence
   remain **`UNKNOWN`**.

### ⚠️ Calibration of `LIVE` in this container — binding

**There is no runtime, no database and no production access in the census environment.** Therefore:

```text
LIVE                     requires a traced call path at the census subject
                         AND a dated runtime/production witness record in-repo.
                         ⛔ Both, or it is not LIVE.

WIRED-BUT-UNOBSERVED     a complete path is traced from a real entry point,
                         but no runtime observation exists. ⭐ THIS IS THE
                         HONEST DEFAULT FOR MOST OF THIS CENSUS.

DORMANT                  the code exists; no reachable caller was found.
ORPHANED                 the code exists; its declared consumer does not.
DOCUMENTATION-ONLY       named in documents; no artifact found at the subject.
```

⭐ *A traced import chain proves wiring. It does not prove participation, and it never proves
authorization.*
