# D9 · Field and Orbit — how the Work and the instruments coexist

**Founder design ruling · 2026-09-09 · ⛔ NOT IMPLEMENTED**
Answers: *how do we weave the Canvas capabilities into the clean creative field?* ⭐ **By not
choosing between them.**

> ⭐⭐ **THE WORK STAYS STILL. THE TOOLS MOVE AROUND IT.**
>
> ⭐⭐ **Keep the Work visually sovereign. Let the interface gather around the writer's attention.**

---

## 1 · The reversal to preserve

⛔ **The production Canvas makes the tools feel permanent and the writing feel INSERTED BETWEEN
THEM.** ⭐ **The artifact reverses it: the writing is the place; everything else is secondary.**
**That reversal is the thing to keep.**

```text
                         WHOLE WORK
                            ↑
                    structure / materials
                            │
               ┌───────────────────────┐
               │       THE WORK        │
   ← orientation│   living creative     │ relation →
     navigation │        field          │   MAIA
               └───────────────────────┘
                            │
                     workbench / history
                            ↓
                    OPERATIONAL LAYER
```

⭐ **The centre is phenomenological. The perimeter is functional.** **The system may be extremely
sophisticated without making the writer inhabit that sophistication.**

## 2 · ⭐ PROCESS DETERMINES INTERFACE DENSITY

```text
WRITING            almost everything recedes — no statistics, no versions
                   tray, no permanent MAIA explanation, no navigator eating
                   a quarter of the screen. All one gesture away.

HIGHLIGHT          the room responds to attention. Passage stays lit.
                   "Ask MAIA" appears. The field already knows:
                   FOCUS the passage · CONTEXT the section ·
                   WHOLE available underneath · THREAD prior conversation
                   ⛔ no Rewrite/Expand/Tone/Analyze menu — intention
                      arrives in language

STRUCTURE          left orbit opens. Same manuscript, same position, same
                   highlighted passage. ⭐ "I haven't left writing to enter
                   Structure. I briefly brought Structure into writing."

DEVELOP            right orbit opens. MAIA gets a comfortable side field;
                   the centre adjusts gracefully rather than shrinking to a
                   column. Proposed language stays BESIDE the Work until
                   the writer puts it in.
                   ⭐ MAIA joins my attention. She does not seize the page.
```

**Modes become changes in EMPHASIS, not separate applications:**

| Mode | Centre | Periphery naturally available |
|---|---|---|
| Write | creation | manuscript · MAIA on demand |
| Develop | creative learning | MAIA · whole-Work context · structure |
| Explore | discovery | materials · connections · questions |
| Review | discernment | versions · comparisons · comments |
| Publish | transmission | formatting · metadata · output |

> ⭐ **One Work. Different relationships to it.** The manuscript stays recognizable through all five.

**Two concrete changes to the existing Canvas:**

```text
BOTTOM BAND    versions/outline/threads/timeline/goals/statistics
               permanently visible = a COCKPIT
               → becomes a WORKBENCH DRAWER, closed by default
               ⭐ the writer decides when operational information
                 enters consciousness

LEFT SIDEBAR   nineteen items visible while composing
               → QUIET: a thin rail — Work · MAIA · Tools
                 EXPANDED: the full navigator, when summoned
               ⭐ nothing lost; cognitive demand removed
```

## 3 · ⭐⭐ THE INTERFACE ITSELF MUST EXHIBIT SCALE COHERENCE

```text
sentence work  → a sentence-level environment
chapter question → chapter structure comes into relation
whole-book question → MAIA's context expands, ⛔ without another screen
version management → operational apparatus comes forward, then recedes
```

> ⭐ **Micro work creates a micro environment. Macro work reveals macro instruments. The Work remains
> continuous between them.**

⭐ **STRUCTURAL FINDING: this is the first time a doctrine written about COGNITION has been applied
to LAYOUT.** ⚠️ **It suggests the doctrines are not only "how MAIA thinks" but properties the whole
room must have** — *Scale Coherence, Developmental Tempo and F-REACTIVE all have interface forms, not
merely conversational ones.*

# 4 · Consequences

## 4.1 🔴 THE DISTINCTION THAT PROTECTS THIS FROM A BAD BUILD

⚠️ ***"Process determines interface density"* can be implemented two ways, and only one is lawful.**

```text
⭐ LAWFUL — GESTURE-DRIVEN
   the interface responds to what the WRITER DID
   highlighting · opening structure · summoning the workbench

⛔ UNLAWFUL — INFERENCE-DRIVEN
   the interface reconfigures because MAIA CONCLUDED something about
   the writer's state
   "you seem to be revising, so I opened Versions"
```

⛔ **Adaptive-by-inference UI is Law 4 at the interface layer — a strategic change to the room the
writer never authorized and must reverse-engineer.** ⚠️ **It is also the most reliably disliked
pattern in interface history, for exactly this reason: the room moving on its own is experienced as
being managed.**

> ⭐ **Every example in §2 is gesture-driven — the founder's intent is already correct. This states
> it so an implementer cannot read the principle the other way.**

## 4.2 ⭐ F-REACTIVE HAS AN INTERFACE FORM — registered

**The founder names it exactly:** *seeing nineteen capabilities while composing communicates
**"there are nineteen other things you should perhaps be doing."*** ⭐ **That is F-REACTIVE arriving
through furniture rather than through speech** — no observation was made, no suggestion offered, and
the writer is already oriented toward evaluation.

```text
ADDED TO F-REACTIVE'S DIAGNOSTIC SET
  "there are other things I should probably be doing"
  "I should check the statistics / versions / goals"
```

## 4.3 ⚠️ RECESSION MUST NEVER BE REMOVAL — and quiet has a discoverability cost

⭐ **"Nothing is lost; everything is one gesture away" is a REQUIREMENT, not a reassurance.**

⚠️ **But a quiet room is harder to learn.** ⛔ **A writer who does not know a capability exists cannot
summon it** — and this cuts differently by person:

```text
THE FOUNDER            knows the system; quiet is pure gain
A NEW MEMBER           may never discover Structure, Materials or Versions
AN ELDER / FIRST-TIME  the cost concentrates here
```

⛔ **Not solved here.** ⚠️ **And the obvious fix is forbidden**: onboarding tours, feature
highlights, or MAIA volunteering capabilities during composition would each reintroduce exactly the
pressure the quiet room removes. **Discoverability must be found somewhere other than interruption.**
