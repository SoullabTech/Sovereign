# RELATIONAL-GEOMETRY-INTEGRATION-01 — R13 / H3h Result

**Status:** EXECUTED · NOT CONFIRMED AS ACQUISITION MECHANISM  
**Date:** 2026-09-16  
**Authority:** offline research only

## Question

If global `bound` is removed, can dynamic interaction and configuration be acquired independently, each with its own evidence basis?

H3h represented:

```text
DYNAMIC
predicate · direction · source · target · evidence basis

CONFIGURATION
predicate · symmetric endpoints · evidence basis
```

Either, both, or neither could be present.
## Result

Same-model off-production inference used `claude-sonnet-4-6` through the local Claude CLI, restricted/no-tools, low effort. This is not an exact production-temperature replay.

12 runs:
- exact all-axis result: **7/12**
- dynamic predicate/direction/endpoints/basis: **9/12** each
- configuration predicate/direction/endpoints/basis: **8/12** each

By fixture:
- dynamic + alignment: **2/2**
- tension only: **1/2**
- inhibits + tension: **0/2**
- dynamic only: **1/2**
- alignment only: **1/2**
- neither: **2/2**

The schema successfully permits independent dimensions, but single-pass acquisition is not reliable enough to serve as the authority-bearing relation constructor.
## Interpretation

This is not evidence against multi-dimensional geometry. H3g already showed that co-present dimensions are representable (6/6 on multi-dimensional cases). H3h instead shows that asking one model act to both discover the evidence and construct the finished relation remains brittle.

The next test therefore mirrors the successful H1c architecture:

```text
RAW MEMBER LANGUAGE
        ↓
EVIDENCE-SPAN EXTRACTION
        ↓
DIMENSION-SPECIFIC BASIS
        ↓
DETERMINISTIC CANONICALIZATION
        ↓
RELATION OBJECT
```

The model may identify candidate evidence spans and basis classes; deterministic code decides which predicates/directions those bases are allowed to support.

**Constitutional law:** relation geometry must descend through relation-specific evidence; fluent classification alone cannot establish the edge.
