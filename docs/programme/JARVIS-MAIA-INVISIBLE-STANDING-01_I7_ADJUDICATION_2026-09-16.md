# JARVIS-MAIA-INVISIBLE-STANDING-01 — I7 Adjudication

## Narrow finding

Within the bounded Writer's Studio synthetic corpus, Structural Standing can be separated from member-facing voice in a way that preserves the relational responses preferred in S5 while still enforcing a small class of substrate-provable authority rules.

The programme supports **two distinct planes**.

## Plane A — hard constitutional control

```text
free relational draft
        ↓
deterministic audit
  named rule + substrate proof only
        ↓
PASS → emit identical bytes
REFUSE → do not emit that draft
```

Properties demonstrated in the prototype:

- 10/10 S5-preferred current responses pass byte-identically;
- ordinary MAIA first-person speech is lawful;
- exact system text misattributed as member speech is refused;
- exact superseded member text presented as current is refused when claim standing is supplied;
- historical superseded quotation remains lawful;
- existing identity-predicate and false-memory-capability violations can be represented as hard findings;
- the audit result has no replacement-text field;
- the bytes authorized for emission must match the bytes audited.

## Plane B — soft support-lineage observation

```text
same final draft
        ↓
deterministic sentence ids
        ↓
zero-authority sidecar candidate links
        +
deterministic lexical-superiority candidates
        ↓
shadow evidence / review only
```

The soft plane never blocks, repairs, or promotes standing. Across two seeds the hybrid recovered the present member utterance for the benchmark's load-bearing anchor in 10/10 cases, while the model sidecar alone varied (8/10 and 7/10).

## Architectural sentence

> **The hard plane may constrain only what the substrate can prove. The soft plane may help us notice what deserves scrutiny. Neither plane gets to narrate itself through MAIA's voice.**

## What remains unsolved

1. **Semantic entailment remains unproven.** Candidate evidence links are not evidence that a sentence is actually supported.
2. **CanonicalTurn does not yet carry general present claim-standing succession.** The hard stale-claim rule can only operate where lawful standing is independently supplied.
3. **Evidence completeness matters.** Unknown direct attribution is observe-only unless absence is itself provable.
4. **No production-model generality.** Sidecar discovery used one local model family and two seeds on synthetic Writer's Studio fixtures.
5. **No population claim.** S5 had one human adjudicator and ten admissible synthetic pairs.

## Production status

No live control plane is authorized. A future production-shadow successor is now **proposable** but not opened. It must preserve these invariants:

- current member-visible response remains the existing response;
- hard audit may not author replacement prose;
- soft observer cannot block production;
- no second model output reaches the member;
- no new durable member profile / Gestalt / synthesis is written;
- sidecar candidate links are never promoted into source standing;
- failures in soft observation cannot fail the response path;
- provider execution requires its own governed decision.
