# WRITERS-STUDIO-FLAGSHIP-ROADMAP-01 / D5C4 — THEME PRESENCE + TRAJECTORY CONTRACT

**Standing:** GOVERNING PURE-PROJECTION CONTRACT · NO NEW INFERENCE

## Purpose

D5C4 turns durable D5C3 occurrence addresses into the descriptive visual facts
the accepted Themes design needs: section presence and manuscript-order trajectory.

It does not decide what a theme means, how important it is, or where it is going.

## Zero is not unknown

A section may render **not here** only when the source Themes reading actually
read that section at body depth and contains no occurrence for the governed Theme.

An unread section, a section absent from the frozen source reading, or a current
section introduced after that reading is **unknown**. It must never render as zero.

## Presence scale

The existing governed presence vocabulary is retained and derived only from exact
occurrence counts inside one section:

- 0 occurrences → **not here**
- 1–2 exact occurrences → **once or twice**
- 3–4 exact occurrences → **sometimes**
- 5+ exact occurrences → **often**

These are frequency buckets, not quality, significance, intensity, or importance.
## Current-Work alignment

A projection receives current section identity + order explicitly.

Historical occurrence addresses are never silently remapped by heading, position,
semantic similarity, or neighboring text.

If a frozen occurrence's section identity no longer exists in the current Work,
it remains historical evidence but receives no current return address.

## Coverage

Whole-current-Work presence authority exists only when every current section is
present in the source reading and was read at body depth.

Partial coverage is shown as partial. Unknown cells stay unknown.

## Trajectory

Trajectory means only:

> the ordered locations at which exact occurrences appear.

It may show first/last current occurrence and the ordered frequency sequence.

It may not say a theme is growing, fading, deepening, resolving, strengthening,
emerging, or becoming more important. Those would require a separate governed
interpretive act.

## Member-declared Themes

A member-declared Theme with no admitted occurrence evidence is still a real
member Theme, but it has no presence/trajectory projection yet. The UI must show
the Theme without inventing bars.

## Acceptance

D5C4 passes only when pure tests prove:

1. exact count → frequency bucket is deterministic;
2. read-zero and unread-unknown remain distinct;
3. current manuscript reordering changes display order, not historical addresses;
4. removed historical sections are not remapped;
5. whole-Work authority is granted only under full body coverage;
6. trajectory is ordered location/count only, with no interpretive language.
