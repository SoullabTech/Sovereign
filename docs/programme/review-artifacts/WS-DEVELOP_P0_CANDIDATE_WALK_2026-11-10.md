## 2 · What the candidate changes

1. **No automatic observation selection anywhere.** The `useState` initial value, the reading-change effect and the `Math.max` clamp no longer pick an observation.
2. **Observation index.** Opening a reading shows an index; only the writer's choice opens one observation. "All observations" returns to it.
3. **Ready state and wait.** A reading the writer asked for completes into a quiet offer ("Explore observations — nothing is opened until you choose"), announced politely (`aria-live="polite"`, no focus move). `commission()` no longer navigates.
4. **A late reading cannot disturb a conversation.** The reading in view does not change on arrival, so an open conversation, a pending consent prompt and unsent text all survive.
5. **"More ways to explore" is visit-scoped** (per-Work temporary choice from #2208) and is labelled "this visit only". Starting a new visit clears it; the writer's saved View is never written.
6. **Read-only chapter pane on lens pages**, so the chapter stays on screen beside an index or an open observation.
