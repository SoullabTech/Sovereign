## §1 What this experiment is and is not

It reproduces the *source condition* under which every manual VP-ON session listened (run 5 + repro, 5/5). It cannot reproduce the *artifact*: that binary is gone (historical Stage C, CLOSED · NOT EXECUTABLE). A rebuilt dylib whose Mach-O UUID equals `11A057AA-4A3C-3CAE-8C28-E29792489459` is **useful evidence that the same source and toolchain produced the same linked image; it is not custody identity** (founder). The question is therefore: *on the automated stratum, on a cleaned container, does the Phase-A source condition show a different gen-1 take rate from the P5-B0 source condition measured under the same cleaned condition?* Any answer is read as probabilistic influence at most, never mechanism.
