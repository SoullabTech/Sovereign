## 7 · Source applicability — SELECTIVE, not AUTHORITATIVE

Exact source authority answers **may MAIA use this source?** It does not answer **is this source an appropriate interpretive frame for this query?**

Nearest-chunk similarity alone was falsified in production:

```text
known EA awareness query       max EA similarity ~0.693
TCM Fire / organ query         max EA similarity ~0.706  ← false positive
Feng Shui five elements        max EA similarity ~0.723  ← false positive
Ayurveda / dosha query         max EA similarity ~0.582  ← false positive
software SQL                   max EA similarity ~0.543
weather                        max EA similarity ~0.529
```

The candidate applicability representation uses max positive-scope similarity ≥ `0.50` and positive-over-confusable margin ≥ `0.05`.

Read-only calibration on the live local model produced:

- **7 / 7 intended EA / self-development controls eligible**;
- **8 / 8 adjacent wrong-system controls refused**, including astrology, ancient Greek elements, Wicca, tarot, fantasy elemental magic, TCM, Ayurveda, and chemistry.

This is bounded calibration evidence, not universal accuracy. It earns testing, not authority; the founder grant in §6 is still required.

Internal fan-out cannot multiply raw source weight.
