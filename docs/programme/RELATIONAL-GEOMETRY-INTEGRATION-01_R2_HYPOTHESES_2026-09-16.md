# RELATIONAL-GEOMETRY-INTEGRATION-01 — R2 Hypothesis Matrix

## Research priority law

Test the smallest structural distinction that could explain a witnessed MAIA failure. Do not begin with a full metaphysical model.

## H1 — Typed relation beats scalar similarity

**Question:** Does distinguishing relation kind improve antecedent, correction, and developmental-continuity accuracy?

**Compare:**
- A: embedding/similarity retrieval only
- B: similarity + typed relation classifier
- C: typed relation + standing + claim identity

**Primary tasks:** opaque reference, correction, adoption, return-with-difference.

**Success:** B/C materially reduce false binding and standing leakage without suppressing valid recall.

**Falsifier:** no meaningful improvement over A.

## H2 — Multilayer Elemental representation beats flattened summary

**Question:** Does preserving differentiated cognitive/affective/somatic/volitional observations improve recognition of contradiction and transition?
**Compare:**
- A: one narrative summary
- B: four differentiated process channels + uncertainty
- C: B + typed cross-layer relations

**Success:** B/C better preserve simultaneous conflict, member correction, and later transformation while producing fewer person-level trait inferences.

**Falsifier:** flattened A performs equally well or better on the same constrained tasks.

## H3 — Mediated integration beats early fusion

**Question:** Is a corpus-callosal-style integration membrane useful computationally?

**Candidate operations:** pass, inhibit, amplify, contest, synchronize, remain-independent.

**Success:** mediated integration preserves useful disagreement and improves later synthesis compared with collapsing layers before relational analysis.

**Falsifier:** early fusion is equally accurate, corrigible, and freedom-preserving.

## H4 — Higher-order configuration adds information beyond pairwise edges

**Question:** Are some Gestalt states irreducible in practice to independent pairwise relations?

**Compare:** pairwise graph vs explicit 3+ node configuration object / hyperedge.

**Tasks:** three-way tension, multi-process convergence, repeated configuration with one changed relation.

**Success:** configuration representation improves discrimination of states that share the same local nodes but differ in organization.

**Falsifier:** configuration object adds no predictive or explanatory value after pairwise relations are known.
## H5 — Temporal geometry beats unordered history

**Question:** Do direction and sequence improve recognition of recurrence, correction, and transformation?

**Candidate descriptors:** emerging, strengthening, weakening, correcting, returning-with-change, transforming, unresolved.

**Astrological analogue:** applying/separating only as a structural hypothesis about relation direction.

**Success:** temporally ordered relations outperform unordered evidence bags on developmental-return tasks.

**Falsifier:** ordering contributes no measurable information beyond current standing.

## H6 — Aspect-like operators can earn computational meaning

Start with neutral operator families rather than astrological labels:
- co-location / fusion pressure
- polarity
- cross-constraint
- facilitative resonance
- optional compatible coupling

**Experiment:** derive each from observable relation features, then test whether the operator predicts distinct conversational/developmental transitions.

**Success:** an operator generalizes across held-out examples and provides information not already captured by ordinary typed edges.

**Falsifier:** the category is merely a renamed cluster, cannot be measured reliably, or produces no incremental value.

## First experimental order

1. H1 typed relation vs similarity — highest existing evidence and easiest falsification.
2. H2/H3 Elemental differentiation + mediated integration — test together but score separately.
3. H5 temporal geometry — use correction and developmental-return corpora.
4. H4 higher-order configuration — only after pairwise representation is stable.
5. H6 aspect-derived operators — last; each must earn itself independently.

This order deliberately places symbolic analogy after empirically grounded relation, standing, and temporal primitives.
