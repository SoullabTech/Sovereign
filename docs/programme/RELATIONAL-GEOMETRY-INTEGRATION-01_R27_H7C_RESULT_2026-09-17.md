## Question

Can a pre-outcome complexity gate choose between pairwise and temporal geometry so that representation complexity is used only when the earlier process structure requires it?

H7c used one session not present in H7a/H7b and froze five new cutoffs before representation generation. Later member-authored turns supplied the outcome evidence. The selector was frozen from H7b: use pairwise unless earlier evidence itself contains explicit recurrence, interruption-return, supersession, reopened meaning, or multi-state transformation; otherwise use temporal geometry.

`G_GATED` received no extra model generation. It reused the exact B or D artifact chosen by the frozen selector.

## Event pattern

The selector succeeded cleanly on:
- the fifth-element/metaphysical-development episode: temporal 3/3 vs pairwise 0/3;
- the Mercurial creation arc: temporal 3/3 vs pairwise 2/3;
- communication-transfer episode: pairwise 3/3 vs temporal 0/3.

The return-after-interruption episode remained imperfect: temporal and pairwise both scored 2/3 while narrative scored 3/3.

The strongest selector falsifier was `C1_CONNECTION_QUALITY`: the frozen rule chose pairwise, which preserved 0/3 later-validated features. Narrative preserved 2/3 and temporal 1/3. The lost material concerned a holistic phenomenological quality of connection rather than a simple local edge or explicit developmental trajectory.

## Adjudication

H7c provides **partial held-out support** for conditional complexity gating. The gated condition matched narrative recall while using roughly half as many words and achieved the highest feature-per-word efficiency.

It does not justify a two-way selector as complete. One held-out event indicates a third representational demand: some member experience is organized as a whole-field or phenomenological Gestalt that pairwise structure can underrepresent even when no explicit temporal-developmental pattern is present.

This observation is post-result and must not be repaired on H7c. It becomes a new held-out hypothesis.

## Law carried forward

> **Use the least complex representation that preserves the process-relevant distinctions—but complexity has more than one axis. Local relation, temporal development, and whole-field Gestalt must not be collapsed into one scalar ladder.**

No result authorizes production integration, live cognition exposure, member-facing behavior, schema migration, or memory writes.
