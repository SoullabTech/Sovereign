## ⭐⭐ The finding that shaped C4

`ReadingsEntry` already documents the law C4 had to keep:

> *"NOTHING WHERE THERE IS NOTHING. With no stored reading this renders NULL — not a placeholder,
> not a button that would produce one. **No interpreter runs in production**, and a surface that
> implied one does would be the static-UI-claim failure."*

⭐ So **Review is a movement only when there is something to review.** A permanent Review control
would advertise a capability the system does not have — the exact defect that component exists to
refuse, lifted one layer up to the shell. ⛔ It is never satisfied by *"the member could commission
one"*, because today they cannot.

`workingMovements()` returns **only reachable movements**, so an unreachable one is **absent**,
⛔ never rendered disabled. There is no control to imply a readiness the system lacks.

## ⚠️ And the finding that stopped C4 from deleting capability

Four rail destinations — **materials · structure · versions · conversations** — are
`satisfiedInRoom`: they open real panels in the canvas. ⛔ **Ripping the rail out would have deleted
working capability while claiming to simplify.**

So C4 **collapses** the rail rather than removing it: `workingRailGroups()` keeps what is
`available` or satisfied in this room, and the unavailable destinations leave the working surface.

## ⭐ C3 — the return already had the substrate, and was not being fed

`StudioModeBar` accepts `currentSectionId` and already composes the return through `modeLocation`
(`canvasForManuscript` + `locationForSection`). ⚠️ **`WriterStudioShell` was never passing it**, so
the return fell back to reading `?s=` off the address — correct only while the room keeps the
address in sync, and silently wrong the moment one does not.

⭐ The shell now takes `placeSectionId` and feeds it through; `DevelopRoom` supplies its resolved
`placeId`. ⛔ Undefined keeps the previous behaviour exactly.

Also recorded: DevelopRoom's only link back to the canvas sits **inside a refusal branch**
(`revision_not_current`), and `canvasForManuscript` carries `m=` but not `?s=`. ⭐ The mode bar is
the real return, and it now carries the place.
