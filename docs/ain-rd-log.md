# AIN Intelligence R&D Log

## Purpose

Track how intelligence actually performs inside the MAIA/AIN environment.

- Increase local sovereignty
- Reduce cloud dependence
- Identify where AIN context improves outcomes
- Learn where frontier reasoning is still necessary
- Evaluate new open-source models as they emerge

This is the singular framework for all Soullab development intelligence.

---

## Entry Format

Copy this block for each experiment. Takes 30-60 seconds.

```
### YYYY-MM-DD — [task name]

**Task:** [What you asked the AI to do]
**Mode:** Local / Cloud / Local→Cloud escalation
**Model:** [e.g., maia-coder, maia-content, claude-opus, deepseek-r1]

**Context provided:**
- [ ] Architecture principles (maia-dev-mind.md)
- [ ] Existing code examples
- [ ] Design canon / tone
- [ ] Decision history
- [ ] Data model / schema
- [ ] Minimal prompt only

**Result:** Excellent / Good / Partial / Failed
**Time:** Faster / Same / Slower

**Failure pattern (if any):** [e.g., hallucinated files, missed constraint, overcomplicated]
**Escalation reason (if any):** [e.g., cross-stack debugging, architectural decision]

**Insight:** [One sentence — what made this work or fail?]
```

## Model Evaluation Template

When a new open-source model becomes available, evaluate it here.

```
### Model: [name and size]

**Date tested:** YYYY-MM-DD
**Source:** [Ollama / HuggingFace / other]
**Parameters:** [total / active if MoE]
**Quantization:** [Q4_K_M / Q5_K_M / etc.]
**Memory footprint:** [GB in unified memory]

**Tested on:**
- [ ] Component generation
- [ ] Refactoring
- [ ] Content/copy writing
- [ ] Multi-file changes
- [ ] Tool calling reliability
- [ ] Following system prompt instructions

**Result vs current default:**
- Better / Same / Worse at: ___
- Speed: Faster / Same / Slower
- Tool calling: Reliable / Occasional failures / Broken

**Verdict:** Replace default / Keep as option / Skip
**Notes:** [anything notable]
```

## What This Log Reveals (Over 4-8 Weeks)

1. **Local Intelligence Boundary** — what the machine reliably handles
2. **True Frontier Needs** — probably debugging, cross-system reasoning, new architecture
3. **The AIN Effect** — which context dramatically improves performance
4. **Model Evolution** — which new models shift the boundary

The core research question:

> How much intelligence comes from coherence of context vs raw model power?

Soullab has created a sovereign intelligence operating system — a stable field that any model can think inside. Not dependent on any vendor. Not racing model size. Building the environment that makes intelligence coherent.

That's AIN.
