## Question

> **When should individually useful capacities not be held together?**

03J tests whether a temporary capacity composition can become attentively noisy without that moment becoming:

- a compatibility score;
- an overload diagnosis;
- a cognitive deficit;
- an automatic simplification;
- a stable preference about how the member thinks.
