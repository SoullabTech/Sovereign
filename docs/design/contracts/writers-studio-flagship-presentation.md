# Writer’s Studio — Flagship Presentation — Experience Contract

## What this room is for

The flagship presentation gives the writer a quiet literary place in which the Work remains primary and MAIA appears in relation to the exact passage or question the writer has chosen. C1A governs the presentation substrate only. It does not declare the controlled candidate to be a live runtime and it confers no authorship, persistence, reading, navigation, or model authority.

## Arrival

> **The Work is already here. Begin with the writing.**

The presentation names only facts the host actually possesses. Missing Work kind, organization, epigraph, labels, or destinations remain absent rather than being generated to make the frame look complete.
## Gestures

| Gesture | Language used | Why this wording |
|---|---|---|
| Continue writing | the manuscript itself | Authorship remains direct; presentation does not become an editor authority |
| Bring MAIA to a passage | Ask MAIA | A member act at an exact locus, never an automatic reading commission |
| Consider a revision | Read in context | The proposal is experienced in the Work before Apply can exist |
| Return from contextual work | return/back language | Context never becomes a trapdoor away from the Work |

## Forbidden here

- replacing the proven authored-body/save substrate with static flagship prose
- a second save, mutation, place, held-passage, or revision authority inside presentation
- dead controls or destinations presented as live product capability
- bridging flagship Develop or Review into legacy rooms merely to satisfy navigation
- fabricating Work kind, epigraph, labels, identity, or other absent facts
- duplicating the flagship semantic token system in a live host
- treating controlled-component screenshots as a production witness
- mounting C1A into /writers-studio/rebuild without a separate C1B authorization

## The two brand tests

**Same house?** Yes. The flagship uses the same restrained Soullab hierarchy: warm Work field, lucid system chrome, bounded accent, quiet atmosphere, and MAIA visually distinct from authored material.

**Distinct room?** Yes. This is the creative room where the manuscript owns attention. Navigation recedes, intelligence is contextual, and every useful move returns to the writer’s own Work rather than to software machinery.
