# DREAM-02R2 — Abstract Dream Field + Visual Conformance Prototype

## Standing

This prototype proves that the seven founder-approved Dream states can inhabit one continuous abstract living field without default identifiable dream imagery.

The review route is intentionally isolated:

`/dev/dream-room-visual-review`

It accepts only a fixture state query:

`?state=arrival|remember|dream|encounter|amplify|series|integrate`

No member identity or content is read.

## Canonical abstract field

Asset:

`public/dream/dream-field.svg`

The field contains only:

- radial depth;
- partial ellipses;
- incomplete arcs;
- faint crossing axes;
- veils;
- low-luminance points;
- warm/cool asymmetry;
- atmospheric grain;
- non-resolved geometry.

It contains no:

- person;
- face;
- animal;
- house;
- door;
- landscape;
- deity;
- mandala;
- ritual implement;
- named archetypal image;
- narrative scene.

The same asset is used by all seven states.

State changes are created by restrained opacity, brightness, saturation, density, and spatial composition—not by swapping symbolic backgrounds.
