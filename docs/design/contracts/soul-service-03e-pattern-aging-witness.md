## Pattern aging is not forgetting

03E does not delete:

- historical evidence;
- original source version;
- provenance;
- the proposition that once had standing.

It changes only:

> **prospective authority in the current context**

This prevents longitudinal memory from hardening an old provisional pattern into permanent identity.

---

## Dormancy

Dormancy means:

- history remains;
- evidence remains;
- the pattern is no longer guiding current attention by default.

Dormancy is not:

- disproof;
- deletion;
- denial.

---

## Retirement

Retirement means:

- prospective influence ends;
- historical evidence remains inspectable;
- provenance remains intact.

The system does not erase the past to respect present change.
