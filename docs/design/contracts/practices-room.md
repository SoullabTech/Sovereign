# Practices — Experience Contract

## Law

> **Practice is entered, not achieved.**

Practices may help a member orient, attend, meditate, anchor, or return. The room does not add streaks, levels, performance pressure, or a capability catalogue.

## Readiness

Only practices with real member-facing destinations are named. Absence is preferable to a decorative placeholder.

## Reconciliation standing

This contract closes historical registry debt for the already-built Practices room. No UI source is changed by the reconciliation.
