# Becoming — executable local experience candidate

This is not a static board or a live member room. The entire encounter can be walked and explicitly kept, revised, revisited, exported, and deleted in browser-local IndexedDB. No account auth, provider, real database, application route, memory engine, or House registry is changed.

Readable design: ordinary UI 16px minimum, meaningful metadata 14px minimum, prose 18px, 44px control targets. Responsive layouts stack rather than shrink. The borrowed House background is served from the already existing local asset; no new generated visual authority is claimed. Screenshots and browser evidence are recorded separately. The composition remains a candidate for Kelly's visual review.

Seven movements are navigation, not completion requirements. Return is a member act; Keep alone cannot record it. Saving an open reflection leaves return unrecorded. Reopening starts at present orientation. The draft is memory-only until Keep; the browser may warn before leaving but never prevents the member from exiting.

Static reflective invitations are labeled as written prompts and are never attributed to MAIA. Dialogue fields require member entry. No future voice or pattern inference is generated. The temporal field displays only selected exact source revisions, separates past imagined content from past factual events, and admits member-entered connections and exceptions without scoring or classifying the member.

Browser storage is explicitly disclosed as unencrypted, account-unprotected local preview storage; test material is appropriate. No content is transmitted, logged, placed in URLs, or added to analytics. The preview has a restrictive CSP and a loopback-only server. This is containment for review, not a production security assessment.

Atomic IndexedDB transactions check expected revision before saving or deleting. Multi-tab stale writes must refuse. Delete removes the whole record and history; linked source IDs may remain but cannot reconstruct words. Exports retain provenance and are outside later in-app deletion. No API persistence is substituted silently when browser storage fails.

Outstanding: founder visual acceptance, live MAIA facilitation, authenticated account persistence, cross-facet context admission, Journal crossing, voice and actual device accessibility review, independent semantic/security review, canonical admission, production release.
