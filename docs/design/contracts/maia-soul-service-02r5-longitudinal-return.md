# MAIA-SOUL-SERVICE-02R5 — Longitudinal Return Witness

**Date:** 29 September 2026
**Status:** LOCAL DESIGN / INTERACTION CANDIDATE
**Base:** 02R2 truthful return
**Production:** closed
**Persistence:** simulated only
**Schema:** unchanged

## Purpose

02R5 tests return after meaningful time has passed.

The core question is:

> **What should still be available after days, weeks, or months—and what must be reconstructed from the present?**

## Governing law

> **Reorient before resuming.**

Longitudinal return should not automatically restore the prior session as though time had not passed.

## Witness interval

Synthetic interval:

> 30 days

Departure:

- living object: `work:elemental-alchemy`
- source: `ea:v1`
- one explicit member-kept marker
- one temporary MAIA lens
- one unsaved next-step suggestion

Return:

- same living object
- current source: `ea:v2`
- current source truth shown first
- exact v1 → v2 change inspectable
- explicit member-kept marker restored
- temporary MAIA lens not restored
- unsaved next step not restored
- old urgency / salience not restored

## Re-entry grammar

02R5 witnesses:

> **Recognize → Reconcile → Reveal change → Restore what was deliberately kept → Ask the present → Move**

## Present-tense movement

The member may choose:

- Resume from what I kept
- Revisit the earlier state
- Inspect the change
- Let it rest

No choice is selected automatically.

## Resume

Resume uses the explicit member-kept locus.

It does not restore unsaved momentum.

## Revisit

Revisit shows historical source as historical.

It does not promote the historical state to current truth.

## Inspect

Inspect compares source versions without narrating meaning.

## Let rest

Non-continuation is a lawful outcome.

## Preservation classes witnessed

### Preserved

- stable living-object identity
- source lineage
- historical provenance
- explicit member-kept marker

### Reconstructed fresh

- current source truth
- current relevance
- current field ordering
- present affordance

### Not carried forward

- temporary MAIA aperture
- unsaved next-step suggestion
- old urgency
- old salience

## Acceptance questions

1. Does the return recognize the same object without recreating the old session?
2. Is current source truth shown before historical state?
3. Is factual change inspectable?
4. Is the explicit member-kept marker restored?
5. Are unsaved MAIA lens / momentum absent?
6. Is Resume distinct from Revisit?
7. Can the member inspect change without a story of progress?
8. Can the member let the work rest?
9. Does the interface ask the present rather than presume continuation?
10. Does the old session remain historical rather than current?

## Exact stop

02R5 remains a local design witness.

It does not authorize durable return markers, longitudinal memory behavior, production re-entry, automated relevance scoring, or persistent session restoration.

**STOP before merge or production.**
