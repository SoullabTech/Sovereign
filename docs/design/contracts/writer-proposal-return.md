# Writer Canvas — Proposal return Experience Contract

## What this room is for

A writer is looking at one exact proposed change beside their manuscript. They may ask to return their attention to the exact marked passage without accepting anything, changing modes, or giving the proposal write authority. The Work remains the comparison surface; the proposal panel remains the issuer of the request and the narrator if that request cannot be honored.

## Arrival

> **The proposal is beside the Work; the exact change is in the Work.**

Proposal arrival may orient the writer once. After that, ordinary reading belongs to the writer. A later return happens only because the member asks for it.
## Gestures

| Gesture | Language used | Why this wording |
|---|---|---|
| return to the proposal locus | `SHOW CHANGE` in this bounded commit; semantically ruled to become `GO TO CHANGE` in the separate F1 lane | this act is orientation, not disclosure or opening a proposal |
| enter proposal work | `Work with this change` | changing mode is a distinct member act and may never be smuggled into orientation |
| decline the proposal locally | `Keep unchanged` | the manuscript is already unchanged; the member is naming that choice, not undoing a write |
| exact return cannot be fulfilled | `I can’t locate the exact passage in the manuscript. Nothing has moved.` | the issuer tells the member what request failed and that no shell fallback or off-screen movement was counterfeited |

## Forbidden here

- section-shell arrival presented as exact-locus success
- a pending return surviving into stale interactive debt
- inferring member intent from `scroll` or from the shared `jumpTo` carrier
- a detached excerpt, duplicate proposal panel, or duplicate manuscript representation
- implicit mode change or manuscript mutation from an orientation gesture
- silent refusal, shell fallback, automatic retry, or stale refusal attached to a newer member act
## The two brand tests

**Same house?** Yes. The proposal return keeps the Writer's Studio hierarchy, page material, typography, quiet metadata, and the House rule that member agency outranks automation. The Work remains visually primary; the proposal panel never becomes a second manuscript.

**Distinct room?** Yes. This is the only Writer Canvas interaction whose subject is one exact proposed change while preserving Whole-manuscript context. Its defining gesture is neither writing nor accepting; it is returning attention to the exact locus without surrendering the writer's chosen view.
