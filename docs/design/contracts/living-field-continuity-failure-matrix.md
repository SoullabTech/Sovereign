# LIVING-FIELD-CONTINUITY-FAILURE-MATRIX-01

**Date:** 29 September 2026
**Status:** design / falsification matrix

Continuity can fail structurally, temporally, spatially, epistemically, relationally, or experientially.

## Failure families

### CF-01 — Identity drift
The returned thing is represented as a new or different object without source warrant.

### CF-02 — Stale-state restoration
The system restores what was previously visible instead of current source truth.

### CF-03 — Context reset
Return collapses the member to a default/home state rather than their actual prior orientation.

### CF-04 — Salience overwrite
The system changes ordering, prominence, or centrality on return without a governed reason.

### CF-05 — Interpretive residue
A temporary MAIA frame, comparison, or rejected hypothesis remains attached after return.

### CF-06 — Provenance drift
The current source or relation loses visible authorship / standing after transition.

### CF-07 — Temporal collapse
Then and now are flattened into one apparent current state.

### CF-08 — Relation persistence error
A released, rejected, or unconfirmed relation survives return.

### CF-09 — Focus / viewport loss
The member must rediscover where they were physically or attentively.

### CF-10 — Branch collapse
Exploring one perspective silently removes other legitimate perspectives or unresolved states.

### CF-11 — Silent external change
The source changes during exploration and the field returns the member to a different state without acknowledging the delta.

### CF-12 — Over-continuity / identity captivity
The system preserves a prior identity, meaning, or state after the member or source has legitimately changed.

### CF-13 — Enhancement dependency
Continuity only works when animation, color, audio, haptics, or advanced rendering is available.

### CF-14 — Cross-surface fracture
The same source loses identity or orientation when moving between Living Field, Grokker, Writer, MAIA, Relationships, or another room.

### CF-15 — Return-story injection
The system explains what the journey “meant” merely because the member returned.

## Governing falsifier

> **A return is not truthful if it preserves orientation by falsifying current state, or preserves current state by destroying recognizable identity and context.**

## Design target

> **recognizable identity + current truth + inspectable change + no imposed narration**
