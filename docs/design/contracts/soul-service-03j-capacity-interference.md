## Purpose

03J tests whether a valid two-capacity chord can become less useful when held simultaneously, without turning that moment into:

- a compatibility score;
- a deficit claim;
- an automatic simplification;
- a fixed preference about how the member thinks.

## Synthetic chord

The witness begins with:

> **Compare versions + Change scale**

Both are legitimate capacities.

The member can then report:

- Clear together
- Tension present
- Unsure

## Tension path

When the member reports tension, Soullab offers:

- Keep both
- Release Compare versions
- Release Change scale
- Use one at a time
- Dissolve support

No option is ranked.

No option is automatically selected.

## Sequence-instead path

If the member chooses:

> **Use one at a time**

the same two capacities remain available as a sequence.

This is attentional rearrangement, not progression.

## Keep-both path

The member may report tension and still choose:

> **Keep both**

Tension does not invalidate the composition.

## Unsure path

Unsure remains lawful.

The member may:

- keep observing;
- simplify;
- leave support altogether.

## Acceptance questions

1. Can the member report tension without being diagnosed?
2. Does the system avoid compatibility scoring?
3. Can the member keep both despite tension?
4. Can either capacity be released independently?
5. Can the pair become sequential without “Step 1 / Step 2” hierarchy?
6. Does Unsure remain first-class?
7. Does no-support remain available?
8. Does the system avoid using behavioral telemetry as overload evidence?
9. Does a tension report remain encounter-local?
10. Does simplification feel like an attentional choice rather than failure?
