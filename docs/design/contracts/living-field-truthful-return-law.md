# LIVING-FIELD-TRUTHFUL-RETURN-LAW-01

**Date:** 29 September 2026
**Status:** governing local integration law
**Runtime authority:** only within explicitly authorized local witness candidates

> **Continuity preserves identity, not sameness.**

Return is a truth-bearing act.

When the field returns a member to something previously encountered, it implicitly makes claims about:

- what is the same;
- what changed;
- what still has standing;
- what was only temporary;
- what is no longer current.

Therefore return must preserve orientation **without falsifying change**.

## Governing law

> **Return must restore the same locus while reconciling with current source truth. It may not silently rewind a changed source, silently replace identity, or promote temporary interpretation into durable meaning.**

## Two opposite continuity failures

### Under-continuity

Too little continuity causes disorientation.

Examples:

- the source appears as a different object;
- the member returns to a default field instead of where they left;
- spatial neighborhood is lost;
- scroll/focus is lost;
- the system forgets which source was entered.

### Over-continuity

Too much continuity causes captivity.

Examples:

- stale content is restored because it was visible before entry;
- an old interpretation is privileged over current source truth;
- a prior identity is preserved after the member explicitly revised it;
- rejected frames remain attached in the name of continuity;
- the system resists legitimate transformation.

> **Continuity fails when recognition is purchased by denying change.**

## Truthful delta

When a source materially changes while the member is deeper in the field, return should preserve:

- the same stable identity;
- the same spatial locus;
- the same surrounding field orientation;

while making the fact of change legible.

The system may show:

> **Updated while you were inside**

and, when useful:

> **Before → Now**

It may not infer:

- why the change happened;
- what the change means psychologically;
- whether the change is progress;
- whether the new state is more authentic.

## Delta law

> ## LIVING-FIELD-RETURN-DELTA-LAW-01
>
> **A material source change that occurs during an exploration must be allowed to update the returned field. Where the difference would otherwise create confusion, the field should make the delta inspectable without narrating its meaning.**

## Identity versus state

The field must distinguish:

### Identity
What makes this the same work, person, question, relation, or source locus.

### State
What is currently true about it.

Identity may remain stable while state changes.

A truthful return can therefore say:

> **same presence · changed source**

without saying:

> **same meaning**

## Delta scope

02R2 recognizes only explicit source-level changes available in the current local component state.

It does not authorize:

- historical reconstruction;
- causal inference;
- semantic-diff scoring;
- psychological significance scoring;
- durable change-memory.

## Acceptance sentence

> **I can recognize where I returned, see what changed, and trust that the system did not decide what the change means.**
