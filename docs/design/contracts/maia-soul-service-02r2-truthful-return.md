## Purpose

02R2 tests the question:

> **What happens when the source legitimately changes while the member is deeper in the Living Field?**

The target movement is:

> **enter source A → source legitimately changes to B → return to the same identity → current truth B is shown → delta is inspectable → no meaning is narrated**

## Governing laws

- `LIVING-FIELD-RETURN-CONTINUITY-LAW-01`
- `LIVING-FIELD-TRUTHFUL-RETURN-LAW-01`
- `LIVING-FIELD-RETURN-DELTA-LAW-01`
- `LIVING-FIELD-CONTINUITY-FAILURE-MATRIX-01`

## Continuity tension

02R2 explicitly tests two opposite failures:

### Under-continuity

The member cannot recognize where they returned.

### Over-continuity

The system restores stale state or prior meaning because it is trying too hard to preserve sameness.

The target is:

> **recognizable identity + current truth + inspectable change + no imposed narration**

## Local witness

The witness uses one synthetic source identity:

> **Current Question**

State A:

> “I keep asking whether to refine this further or let it enter the world.”

State B:

> “I want to release this version and keep learning from what happens next.”

The source ID remains unchanged.

The updated timestamp changes to a later factual time, so the presence may also move to the field's current recency position.

This is intentional.

02R2 tests whether View Transition continuity can preserve identity through a truth-driven topological move.

## Delta behavior

On return, if source-level material changed, the field may show:

> **Updated while you were inside**

with:

> **Before → Now**

The delta does not infer:

- why the source changed;
- whether the change is progress;
- whether the member is more ready;
- whether the new state is more authentic.

## Locality

Return delta exists only in component-local state.

It clears on the next presence entry.

No durable change memory is created.

4. Does the delta avoid narrating meaning?

6. Does the field preserve widened / quiet mode?
7. Does focus return to the same source opener, wherever it now lives?
8. Does viewport continuity remain coherent?
9. Does reopening the source clear the temporary delta?
10. Does a temporary MAIA aperture remain cleared?
11. Does reduced-motion remain semantically equivalent?
12. Does continuity feel alive rather than frozen?
