# Soul Portrait — Offer a complete gift

## What this room is for

Someone entrusted to hold a portrait reviews the finished work and offers an unlisted link only after explicitly recording the adult subject's agreement. A recipient can read the completed portrait without creating a Soullab account. Sharing is an act by a person, not automated marketing.

## Arrival and gestures

The panel's title names a private gift rather than a campaign or invoice. Its first irreversible gesture requires an explicit attestation that the intended adult has agreed to receive it.

| Gesture | Human-facing language | Boundary |
|---|---|---|
| Attest agreement | The recipient knows this portrait was prepared and has agreed to receive it | Required before first private-link publication |
| Publish a consented portrait | Create private link | Authenticated owner only; no recipient address, message or outbound provider call |
| Carry the completed gift | Copy link | Manual choice by the sender; no automatic email |
| Withdraw consent | Through the governing recipient consent process | The public recipient read checks live consent on each request; revocation hides the portrait |

## House and room distinction

Shared with Soullab: generosity without a funnel, member-authored significance, and consent as a real crossing. Particular to this room: an unlisted, recipient-readable portrait that remains complete if the recipient never engages with the platform again.

## Evidence limits and exclusions

The displayed checkbox and disabled button were witnessed in **static component HTML**, not through browser hydration. The 18-case actual-HTTP fixture separately proved consent record, publication, revocation, re-attestation and owner-session refusal using fabricated records. Some denied anonymous reader pages rendered non-disclosing Not Found HTML with HTTP 200 because of Next.js streaming; that status behavior still requires technical review.

No email sender, no live recipient identity, no new gift credits, no purchase invitation, no client record permission, no minors' guardian pathway, no new member registration and no additional MAIA authority are approved by this contract.
