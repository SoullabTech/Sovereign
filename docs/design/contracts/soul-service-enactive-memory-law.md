# SOUL-SERVICE-ENACTIVE-MEMORY-LAW-01

**Date:** 30 September 2026
**Status:** governing memory-design law
**Persistence authority:** none by this document

> **Not every action loop deserves to become autobiographical memory.**

An enactive loop contains many possible memory candidates:

- source question;
- member-authored action;
- expectation;
- disconfirmation criterion;
- reported consequence;
- direct evidence;
- revised interpretation;
- member-kept learning;
- unfinished uncertainty.

These do not all have equal durability.

## 1. Durability classes

### Durable by existing source standing

Examples:

- a manuscript change already persisted in Writer;
- a sent message already exists in an authorized source;
- an explicit decision already has durable standing.

Soul-Service does not duplicate them merely to remember the loop.

### Durable only by explicit member keep

Potential examples:

- “I want to remember what this taught me.”
- “Keep this experiment.”
- “Return to this if the pattern appears again.”
- member-authored revised synthesis.

The system must know what exactly is being kept.

### Reconstruct fresh

- what this experiment means now;
- current relevance;
- whether the lesson still applies;
- current confidence;
- what to do next.

### Do not persist by default

- model suggestion;
- temporary aperture;
- unconfirmed causal interpretation;
- transient fear/salience;
- system score;
- “success rate” of the person;
- behavioral compliance score.

## 2. No behavior dossier

> ## SOUL-SERVICE-NO-BEHAVIOR-DOSSIER-LAW-01
>
> **Enactive learning must not silently accumulate a behavioral dossier in which experiments and outcomes become traits, compliance metrics, or predictions about the member.**

Examples of prohibited silent promotion:

> “They usually avoid hard conversations.”

> “They follow through 62% of the time.”

> “This user responds well to confrontation.”

unless a completely separate, explicitly consented research or product purpose governs such measurement—and even then it must not become autobiographical truth.

## 3. Failed experiments

A failed, abandoned, or inconclusive experiment must not become stigma.

It may remain history only under appropriate source/member standing.

## 4. Member-kept learning

If the member chooses to preserve learning, store the member-authored formulation separately from:

- raw consequence;
- MAIA synthesis;
- system hypothesis.

## 5. Longitudinal aging

A kept learning can later be revisited.

It should not automatically become a permanent rule.

> **What was learned then may itself become revisable evidence later.**

## Acceptance sentence

> **The system can learn with me without turning my life into a behavioral profile.**
