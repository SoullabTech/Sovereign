## Two attention modes

### Open encounter — default

Before returned evidence is captured:

> **What happened?**

The exact provisional pattern is deliberately absent from the rendered encounter.

Browser witness:

> **pattern absent before capture = PASS**

This prevents the system from leading the next report merely because a pattern already exists.

### Deliberate pattern test

The member may explicitly choose:

> **Deliberate pattern test**

Only then is the provisional proposition shown in advance.

The test exposes, before observation:

- what would support it;
- what would count against it;
- what could be outside scope;
- an instruction to record anything else that materially affects comprehension.

Pattern influence on attention is therefore visible rather than hidden.

### Contradiction

Returned report:

> “The core idea was clear and the chapter transitions were easy to follow.”

Governed relationship:

> **Contradicts this proposition**

It is not softened into hidden support.

### Support

Returned report:

> “The core idea was clear, but I lost the thread at the transition into the final section.”

Governed relationship:

> **Supports this proposition**

But the system explicitly says:

> **Do not promote the pattern automatically; re-evaluate maturity with all evidence.**

Support joins the evidence field.

It does not become automatic stronger standing.

### Insufficient

Returned report:

> “I liked the chapter.”

Governed relationship:

> **Insufficient to compare**

The system states:

> **Do not update the proposition from this event.**

It does not invent missing evidentiary content.
