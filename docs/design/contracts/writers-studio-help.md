# Writer Studio Help — Experience Contract

## Activity and arrival

The writer opens **Help with Writer’s Studio** when a control or next step is unclear. The writing remains mounted and visible behind a temporary sheet. Closing the sheet returns keyboard focus and preserves the working place. Help is not another permanent column and does not replace the editorial conversation.

## Gestures

| Gesture | Member language | Result |
| --- | --- | --- |
| Open | Help | Opens guidance without commissioning a reading. |
| Ask | Ask MAIA about Studio | Known questions use the maintained guide; unfamiliar questions may request an approved-topic match through the governed service. |
| Browse | Topics / Quick start | Available without a successful model request. |
| Read | Illustrated handbook PDF / Quick-start PDF | Authenticated pilot-only access to separately supplied private review assets. |
| Return | Close / Escape | Returns to the same writing, without an edit or save. |

## Boundaries

No manuscript text, identifiers, source documents or editorial history are automatically included in a Help request. Help cannot execute an edit, Save, Apply, Undo, deletion or privacy change. The selected guide topic is not evidence that an action already happened. Unsupported or unavailable state remains explicit. No general conversational command capability is promised.

The instruction sheet uses shared atmosphere variables and ordinary language. Numbered help steps, optional illustrations and named next controls serve a specific question rather than a required feature tour. Enlarged text uses one scrollable sheet so header/footer furniture cannot consume the answer space. A narrow screen receives a reachable Help entry instead of an off-screen toolbar control.

## Reference and acceptance standing

The screenshots are actual browser captures of a disposable test Work. They contain synthetic text only; the author’s illustrated review PDFs are deliberately excluded from this public repository. The record establishes rendered and machine-checked behavior, not founder aesthetic approval or a fresh writer’s independent usability acceptance. Those checks remain required before the final pilot activation.
