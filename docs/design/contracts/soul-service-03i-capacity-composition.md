## Purpose

03I tests whether two human capacities can be held together as a temporary cognitive chord without becoming:

- a workflow;
- a member profile;
- a model-ranked prescription;
- a permanent tool configuration.

## Working together

A chord does not merge its capacities.

For example:

### Compare versions
> What changed between the earlier and current source?

### Look for counterevidence
> What would complicate or limit the current view?

Held together, these questions coexist.

The system does not synthesize them into a new doctrine.

## Reshape

The member may replace one capacity while keeping the other.

No “next step” or upgrade language is used.

## Release

The member may:

- release one capacity;
- keep the other;
- dissolve all support.

## Naming

The member may optionally name the temporary chord.

This name remains member-authored and local to the witness.

## Acceptance questions

1. Can the member see both capacities separately inside the composition?
2. Does the chord feel like concurrent support rather than a workflow?
3. Can either capacity be released independently?
4. Can the composition be reshaped without implying progression?
5. Can the member dissolve the chord completely?
6. Is no support still first-class?
7. Are MAIA-offered pairs bounded and explicitly non-ranked?
8. Can the member reject all MAIA offers?
9. Does optional member naming remain visibly theirs?
10. Does the composition avoid becoming a trait or persistent cognitive style?
