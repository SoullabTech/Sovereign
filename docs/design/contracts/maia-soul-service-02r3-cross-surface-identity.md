## Purpose

02R3 tests whether one governed living object can move across multiple Soullab surfaces without becoming multiple semantic copies.

Witness object:

> **work:elemental-alchemy**

Surfaces:

- Living Field;
- Grokker;
- Writer's Studio;
- MAIA.

## Governing law

> **A living object has one governed identity across Soullab. Each surface receives a projection of that identity, not a new copy of the thing.**

## Surface affordances

### Living Field

Situates the work in lived context.

### Grokker

Shows relational / spatial structure.

### Writer's Studio

May mutate source text where explicitly authorized.

### MAIA

Provides dialogical / perspectival participation without becoming the object's source authority.

## Identity witness

The same stable identity must remain:

`work:elemental-alchemy`

through all surface transitions.

The View Transition identity is likewise stable across projections.

## Source mutation witness

Writer's Studio may advance:

> `ea:v1 → ea:v2`

The living-object identity remains unchanged.

The active Return Envelope still remembers the source version witnessed at departure:

> `ea:v1`

so return can reconcile current truth and expose change.

## MAIA-local state

A temporary MAIA aperture belongs only to the MAIA projection during the active traversal.

It must not become:

- living-object identity;
- source text;
- a Grokker relation;
- a durable Living Field property.

Returning clears it.

## Return Envelope

02R3 carries a local ephemeral Return Envelope containing:

- livingObjectId;
- sourceVersionWitnessed;
- originSurface;
- originLocus;
- originView;
- focusTarget;
- member-chosen movementIntent;
- openedAt;
- returnPolicy.

It carries no interpretation or hidden importance.

## Truthful return

On return:

1. same living object is recognized;
2. current source truth is shown;
3. source-version delta is exposed if changed;
4. temporary MAIA state is cleared;
5. Return Envelope is cleared.

## Acceptance questions

1. Does Elemental Alchemy feel like one thing across all rooms?
2. Does each room add affordance rather than identity?
3. Can Writer mutate source without forking identity?
4. Does Grokker relation-space remain a projection rather than an ontology owner?
5. Does MAIA's temporary lens remain temporary?
6. Does the Return Envelope preserve enough orientation without carrying a narrative?
7. Does return show v2 rather than restoring v1?
8. Is v1 → v2 inspectable?
9. Is the envelope cleared after return?
10. Does View Transition continuity support sameness of identity without freezing state?
