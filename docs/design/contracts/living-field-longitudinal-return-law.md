# LIVING-FIELD-LONGITUDINAL-RETURN-LAW-01
## Return across days, weeks, months, and changing life

**Date:** 29 September 2026
**Status:** governing architecture law
**Runtime authority:** none

> **Longitudinal return restores relationship and orientation to a living object without pretending the member, the object, or the surrounding world is still where it was.**

Longitudinal return is not simply a durable version of browser Back.

Time itself is new evidence.

## Governing sentence

> **Reorient before resuming.**

A system should not automatically say:

> “Let's continue where you left off.”

It should first establish:

- what is the same;
- what changed;
- what is current;
- what the member deliberately kept;
- what matters now.

## Preservation classes

### Class A — Must preserve

Subject to ordinary retention / consent rules:

- stable living-object identity;
- source lineage;
- provenance;
- authorship;
- source versions;
- durable member-authored content;
- confirmed relations;
- durable decisions / commitments where already governed;
- privacy / consent standing.

These make truthful recognition possible.

### Class B — Preserve only when the member intentionally keeps it

Examples:

- “return here” marker;
- explicit next step;
- saved question;
- chosen working set;
- member-authored synthesis;
- chosen lens;
- explicit unfinished intention.

The system may offer these on return because the member gave them standing.

### Class C — Reconstruct fresh

Do not treat these as durable truth:

- current salience;
- current relevance;
- best next action;
- field ordering;
- suggested perspective;
- recommended pathway;
- MAIA synthesis;
- “what matters most.”

These must be recomputed from the present encounter and current source truth.

### Class D — Do not persist by default

- hover;
- scroll;
- temporary zoom;
- temporary MAIA frame;
- rejected hypothesis;
- unconfirmed relation;
- incidental comparison;
- transient emotional inference;
- model confidence.

## Longitudinal re-entry grammar

A strong re-entry sequence is:

> **Recognize → Reconcile → Reveal change → Restore what was deliberately kept → Ask the present → Move**

### Recognize

> “This is the same Elemental Alchemy work.”

### Reconcile

Establish current source truth.

### Reveal change

Where useful:

> “Since your last visit, these source-level things changed.”

No developmental story is inferred.

### Restore what was deliberately kept

Examples:

> “You marked this passage to return to.”

or:

> “You left this question open.”

### Ask the present

> **What is your relationship to this now?**

or a less verbal equivalent.

Do not assume the prior task remains the current task.

### Move

Offer present-tense affordances:

- resume;
- revisit;
- inspect change;
- widen;
- let rest;
- ask MAIA;
- act elsewhere.

## Resume versus revisit

Longitudinal return must distinguish:

### Resume

The member explicitly wants to continue the prior work.

### Revisit

The member wants to see the prior state without assuming continuation.

### Reorient

The member needs to understand where the object and wider field stand now.

### Let rest

No further movement is required.

## Aging law

> ## LONGITUDINAL-CONTEXT-AGING-LAW-01
>
> **The longer the interval since an encounter, the less temporary encounter state should be treated as current without renewed member confirmation.**

Time weakens the authority of:

- old salience;
- old task urgency;
- old MAIA suggestions;
- old inferred context.

Time does not weaken:

- source provenance;
- historical authorship;
- factual lineage.

## Surprise requirement

Longitudinal return inherits the Temporal Relational Memory requirement:

> **A mature long-horizon system must remain capable of being surprised by the person it knows well.**

Therefore a return after months must not simply reload the prior interpretation.

The present member gets first evidentiary standing.

## Source-change posture

If source or world state changed while the member was away:

> current truth first.

Then:

> inspectable history if useful.

Never:

> stale continuity for familiarity.

## Member-change posture

Even if the source did not change, the member may have.

Longitudinal return must not assume:

> same source = same meaning.

## No-momentum law

> ## LONGITUDINAL-RETURN-NO-MOMENTUM-LAW-01
>
> **A prior unfinished action must not automatically regain urgency merely because it was unfinished.**

“Unfinished” is historical fact.

“Still important” is a present question.

## Acceptance sentence

> **I can return after time has passed, recognize where I am, see what changed, and choose anew what this means or asks of me now.**
