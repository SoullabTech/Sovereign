## 🔴🔴 Critical correction

⛔ **Do not design Author Studio as a manuscript editor with supporting features.**

The manuscript editor is **one instrument** inside a larger creative environment.

⭐⭐⭐ **The centre of gravity is the creator's evolving body of work.**

- **Writer Canvas** — the environment where ideas become works.
- **Editing Canvas** — one tool inside it, used when the creator enters the *writing* stage.

⛔ **Do not confuse the writing instrument with the author's workspace.**

⚠️ **The standing risk this document exists to prevent:** an engineer sees *"writing"* and
immediately builds a better editor. ⭐ **The editor is one room in the house.**

---

## Core experience principle

> ⭐⭐⭐ **A writer does not begin with a manuscript. A writer begins with material.**

```
Capture → Gather → Discover → Shape → Write → Refine → Release
```

The transformation the system must support:

```
Life + Experience → Ideas → Fragments → Connections → Structure → Writing → Published Work
```

---

## Inputs exist before writing

A creator may begin with: **ideas · journal entries · uploaded documents · existing manuscripts ·
images · quotes · research · notes · voice recordings · conversations · fragments · observations ·
questions · unfinished passages.**

⛔ **These are not "attachments."** ⭐⭐⭐ **They are the raw materials of creation.**

---

## The design test

> ⛔ *"Where do I type?"* → **we built a form.**
> ✅ *"I can work here."* → **we built a studio.**

## Architecture model — build around the Work, not the Document

```
                      WORK
                       |
      -----------------------------------
      |                |                |
   Sources           Ideas         Reflections
      |                |                |
  Gatherings         Themes      Conversations
                       |
                   Structure
                       |
                 Editing Canvas
                       |
                     Draft
                       |
                    Release
```

⭐⭐⭐ **The manuscript is an expression of the work. The work is not a container for a manuscript.**

---

## UI / UX requirements

**Centre — the creator's work.** ⛔ Not empty text boxes, forms, or fields. It must feel like a
professional creative workspace.

| **LEFT — Context** | **CENTRE — Creation** | **RIGHT — Intelligence** |
|---|---|---|
| *What am I creating?* | *Where does the work happen?* | *How am I thinking with this?* |
| current work · sources · materials · structure · related pieces | writing · composition · manuscript editing · creative development | reflection · connections · questions · noticing patterns · organizing thoughts |

> ⭐⭐⭐ **MAIA remains beside the writing, never inside it. The author remains the author.**

---

## ⛔ Anti-patterns

Do not create: a blank document with a title · a survey-style writing box · a chatbot pretending to
be the writer · a dashboard of writing metrics · progress bars · completion scores · AI-generated
direction replacing authorship.

## Success criteria

A creator opening Author Studio should immediately feel:

1. **My work has a home.**
2. **My materials belong together.**
3. **I can continue from where I left off.**
4. **I can move from inspiration to expression.**
5. **This supports my voice rather than replacing it.**

> ⭐⭐⭐ **The goal: build the environment where a creator's work becomes possible.**
