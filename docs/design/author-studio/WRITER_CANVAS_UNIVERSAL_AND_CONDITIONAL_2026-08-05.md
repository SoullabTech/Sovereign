> the Step 2 persona walk (`WRITER_CANVAS_PERSONA_WALK_2026-08-05.md`) —
> this is what the walk *proved*, not what the hypothesis assumed. The

## Universal — present for every creator, always

These are the room. Removing any of them breaks a persona.

| Universal element | Where it lives | Walk evidence |
|---|---|---|
| The work, named by its becoming (in the member's words) | Head of the room | All five needed to know "what am I working on" without asking |
| The creative field with one instrument in hand | Worktable (center) | All five worked *somewhere*; none needed two instruments at once |
| Materials that feed the work + bring-to-table | Study Wall · Materials | Novelist (research notes), scholar (sources), elder (forty years) |
| History with preserved versions + "keep a version" gesture | Study Wall · History | Novelist (before cutting), collaborator (attribution), elder (originals) |
| Arrival-as-continuation (room opens at the last gesture) | Room behavior | The return test: every persona resumes, none re-orients |
| Orientation phrase from authored acts only, member-renamable | With the work's name | All five oriented; none scored |
| The Window — invited reflection, never authorship | Right edge, folded | All five could invite; none was intruded upon |
| Expression model (a work can declare new becomings) | Header switcher when >1 | Blogger's series; elder's book-and-course; mode fluidity itself |

## Conditional — instruments that appear only when the work makes them real

Each has an **appearance condition** that is a member-authored fact,
never a system inference. Absence is a correct state, not a gap.

| Conditional instrument | Appears when… | Disappears when… |
|---|---|---|
| Structure drawer / pinnable rail (chapters, sections, series) | The member declares structure or imports a structured manuscript (A2) | The work has no structure |
| Renewal surface (original preserved beside new expression) | The member enters with "returning to an existing manuscript" (A1) | The work is new or continuing |
| Citation instrument + generated bibliography | Materials carry citation metadata (member-added or ingest-found) (A5) | No citable materials |
| Collaboration presence + offered/adopted grammar + roles | The member invites someone (A4) | The work is solitary — zero trace |
| Expression switcher | The work has more than one expression (A3) | Single-expression work |
| Publishing / share workflow | The member marks an expression ready to share | Nothing declared ready |
| Bulk gathering arrival | The member arrives with material and a loosely named work (A6) | — (an arrival shape, not a persistent surface) |

## Changes from the brief's starting hypotheses

1. **"Drafts/versions" moved from universal shelf to History + worktable**
   — the persistent bottom strip was deleted (warehouse grammar); no
   persona missed it.
2. **"Revision tools" split**: keeping a version is *universal* (a
   gesture); comparison/renewal views are *conditional*.
3. **Expression switching added to universal** (the brief did not list
   it) — it is the mechanism of mode fluidity, and mode fluidity is a
   governing principle, not an option.
4. **Collaboration controls sharpened into a grammar** (offered/adopted,
   consistent with the platform's existing Corpus Callosum ruling: only
   the author adopts) rather than "controls."

## The two failure modes, checked

- **Too generic?** No — the conditional instruments are deep where they
  appear: real chapters, real citations, real renewal, real attribution.
  The blank-editor failure is avoided because the room always opens onto
  *the member's actual work mid-motion*, never onto emptiness.
- **Too fragmented?** No — every persona's strain resolved *inside* the
  same three-zone room as a conditional instrument. Zero separate apps,
  zero forked products, one environment learned once.

**Same studio. Different instruments.** — validated, not assumed.
