## The failure is architectural, not a copy defect

> "The Studio is asking you to understand its architecture before it lets you continue your
> work."

The page simultaneously attempts to be an onboarding screen, a project dashboard, a document
importer, a source library, and a doorway to MAIA — different moments in the journey flattened
onto one surface, so every element competes with every other.

## Structural findings recorded by the founder

1. **Every top card duplicates something beneath it.** "Begin something new" duplicates the New
   project tile; "Bring something in" duplicates the lower panel. The top row is not navigation
   — it is a second set of labels for content already on the page.
2. ⭐ **"Your Work" does not contain the writer's work — the hierarchy is reversed.** Only "New
   project" appears there, while the actual works (*Your writing*, *Second Book*, *Elemental
   Alchemy*, *Elemental Alchemy KDP print*) appear under "Bring Something In". That tells the
   writer their manuscripts are imported files rather than living works. **Correct
   relationship: a Work CONTAINS drafts, source documents, notes, recordings, quotations.**
3. **"Continue your work" has no referent.** A continuation action must name the work and the
   place: *"Continue Elemental Alchemy — return to Chapter 7, where you left off yesterday."*
   Generic continuation is a command without an object.
4. **"Bring something in" collapses five different actions**: new work from manuscript · add
   material to an existing work · attach note or quotation · import image or recording · upload
   reference edition. Import must always answer: into **which** work, or create a new work from
   it? **Nothing enters an unowned document warehouse.**
5. **The Document tile looks like a filter tab, not an upload control** — no choose-file, no
   drag-drop, no destination, no status, no confirmation.
6. **`NOT YET` tiles reduce trust.** Unavailable capabilities should be hidden, not catalogued.
7. **"Open" and "Source" expose machinery.** Source vs Working Draft matters, but belongs
   *inside* the work — not as a technical fork under every home-screen item.
8. **"Reflection with MAIA" sits globally upper-right**, making MAIA a destination competing
   with writing. MAIA belongs beside the current work, deliberately invoked.

## Governing interaction rule

> "A button named for an outcome must perform that outcome."

Continue opens the work. Import opens import. New work begins a work. **Scrolling to another
section is navigation and must be represented as navigation, not as completion of the act.**

This subsumes and strengthens the door rule recorded at `898d42d8e`.

## The redesign principle

> "Writer's Studio is the place where a writer re-enters a living work. It is not an onboarding
> menu, document manager, or import tray. The Work is primary. Everything else is an instrument
> used in relation to the Work."

> "Stop organizing the Studio around what the system can ingest. Organize it around what the
> writer is making."

The home must answer three questions immediately: **What am I making? Where did I leave off?
What is the clearest next movement?**
