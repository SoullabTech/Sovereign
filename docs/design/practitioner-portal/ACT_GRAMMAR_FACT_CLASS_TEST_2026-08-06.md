# The Act Grammar Under the Fact-Class Test

**Status: CANDIDATE — analysis only.** ⛔ No schema, no code. Applies the founder's discriminator
(2026-08-06) to the ruled act grammar.

**The earlier question** — *is Offering a sixth act, or is Placement direction-agnostic?* — was the
wrong shape. The founder's replacement is prior to it:

> ⭐⭐⭐ **Acts create facts.** So the discriminator is not direction, and not authorship:
> **does this authored occurrence create a different class of durable relational fact?**
> If yes, it is a distinct act. If no, it is a modality.

⭐ The test's value is that it **discriminates in both directions** — it does not merely multiply
acts. §3 shows it correctly *refusing* to promote two candidates.

> ⚠️ **This is one of two independent gates, not the admissibility test** (founder, 2026-08-06). See
> §0 — a candidate must pass **both**, and ⛔ the fact-class test must never be used to refuse
> something it does not actually refuse.

---

## 0. Two independent gates

| | Gate 1 — **Fact class** | Gate 2 — **Constitutional admissibility** |
|---|---|---|
| Asks | does this create a genuinely distinct relational fact? | even if it does, is this a fact the relationship is **permitted to preserve**? |
| Kind | ontological | constitutional |
| Outcome | distinct act · or modality | admitted · or refused |

A candidate enters the grammar only by passing **both**. ⭐ They are independent: neither implies the
other, and ⛔ **passing gate 1 confers no claim on gate 2.**

### ⭐ The worked case: `viewed`

`viewed` **passes gate 1.** It is a genuinely distinct occurrence, and it is not a modality of
anything — no other fact in the grammar records it. Refusing it as *"not a distinct fact class"*
would be **false**, and a future engineer could correctly rebut it, at which point the refusal
collapses.

`viewed` **fails gate 2**, and that is the true ground: preserving it would make the relationship a
surveillance record. It is refused by the constitutional model, ⛔ not by the ontology.

> ⭐⭐⭐ **Refuse on the true ground.** A refusal argued on the wrong gate is a laundering risk — it
> survives only as long as nobody checks the argument.

### What governs gate 2

Drawn from what already binds, ⛔ not invented here:

1. **Standing** — does the author have standing to author a fact about *this subject*? (a
   practitioner-authored developmental claim about a member is refused however genuine)
2. **No aggregation** (**N7**) and **no norm from frequency** (**N8**) — a fact whose content is a
   count, ratio, or comparison across persons.
3. **Declared, never derived** — no fact inferred from behaviour, timing, or recurrence.
4. ⭐ **Relational necessity** — does preserving it serve the commitment, or only serve *observation
   of a person*? This is what kills `viewed`.
5. **Erasability** — a fact about private material that cannot be erased cannot be admitted.

⚠️ The deliberate absences in the Event Specification §4 — `viewed`, `opened`, `downloaded`,
`overdue`, `reminded` — are **gate-2 refusals**. Several of them would pass gate 1. That is the
correct reading of the vocabulary, and this section corrects an earlier framing that let them read
as ontological.

## 1. The fact classes

Working from what each act leaves behind, not from who performed it:

| Class | The durable fact | Truth-value |
|---|---|---|
| **Dispositive** | an existing authored object is now available within a commitment | asserted |
| **Constitutive** | ⭐ an object that did not exist now exists as a relational artifact | asserted |
| **Stance** | a party's declared relationship to something already inside the commitment | asserted by that party |
| **Testimonial** | one party asserts having witnessed another party's speech | ⭐ **deliberately undetermined** |
| **Revocatory** | a prior fact's forward force ends, without the prior fact ceasing to be true | asserted |
| **Conferring** | a candidate acquires constitutional force | asserted |

## 2. The grammar, tested

### 2.1 Offering vs Placement → ⭐ **different classes. Sixth act confirmed.**

The discriminator is not direction. It is what each leaves behind:

- **Placement is dispositive.** The Work already existed and remains wholly the practitioner's. What
  becomes true is an availability relation to an object that was already there.
- **Offering is constitutive.** ⭐ The migration says so in its own words: *"That act does not hand
  over the source, and it does not duplicate it into a second truth. **It creates a THIRD thing**: a
  member-authored relationship artifact with its own lifecycle."*

> ⭐ **Placement creates a relation to an existing object. Offering creates a new object.** Those are
> different classes of durable fact, so Offering is a distinct act — and it would be a distinct act
> even if a practitioner performed it.

⭐ This also explains why the founder's asymmetry list is not incidental. Opaque lineage, ciphertext
without a plaintext sibling, and different withdrawal semantics are not privacy decoration on a
shared shape — ⛔ they are what a **constitutive** fact about private material requires. A shared
table with a `direction` column would carry one lifecycle for two fact classes and erase exactly the
distinctions the object exists to hold.

### 2.2 Offering vs Uptake → different classes, confirming the founder's read

- **Offering** introduces something that was not in the commitment.
- **Uptake** changes the member's stance toward something already inside it.

⛔ Not interchangeable, and not orderable: an Offering has no prior object to take up, and an Uptake
introduces nothing.

### 2.3 Attestation → ⭐ the test independently confirms the earlier ruling

Attestation is the **only** act in the grammar whose fact has a **deliberately undetermined
truth-value**. The system records *that P claims to have heard M say X* while asserting nothing about
whether M said it. Every other act asserts its fact outright.

⭐ **It is the only fact the system records without asserting.** That is a class of its own — and it
is reached here without appeal to the earlier independence argument, which is now a second,
concordant reason rather than the only one.

### 2.4 Ratification → conferring; distinct, uncontroversial

The only act that changes what other acts are permitted to do.

## 3. ⭐ Where the test refuses to promote

The test is only worth using if it can say no.

**`set_down` is not an act.** It creates the same class of fact as `taken_up` — a stance fact,
opposite polarity, same author, same lifecycle, same erasure semantics. ✅ Correctly a **modality of
Uptake**.

**`work_revised` is not an act distinct from `work_authored`.** Both are constitutive of a version
of the practitioner's own object; neither touches a commitment. ✅ Modalities of Ratification's
authoring family. ⭐ Consistent with **N10** — revision proves change, nothing more.

## 4. ⚠️ Where the test produces a candidate amendment

Applying the test honestly to the **ruled** grammar surfaces one tension. ⛔ Recorded, not asserted —
this is the founder's test returning a result about the founder's ruling.

**Withdrawal was ruled as one act with "relevant party" as author.** Under the fact-class test it
looks like **two**:

| | Practitioner withdrawal | Member visibility withdrawal |
|---|---|---|
| What ends | forward availability of **one's own** authored object | **another party's** access to one's own field |
| Class | revocatory over one's own disposition | ⭐ revocation of a **grant made to someone else** |
| Who is affected | no one's access is removed — prior placements stand | the other party loses access |
| Rendering | `{title} is no longer available to place` | `{party} withdrew access` — fact only |

⭐ **Independent convergence, again:** the Permissions document reached the same split from the
authority side (*"withdrawn is two relationships with different owners"*) before the fact-class test
existed. Two routes, one conclusion.

**And a genuine edge the test does not settle:** `attestation_confirmed` is the only occurrence that
**converts one fact class into another** — a testimonial fact with an undetermined truth-value
becomes a stance fact asserted by the member. ⚠️ Whether *conversion* is its own class or a stance
fact that happens to reference a testimonial one is not resolved by the test as stated. ⛔ Left open.
