# 1. Flagship North Star

> **Writer's Studio should feel like exploring a living world that happens to be your book.**

Success means the member can:

```text
recognize the Work
→ act without expert vocabulary
→ discover something real
→ follow it through the Work
→ return to an exact passage
→ talk with MAIA there
→ safely try a possibility
→ preserve or restore the original
→ keep exploring
```

# 7. R3 — Intent-First Entry

## Objective
Remove the requirement that the writer diagnose their own writing problem.

## Front door
> **What are you trying to understand?**

Primary human-language entries:
- Something feels off
- Help me see the shape
- I'm losing the thread
- This doesn't sound like me
- I'm not sure what this chapter is doing
- Show me what keeps appearing
- I want to go deeper here
- I'm worried I'm repeating myself
- I don't know — help me look

## Required laws
- intent is not a commission;
- MAIA names proposed reading scope;
- writer agrees / narrows / cancels;
- no silent lens expansion;
- Guided / Learning / Direct remain authority-invariant.

## Owner
Design: HERE  
Implementation: CC

## Exit evidence
- state flow;
- existing-evidence path;
- new-reading permission path;
- insufficient-coverage path;
- "I don't know" path;
- refusal/falsifier suite.

# 14. R10 — Flagship Remediation

Every beta issue is classified:

## BLOCKING
Core loop impossible or trust boundary violated.

## MAJOR
Success requires coaching/confusion/repeated recovery.

## FRICTION
Member succeeds but hesitates or misreads.

## POLISH
No material agency/comprehension impact.

These grades apply to **product defects**, never to the Work.

## Owner
HERE rules priorities  
CC implements bounded fixes
