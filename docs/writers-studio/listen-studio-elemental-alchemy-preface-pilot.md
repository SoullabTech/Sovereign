# Soullab Press · Listen Studio · Preface Pilot

**Status:** Local, isolated founder-review candidate. Not deployed or release-ready.

## Available
- Access: `/dev/writers-studio-pc3-live?mode=listen&m=<real-manuscript-id>`.
- Reads existing authenticated, section-addressable manuscript context. Prefers heading “Preface”; no fabricated text or anonymous work identity.
- Read-only manuscript; microphone selection; browser recording; playback; raw file download or discard; separately downloadable performance notes.
- Temporary session-only recordings. **Nothing is uploaded or persisted. Download raw takes before navigating away.**
- Existing Develop, Write, Review, MAIA, Craftsman’s Table and production routes untouched.

## Gates before public release
1. Confirm source section/passage identity and version/hash, including multi-section Preface continuity.
2. Consent to recording, cloud transfer, AI enhancement and cloning must be separate explicit choices.
3. Durable authenticated raw recording storage, crash-safe writes, orphan recovery, deletion, authorization, and old/new app compatibility.
4. Non-destructive audio history: compare original/processed audio, explicit apply/undo; protect meaningful breath and silence.
5. Descript handoff only after approval; uploads must obey existing Sanctuary source-write hold.
6. MAIA Craftsman’s Table presents playable audio alternatives, no automatic manuscript edits.
7. Audiobook export mastering QA: decoded audible duration, completeness, silence, loudness/peaks, per-chapter source match. Never count AI scratch placeholders as actual sound.
8. Multi-device/responsive browser proof and owner acceptance before deployment.

## Founder test
Open a real manuscript with its `m` parameter; use `mode=listen`. Select Preface or a specific passage, choose microphone, record one minute, play, download, and reload to confirm no retained take. Confirm manuscript unchanged. Review downloaded original in Descript separately.

The current pilot is **not** a WAV mastering pipeline, a Descript recording integration, or a finished audiobook player. Browser capture may use WebM/Opus or MP4, depending on browser.
