# Jondi Corpus Inventory — "The Jondi Archive Project"

**Status:** Phase 0 / Track B working document. **No build authorization required or implied.** This is corpus formation — gathering and permissioning Jondi's *existing* materials. It can proceed entirely independent of any decision to build the Jondi Companion (see `JONDI_COMPANION_CANDIDATE_2026-07-21.md` §8, §13).
**Started:** 2026-07-21
**Discipline:** *Collect, don't create.* Every wisdom line and EFT sequence recorded here must be **sourced from real Jondi material** — never invented, paraphrased-as-hers, or AI-generated. If it isn't traceable to a source row below, it does not go in.

---

## How to use this document

1. **Inventory** every source into the table (§2), one row per discrete source.
2. **Permission** each row: 🟢 Green (clear to use) / 🟡 Yellow (must ask) / 🔴 Red (cannot use). Nothing moves to curation until it is 🟢.
3. **Prioritize** by the permission × value tiers (§1).
4. **Curate** only 🟢 material into the candidate sections (§4–§5), always with a source reference.

**Consent note (load-bearing):** a group or client recording contains *other people's* voices and words. Consent to curate it is **not Jondi's alone to give** — it requires the participants' consent too. Those rows stay 🔴/🟡 until that is explicit.
