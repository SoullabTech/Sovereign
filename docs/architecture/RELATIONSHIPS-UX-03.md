# RELATIONSHIPS-UX-03 — Relational Environment Rebuild
**Status:** Threshold rebuild candidate
**Scope:** Relationships landing environment only; data/API/runtime semantics preserved
## Why this exists
Two visual witnesses showed that incremental styling could not solve the core problem.
The previous surface retained the old composition:
- header over a list,
- stacked rectangular relationship rows,
- system-generated holding material inside the same hierarchy,
- low-emphasis relational language,
- a visual grammar inherited from records/dashboard UI.
Changing palette and contrast did not change the felt experience because the underlying composition still represented relationships as records.
UX-03 therefore treats the existing landing presentation as replaceable and preserves only the underlying relationship data and actions.
## Design thesis
A relational-intelligence platform should let the member encounter **presence before representation**.
The Relationships threshold should feel like a room one enters, not a table one manages.
## Threshold architecture
### Relational room
The page is composed as a living environment with:
- warm mineral daylight,
- subtle connective lines,
- generous breathing space,
- a central relational question,
- a visible invitation to bring someone closer.
### Presences, not rows
Existing relationships are presented in a responsive relational field rather than a vertical record list.
Each presence carries:
- name,
- orientation/bond,
- one living relational sentence,
- a restrained identity marker,
- a clear gesture to enter the relationship.
### System at the edge
The auto-generated `Unresolved Relational Field` remains technically available but is not allowed to lead the human field.
It is represented only as peripheral `Unplaced threads`.
### Readability
The threshold uses:
- warm light ground,
- dark readable ink,
- medium-weight primary typography,
- no black-on-dark copy,
- no hairline green body text.
## Non-effects
This rebuild does not change:
- `/api/relationships`,
- relationship schema,
- relationship records,
- relational observer behavior,
- memory or voice authority,
- MAIA seeding,
- consent,
- `Now / Story / Field`,
- the relationship detail runtime.
## Sequencing law
**Do not propagate this visual language deeper until the rebuilt threshold passes founder visual witness.**
The threshold is the calibration surface. Once it feels warm, elegant, relational, and inviting, the same grammar may be carried into the relationship room, progressive arrival, and contained MAIA encounter.
## Acceptance
The threshold passes only if it no longer reads as:
- a dashboard,
- a CRM,
- a dark ledger,
- a warmed-up version of the previous page.
It should instead feel like:
> a quiet, beautiful place where the people and presences in one's life can be brought close.
