# 20. Planned obsolescence levels

These describe scaffold state, not member rank.

## S0 — Full support
MAIA names and structures the capacity.

## S1 — Guided participation
MAIA asks; member performs.

## S2 — Light cue
One optional prompt or visual affordance.

## S3 — Self-initiated
Member invokes the capacity.

## S4 — Independent
Member performs without MAIA.

## S5 — Generative transfer
Member adapts the capacity to a novel context or teaches it to another person.

A scaffold may fade when repeated evidence suggests S3–S5 independent use.

It may return when requested.

No capacity is assumed permanently mastered.

---

# 21. Fading protocol

When independent use is demonstrated:

1. reduce repeated explanatory prompts;
2. preserve optional access;
3. shift from automatic suggestion to member initiation;
4. test unassisted transfer;
5. do not interpret reduced MAIA use as disengagement failure;
6. restore scaffold if member requests or context changes.

The system should become quieter before it becomes absent.

# 23. Real-world consequence witness

For selected voluntary studies:

1. member describes a real situation;
2. member identifies the capacity used;
3. member records what they did;
4. later records what happened;
5. compares expectation and consequence;
6. revises understanding if needed.

The system must not reinterpret every outcome as successful growth.

A failed experiment is evidence too.
