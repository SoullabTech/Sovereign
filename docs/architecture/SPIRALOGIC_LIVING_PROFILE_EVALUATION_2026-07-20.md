## 3. The salvage — direction of authorship per layer

Each layer survives if its author changes:

- **Constitution** → the deterministic registration spine (chart → distribution, dominance behind the one C-fence rule, may return `none`). System may render this because it is a rendering of symbolic relationships, not a verdict. **Already the gated 5-step sequence, step 1 complete.**
- **Season** → member-declared, never system-detected. "What season am I in?" is a legitimate ephemeral invitation (asking, wondering — constitutional speech acts); a stored season assigned by the system is not.
- **Field State** → stays frozen. If it ever surfaces, it surfaces as the member's own marked moments and atoms (provenance-grounded), never as inferred elemental weather.
- **Developmental Invitation** → the Five Questions ("What comes naturally? What do I overuse? What do I avoid? What season? What is trying to emerge?") are the constitutional kernel of the whole proposal — **as member-answered inquiry**, they are Encounter→Reflection respecting upward authority. As system pronouncements they are the drift. Keep the questions; refuse the answers.
- **Emergent** → never a system output. If something is emerging, the member names it or it remains unnamed. "The right to remain unpossessed."

## 5. Second pass (same day) — refinements accepted, one trap caught

The follow-up round converged on §2–§3 and offered three refinements. Disposition:

**5a. "Assessment Logic vs Journey Logic" — accepted as candidate vocabulary.**
`System → Person` (determines and delivers) vs `Person ↔ MAIA` (discovers and witnesses). This is a compact naming of what canon already holds distributively (constitutional sentence + speech-act grammar + Direction of Authority). Useful as teaching vocabulary; adds no new constraint. Candidate for the essay, not for canon (canon already has the load-bearing forms).

**5b. Constitutional layer "held lightly" — accepted, with a precision.**
"You have described yourself as someone who often leads with vision" is **quoting-the-member** — already a legitimate speech act (provenance-grounded, member's own words). But this does not *replace* the chart layer; canon holds both, on opposite sides of the constitutional sentence:
- *"Your chart's registration distributes as Fire → Air → Water"* = rendering of symbolic relationships — legitimate (this is what the deterministic spine is for).
- *"You are constitutionally Fire-Air"* = ontological claim about the person — never.
The word "constitutionally" applied to a *person* is exactly where rendering becomes verdict. The Constitution layer survives as **chart-rendering + member-self-description with provenance**, never as system ontology about the person.

**5c. THE TRAP — the proposed "Living Questions" output smuggles the frozen inference back in.**
The sample output was:
> *Questions presently alive: • Where does vision exceed container? • What qualities are asking for development? • What have you been neglecting?*

Each of these **presupposes the assertion it replaced**. "Where does vision exceed container?" presupposes vision exceeds container — that is the Cat 5 frozen field-state inference wearing a question mark. This is precisely the presupposition rule already on record (Living Field label ruling refinement): *a question can smuggle a stored assertion via presupposition — test the presupposition, not just the illocutionary form.* An interrogative surface is not automatically Journey Logic.

Two clean forms exist:
1. **Universal question set** — the Five Questions verbatim, identical for every member ("hospitality anticipates situations, never people"). No selection = no inference. The "if any" construction carries the constitutional weight: *"Which, if any, feels true for you?"*
2. **Member-authored questions** — the member's own alive questions, held with provenance.

What is NOT clean: a per-member *selected or personalized* question list. Choosing which questions to surface is itself an assertion of salience — softer than a verdict, but still system authorship of what is alive in the person. If personalization ever enters, it enters by the standing consent pattern (member-pulled, like atoms/anchors), not by default.

**5d. Naming.** "Spiralogic Inquiry Profile" / "Living Questions" both candidates. Note collisions before any mint: "Living Field," "Living Inquiry" (AIN Institute — sealed), the Companion's "living questions" chapter. Naming goes to a sitting, per standing discipline.

**Net ruling unchanged:** the profile is the member's answers. The system holds the questions — unselected, unpresupposing — and the rooms.

## 6. Third pass — the selection principle, scoped; the taxonomy, refused

**6a. "Question selection is itself a speech act" — accepted, but it MUST be scope-limited or it breaks live conversation.**

Stated bare ("a selected question carries the same constitutional weight as an assertion"), the principle would prohibit MAIA from asking anything responsive in conversation — every conversational question is selected. Canon already protects responsive asking: *conversation is ephemeral — an invitation, not stored* (the Living Field label ruling's jurisdictional line was **ephemeral vs stored**, not selected vs universal). And communicative attunement *requires* reading the live encounter and choosing what to ask.

The correct form of the principle:

> **Selection becomes assertion when it persists.**
> Ephemeral selection (live conversation) = attunement — governed by the speech-act and presupposition tests, read from the live encounter, never from a stored profile.
> Stored or ambient selection (a profile surface, a recurring prompt, an unbidden nudge, a "questions presently alive" panel) = an inference surface — it asserts salience on every return, and therefore requires member standing consent.

**This principle is already operational, which is its strongest evidence.** The Daily Anchor consent gate is exactly it: system-chosen *surfacing* of an anchor was moved behind `surface_preference` member opt-in (default `member_pulled`). Same shape: atoms `return_preference`, Portrait lens member-pulled-only, Themes/Reflections HOLD+EXPLAIN. The platform has been enforcing "stored selection needs consent" for months without having named it. That is the generative test passing — the principle compresses existing architecture rather than adding to it.

**6b. The "system may / may not author" taxonomy — do NOT mint it as a new principle.**

The proposed table (may author: rooms, questions, symbolic renderings, provenance, continuity, invitations-to-revisit / may not: identity claims, diagnoses, verdicts, inference-implying selections, emergence declarations, becoming labels) is **the existing sovereignty table restated in authorship vocabulary**. Canon already holds: *platform MAY configure relationships · participation · jurisdiction · context · communication · permissions; may NEVER configure identity · personhood · meaning · consciousness · worth* — generalized as *"configure ecologies, never configure beings."*

Kelly's standing directive (2026-07-08) applies verbatim: **stop adding principles; run the generative test.** The test passes — the existing small set explains this table — so the right move is reconciliation, not mint. If the authorship register proves useful, it is a *teaching restatement* of the sovereignty table (essay material), not a new constitutional object. One correction to the "may author" column regardless: provenance and continuity are may-author **only under the consent architecture** — they are capability-gated, not unconditional.

**6c. Universality carrying constitutional weight — accepted, and it has a name.**

*"What is trying to emerge?"* is clean; *"What leadership quality is trying to emerge?"* is an assertion — correct, and this is **"hospitality anticipates situations, never people"** applied to inquiry. A universal question anticipates a situation (being human, being in transition); a narrowed question anticipates a person. No new principle needed; the hospitality rule already governs it.

**6d. Ruling sentence — hold the current formulation.**

"The system holds questions, not answers" is quotable but loses both load-bearing qualifiers (*unselected, unpresupposing*) — and after 6a, "unselected" must be read as *unselected-in-persistence*, not "MAIA never chooses what to ask." Standing formulation, unchanged, awaiting Kelly:

> *The profile is the member's answers; the system holds the questions — unselected, unpresupposing — and the rooms.*

**Status:** §6a ("selection becomes assertion when it persists") is the single genuinely new candidate from this exchange — a refinement of the presupposition rule, with the anchor gate as live precedent. Everything else reconciles into existing canon. Awaiting Kelly's read; nothing here authorizes build or canon changes.
