## The thesis

> **Authority accrues only through actual contact.**

Both halves of governance were circling this without naming it:

- **Protective (negative) governance** — the Constitution — *forbids authority without contact*: don't overclaim, don't collapse layers, don't manufacture higher-order meaning from below, don't confuse observation with interpretation.
- **Developmental (positive) governance** — the Ecology — *cultivates the capacity for contact*: how discernment matures, how understanding is revised through contact with reality, how judgment becomes trustworthy over time.

One forbids counterfeit authority; the other grows the real thing. They are two halves because each is the thesis applied in a different mode — prohibition and cultivation — which is why neither can substitute for the other.

## One invariant, enforced twice

The same law already operates on two substrates, independently arrived at:

**The direction of travel is free below the line of authority; the line itself moves in one direction only, through contact.**

| | Member register | System register |
|---|---|---|
| Free travel below the line | Encounter ⇅ Reflection ⇅ Recognition — the member loops at will | build ⇅ test ⇅ redesign — the session loops at will |
| The line, one-directional | Invariant 16: Encounter → Reflection → Recognition → Living Field → Developmental Ecology; no layer skipped, no meaning manufactured | The six-state ladder: direction → spec → built → wired → surfacing → live; *declaration ≠ liveness, built ≠ wired ≠ surfacing ≠ verified* |
| Contact that moves the line | Authored experience — the member's own act | Witnessed production evidence — the machine's own behavior |
| Inflation drift (refused) | Synthesizing a Recognition for the member | Calling Cat 3 live |
| Inverse drift (refused) | A member's declared recognition going unheld | Cat 6 substrate going unnamed |

Same law, same drift-pair, both drifts refused in both registers. By the house's own elevation test — cross-domain, independently arrived at — the underlying principle is canon-grade *as candidate*, awaiting its sitting.

## The Mirror Invariant as fixed point

Both registers share one root prohibition:

> **The party holding the mirror may not sign for the party doing the living.**

Member side: MAIA may never manufacture Recognition — the member declares, MAIA reflects. System side: a session may never manufacture verification — the machine witnesses, the session records. Announce-never-mutate, evidence-never-meaning, findings-bind-to-ref, the probe-induction rule — each is this one prohibition applied at some layer. If the canon ever wants a root node, this is it.

## Held direction (Cat 1) — self-retiring governance

The maturation arc (orientation → capacity → autonomy → seasonal return — *the member needing the system less*) currently has **no engineering mirror**. Its analog would be governance designed to be needed less over time: instruments retiring checks they have made unnecessary; gates dissolving where a tripwire made the bypass structurally impossible; discipline graduating rule → structure → *no longer needing enforcement*.

First observed instances (2026-07-10): the retag hazard cannot recur once the rollback pile can't rebuild, so its check retires; the deploy-lane tripwire (#583) makes the lane-discipline reminders moot on arming.

**Held as Cat 1** — a preserved direction, not authorized work. No gate walked.

## Jurisdiction (scoping required before adoption)

*Added 2026-07-10 evening (Kelly) — the root node needs its jurisdiction stated, or it collides with the floor above it.*

Drafted broadly — *"the platform holds only what the sovereign party placed"* — the thesis is **false**: the constitutional runtime itself holds behavior nobody placed per-relationship (the invariants, the Authority Floor), and holds it precisely *so it can't be displaced*. The accurate scope is one level down: **interpretive and administrative claims about a person or a body of work** may exist only by that party's placement. The narrow-only nesting rule is already the resolution — **the floor sits above the thesis's jurisdiction, and the thesis governs everything below it.** An unscoped root ruling would eventually be cited against the floor, a worse seam than the divergent-precedent problem the convergence flag prevents.

*Evidence note:* the three instances in the record only ever attested the narrow form — none shows the platform holding *nothing*; each shows it declining to hold an interpretive or administrative claim it didn't receive from the sovereign party. The broad draft would have been unsupported by its own evidence, independent of the floor collision.

*For the sitting, when it takes Question 4 (not a fifth question — the fourth answers it for free):* **self-application survived is a ratification signal.** This thesis was scoped *by* the thesis — authority claimed only to the reach of contact earned. If the adoption text records that, the boundary is constitutive rather than a fence of caution: amending it away would visibly break the principle it belongs to. A candidate root that holds when run against its own candidacy is categorically different from one that can't be tested that way or fails when it is.
