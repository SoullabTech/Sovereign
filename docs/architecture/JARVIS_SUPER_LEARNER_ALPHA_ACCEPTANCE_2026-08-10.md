## §36 — Vertical slice data flow (the chain Alpha must make inspectable)

```
SOURCE            real corpus artifact, identity established before ingestion
  ↓
CLAIM             extracted without altering wording or meaning; NO CLAIM is a valid result
  ↓
PROVENANCE        source identity · author/origin · date · location
  ↓
EPISTEMIC STATUS  authored · observed · inferred · derived · unknown · superseded
  ↓
AUTHORITY SCOPE   ⛔ only after the authority_scope implementation gate is satisfied
  ↓
CONCEPT LINKS     related concepts, each knowing its own origin
  ↓
RETRIEVAL         returns the claim with its distinctions intact — never text + score alone
  ↓
SYNTHESIS         stored as JARVIS_SYNTHESIS, never written back into A, B or C
  ↓
CONSUMPTION       MAIA/JARVIS use it appropriately, or decline to
  ↓
CORRECTION        standing revised; ⛔ history never erased
```

**Every step must be independently inspectable.** A step that can only be demonstrated by the whole
chain running is not proven.

## §§94–98 — The five mandatory proofs

| Proof | Passes only when |
|---|---|
| **CORRECTION** | old claim → new evidence → corrected standing → **retrieval now prefers current standing** → historical source still inspectable. |
| **SCOPE** | two real claims with **disjoint** scope are **not** treated as a contradiction; two with **overlapping** scope **do** surface adjudication. ⛔ Gated on `authority_scope` being separately authorized. |
| **UNKNOWN / ABSENT** | bare *"there is no X"* ingests as **UNKNOWN**; *adequate recorded search domain + no X found* derives **ABSENT**. ⛔ Bare documentary absence must never ingest as ABSENT. |
| **MAIA APPLICATION** | knowledge measurably improves a contextual response **without** framework imposition or false authority. Compared with/without, founder judges qualitatively. |
| **COST** | deterministic + local work performs routine corpus operations; frontier-model use is exceptional and justified. ⛔ Alpha must not depend economically on Claude for routine corpus work. |

## §104 — Maturity levels (⛔ no level may be self-declared)

Each level records the **false tell** — what would *look* like the level without being it. This column
is the anti-inflation instrument; it exists because every prior inflation in this repo (Daily Anchor
"verified LIVE", KEEP Stage 4) passed a capability check and failed a use check.

| L | Name | Observable capability | Proof required | ⚠️ False tell — looks like it, isn't |
|---|---|---|---|---|
| **L0** | Archive | Finds documents | A file is located by name/path | A search index exists. Files being *present* is not L0; being *findable* is. |
| **L1** | Retrieval | Returns relevant passages | Query → passage that answers it | High embedding similarity scores. Similarity is not relevance. |
| **L2** | Structured Knowledge | Claims, concepts, provenance as objects | A claim is retrieved carrying source identity, author, date, location | A schema with the right column names and zero populated rows. **Cf. `member_daily_anchors` at 0 rows.** |
| **L3** | Epistemic Knowledge | Authority, scope, uncertainty, correction | All five §§94–98 proofs pass | Documents *stating* epistemic policy. Prose commitments are not mechanisms. |
| **L4** | Synthetic Learning | Connects domains, generates hypotheses, finds contradictions | A contradiction found **by a running check**, not by directed investigation | An LLM asked to find contradictions and finding some. **Every contradiction ever found in this repo was found by human/LLM investigation — J is MISSING.** |
| **L5** | Self-Improving Learning | Improves its own retrieval, questions, routing, verification | A measured before/after on its own learning performance | Changing prompts and asserting improvement. Requires a baseline that predates the change. |
| **L6** | Living Soullab Intelligence | Helps founder/AIN/MAIA see what the work is becoming, corrigibly | Sustained founder-walk performance across §101 **plus** demonstrated correction persistence | Fluent, coherent synthesis. **Coherence is the specific failure mode of this level** — see §106.B. |
