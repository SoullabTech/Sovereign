## ⚠️ Scope limit on the absence claim

A rendered surface can establish:

> *"I did not observe a practitioner control."*

It **cannot** establish:

> *"No practitioner capability exists."*

⛔ Those require a different instrument — route inventory · authorization checks · API inspection ·
payload analysis. The admissible wording is:

```
Rendered member surface:     no practitioner controls observed
Payload/API authorization:   requires separate verification
```

⚠️ This bears on the **G2/G6** privacy observation, which must not be upgraded from *rendered
absence* to *capability absence* on this evidence.
