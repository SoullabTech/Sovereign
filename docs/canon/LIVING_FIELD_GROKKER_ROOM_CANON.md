## Governing proposition

> **Grokker is a Soullab room that has become spatial. It is not a separate product, a knowledge-graph dashboard, or a visual spectacle with meaning attached afterward.**

The Living Field remains the experiential center.

The surrounding shell exists to:
- preserve orientation;
- illuminate meaning;
- enable lawful movement across scale;
- provide routes into MAIA and evidence;
- connect the room to the wider Soullab House.

Semantic depth governs all visual and interaction decisions.

## SEMANTIC-PRIMACY-COMPOSITION-LAW-01

> **The visual composition is authority for layout, atmosphere, and interaction character. It is not ontology authority.**

Every visual implication must be classifiable as:
- semantically grounded;
- atmospheric;
- ambiguous and therefore ineligible for production meaning;
- semantically false and therefore removed.

Beautiful nesting does not create containment.
Glow does not create importance.
A decorative filament does not create relation.
Spatial nearness does not create evidence.

## CONTEXT-PATH-NOT-LINEAGE-LAW-01

> **Context path answers where I am. Lineage answers how this became.**

`CONTEXT_PATH` / `CONTAINMENT_PATH` and `LINEAGE` are separate semantic objects and separate UI apertures.

The top orientation surface may show current context.
The right Illuminator owns a distinct **How this became** aperture.
Until lineage is actually bound, the aperture must remain explicitly unbound rather than synthesizing history from current containment.

## CONTAINMENT-RELATION-DISCRIMINATION-LAW-01

> **The interface must distinguish what is inside a field from what is related to it.**

`Within this field` contains only true contained children.

Relations, near fields, resonances, tensions, supports, and other noncontainment links remain outside the membrane even when they are visually close.

`Enter field` appears only when an actual inhabitable child ecology exists.

## OPTICAL-ZOOM-SEMANTIC-SCALE-LAW-01

> **Optical magnification and semantic traversal may feel continuous while remaining formally distinct.**

Optical zoom:
- changes camera magnification;
- changes no semantic state.

Semantic scale:
- changes current context / aperture;
- requires a settled threshold-crossing gesture.

Raw wheel or pinch input may approach a semantic membrane.
It must not immediately trigger semantic traversal from a single noisy gesture.

R2D3 therefore uses a dead zone + accumulated outward intent + time window before semantic widening.
Explicit **Wider** remains a fallback.
**Whole** restores minimum sufficient containing context, not all Soullab data.

## SEMANTIC-ATMOSPHERIC-DISCRIMINATION-LAW-01
