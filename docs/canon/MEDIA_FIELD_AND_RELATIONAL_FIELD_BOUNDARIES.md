# Media Field and Relational Field Boundaries

**What the public-signal organism may do, and what it must never become.**

## Status

Canon — DRAFT. Articulated 2026-05-23, in dialogue. Written before the media engine exists, so that the engine is born under this document rather than retrofitted to it. Sibling to [The Clearing](./THE_CLEARING.md) and [MAIA Sovereignty Invariants](./MAIA_SOVEREIGNTY_INVARIANTS.md). Where this document conflicts with media-engine optimization logic, this document carries.

Kelly's hand remains on this draft. Seams visible.

## The recognition

The media engine and the sovereign companion operate under overlapping but distinct ethical terrains. They share a parent canon (The Clearing) but answer to different gravitational dynamics.

The deepest insight from which this document follows:

> *The scoring function itself shapes the organism.*

A system that scores for virality bends — over time, unintentionally, structurally — toward outrage, stimulation, compulsive novelty, identity reinforcement, emotional extraction. Even if the surface language remains spiritual. Even if the operators intend otherwise.

The architecture is downstream of the metric. The metric is therefore canon-bearing.

## Two domains, not one substrate

| Domain | Operates under | Gravitational dynamic |
| --- | --- | --- |
| Public Knowledge Field | publishing, discourse, cultural participation, discoverability | reach, signal, contact |
| Relational Memory Field | continuity, companionship, member-presence | sovereignty, restraint, becoming |
| Canonical Doctrine Layer | governing principles | answerable to The Clearing |
| Research / Observation Layer | pattern analysis | observational, non-extractive |

These cannot fully collapse into one substrate. If merged too early:

- media incentives bleed inward
- companion logic bends outward
- canon contamination becomes likely

Soullab Media is a distinct public-discourse surface with its own pacing, boundaries, and governance. Whether it lives inside MAIA-SOVEREIGN or as a sibling repository is an implementation decision; the boundary is ethical and architectural before it is infrastructural.

## Attention ethics — what the media system may optimize for

**Permitted:**

- symbolic density
- philosophical tension
- emotional authenticity
- archetypal coherence
- meaningful contact
- signal clarity

**Refused:**

- virality probability
- session length via emotional bonding
- A/B testing for felt intimacy
- compulsive novelty
- identity reinforcement loops
- audience dependency

The output of the signal layer is not *"how do we hijack attention?"* — it is *"where is meaningful contact needed?"*

## Resonance vs virality — explicit doctrinal distinction

Virality optimizes spread.
Resonance optimizes meaningful contact.

These are not identical. They are not synonyms with different aesthetics. They are different ontologies producing different organisms.

The engine is therefore not a Virality Engine. It is a **Resonance Observatory**.

What it observes:

- where collective tension is emerging
- where symbolic pressure is building
- where meaning systems are destabilizing
- where relational hunger is appearing
- where civilization is metabolizing contradiction
- where coherence is breaking down
- where deep questions are surfacing

Not *"what will explode?"* — *"where is meaningful contact needed?"*

## Media-to-MAIA boundaries

The media organism must not become the companion substrate.

MAIA may:

- reference public work
- understand authored philosophy
- navigate symbolic frameworks the user knows from public material

MAIA must not:

- shape relational memory around publication identity
- let audience metrics influence companion tone
- treat the member as an instance of the public reader
- import publishing priorities into reflective intelligence

**Relational memory remains member-centered, not publication-centered.**

Otherwise the companion becomes ideological, performative, identity-projective, subtly extractive.

Direction of permitted flow:

- MAIA → public field: only what the member authors and chooses to publish (member-sovereign)
- Public field → MAIA: reference only (member's own published work as known context, not as authority shaping interpretation)
- Analytics → MAIA: **never**

## Drift risks

Named so they can be watched:

- performative spirituality
- ideological reinforcement
- attention capture
- audience dependency
- identity hardening
- synthetic authority inflation
- mythopoetic compression of the member into the brand
- the founder voice becoming a substitute for the member's own becoming

When any of these appear, the engine has drifted. Return here.

## Canonical design constraints

Rules the media engine is built under:

- sovereignty preserved (the public reader is also a sovereign center; the field does not flatten them)
- continuity protected (the member's relational substrate is never shaped by audience metrics)
- relational integrity (no parasocial optimization)
- experiential immediacy (the work points outward into lived life, not inward into the system)
- interpretive humility (the engine observes; it does not pronounce)
- non-substitutability honored (readers, like members, are not reducible to behavioral profiles)

## What follows

From this canon follows the discipline of first contact:

- The first contact loop is built smallest.
- It is observational, interpretive-light, canon-aligned.
- It does not include: publishing automation, virality scoring, autonomous content flooding.

The smallest coherent step is enough. The boundary must hold under load before more is built.
