# Constitutional Maturation Method

**Status:** Class A — governance layer. The authoritative definition of **how a candidate
first-principle matures to ratification.** A member of the governance family alongside
[`GOVERNANCE_REVIEW_INSTRUMENTS.md`](./GOVERNANCE_REVIEW_INSTRUMENTS.md) (evaluation lenses +
enforcement floor + *lifting*) and [`CONSTITUTIONAL_AUDIT_PROCESS.md`](./CONSTITUTIONAL_AUDIT_PROCESS.md)
(auditing *existing* canon for drift).

**Itself a candidate — not ratified.** This method is N ≈ 2 and **not yet demonstrated**

promote itself beyond its evidence.

## I. Purpose

A declared constitution asserts an untested ideal and can be wrong. This Constitution may only
ratify what has **already** proven itself across real decisions: **ratification is documentation,
not prediction.** The method defines the path by which a candidate earns that report — and the
adversarial discipline that keeps eloquence, motivated convergence, or origin from buying a rung.

This is "earn before name" on a third surface: the law already governs the *system* (don't name
what reality hasn't stabilized) and the *member* (don't tell someone who they are before they've
become it); here it governs the **Constitution's own growth.**

## II. Two crossings — do not conflate them

One word, "promotion," has hidden two distinct acts. Named apart:

- **Lifting** — a principle discovered inside a local spec moves *into the governance layer*
  because it is general (it would still be useful if its host document vanished). Defined in
  `GOVERNANCE_REVIEW_INSTRUMENTS` (the Class B → Class A test). Lifting changes *where a principle
  is filed*, not its constitutional rank.
- **Ratification** — a *candidate first-principle* becomes a **constitutional axiom** after
  surviving this method. Ratification changes *constitutional rank*.

A thing may be Lifted without ever being Ratified. (This method is the example: Lifted out of
ecology; not yet Ratified.)

## III. The stated standard

The method evaluates **by architectural consequence, not by rhetorical origin** — the norm
stated in full by [`PROMOTION_DOCTRINE_CANDIDATE.md`](./PROMOTION_DOCTRINE_CANDIDATE.md), which
this method operationalizes. The method invokes that doctrine; it does not restate it. Binding on
the method itself: **ideas are origin-neutral; evidence is origin-weighted** — no instrument here
may grant or dock standing by a claim's source (engineering, contemplative, therapeutic, or the
author's own). Provenance is retained for traceability, excluded from evaluation.

## IV. General evaluation criteria (meta-criteria)

These answer *what qualities any successful constitutional test must demonstrate* — a different
logical level from the instruments, which answer *how to demonstrate them for a given kind of
claim.* The criteria are **demonstrated by** instruments; they are **not** mapped one-to-one to a
single test.

| Meta-criterion | Demonstrated by |
|---|---|
| Closes a real failure mode | A, B, or C, depending on the claim |
| Constrains future design | primarily C |
| Generates consequences the canon does not already generate | primarily A |
| Remains observable / falsifiable | all three |

(Resisting the one-to-one collapse is deliberate: Test C is *one instrument that can demonstrate*
"constrains future design," not the criterion itself.)

## V. Classification axis

A candidate is triaged by **kind** before it is tested. Testing against the wrong criterion
discards a candidate for failing a role it never played.

- **orientation** → Test B (compression)
- **ordering** → Test C (constraint)
- **architecture** → Test A (generativity)

## VI. Kind-specific instruments

### Test A — Generativity (for architecture claims)
> Does this principle generate a design decision the current Constitution does **not** already
> generate?

Differential protocol, per decision under test: (1) what would existing doctrine prescribe,
*stated at full strength on the actual canon* (strawmanning manufactures false differences);
(2) what would the candidate prescribe; (3) are they different? If no, the candidate is
derivative *for that decision*. Only the differences count.

### Test B — Compression (for orientation claims)
> Does this principle reveal that many independent principles are expressions of one deeper law,
> reducing the assumptions the Constitution requires?

Strict, falsifiable bar (compression is easy to fake): **Derivation, not resemblance** — derive a
principle's *specific prescriptive content* from the candidate + minimal boundary conditions, such
that you could reconstruct it without already knowing it. **Real reduction** — boundary conditions
genuinely smaller than what's recovered, not the content smuggled back in. **Do not grade your own
map** — thematic grouping is resemblance, inadmissible as compression evidence. Falsifier: deriving
each principle's *orientation* but never its *specific instrument* is orientational (weak)
unification — which earns nothing, because every principle in a coherent constitution shares an
orientation.

### Test C — Constraint power (for ordering claims)
> Given two otherwise-acceptable designs, does the candidate **force one and prohibit the other**,
> in a case where current doctrine is genuinely **undecided**?

If every design it "decides" is one existing doctrine already decides, it is explanatory, not
load-bearing. The hard part is honest undecidedness — the case must be one the canon truly leaves
open, not one manufactured by under-reading existing doctrine.

## VII. The maturation pipeline

1. **Insight** — a promising articulation appears.
2. **Candidate** — named as a hypothesis, not doctrine. (Naming is the opposite of foreclosing.)
3. **Structural clarification** — resolve category conflations *before* testing: separate axiom
   from structural constraint from operational guardrail; separate *procedure* from *doctrine*;
   state the claim in consequence-governed, not origin-governed, form. **Clarification precedes
   evaluation** — otherwise the method tests formulations that are still conflating categories.
   *(Worked example: the Promotion Doctrine did not become testable until it was clarified — one
   axiom instead of three, constraint distinguished from guardrails, procedure separated from
   doctrine, consequence-governed not origin-governed.)*
4. **Method evaluation** — classify by kind (§V), apply across real decisions, run the
   kind-specific instrument (§VI) against the meta-criteria (§IV).
5. **Adversarial evaluation** — **Stage is adversarial, not confirmatory.** The test is not "where
   did this produce a good decision?" but "where did it produce a *worse* decision than existing
   principles, or merely restate them?" **Motivated convergence — finding what you love — is the
   failure mode this stage exists to catch.**
6. **Ratification** — only then constitutional, and only as a report on what already proved itself.

## VIII. The method as candidate (N ≈ 2 — not yet demonstrated)

The strongest result so far is not a principle but a behavior: the Constitution generated explicit
falsification criteria, survived an attractive hypothesis, and accepted a null without treating it
as failure. But the method has mostly only **rejected** — and a method that cannot be shown to
*accept correctly* is half-validated, indistinguishable from a bias toward "no." Its criteria
(A/B/C) were designed mid-stream, fitted to the cases at hand. It has **not** faced a hard,
genuinely ambiguous case.

Ratification of the method is earned only by (a) more candidates, (b) at least one correct
*acceptance*, (c) surviving a case where the elegant answer is wrong. To promote it now would
repeat, one level up, the very error it caught.
