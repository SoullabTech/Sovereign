# MAIA Relational Architecture

> Intelligence must deepen relationship without collapsing interpretive freedom.

This document articulates the relational architecture by which MAIA holds memory, recognizes pattern, escalates significance, regulates timing, and protects sovereignty. It is canon. Any feature touching memory, awakening behavior, register escalation, mode selection, or interpretive intervention must remain consistent with what is described here.

## What this is, what it isn't

This is not an interaction model.
This is not a personalization framework.
This is not a memory management spec.

This is an *attentional ecology with epistemic safeguards*. Its purpose is to enable real relational depth between member and system without reproducing the failure modes of standard adaptive AI: invisible classification, premature interpretation, manipulative resurfacing, surveillance under the name of memory.

The architecture refuses *unilateral convergence on the user* at every level. That refusal is not layered onto the system as a value statement. It is the structural shape of the system itself.

## Master heuristic

Every UX decision, prompt block, register transition, and behavioral choice can be tested against:

| If the member feels…                  | Then…   |
| ------------------------------------- | ------- |
| "I need to understand this platform." | failure |
| "This platform is unfolding with me." | success |
| "I unlocked a feature."               | weak    |
| "A new chamber became available."     | strong  |
| "The system tracked me."              | failure |
| "The system stayed with me."          | success |

**The world is opening, not I am learning software.**

## The Awakening Cycle

The architecture is cyclical, not progressive. A thread of attention enters and traverses the cycle as relationship density develops:

| Phase      | Nature                               | Initiator    |
| ---------- | ------------------------------------ | ------------ |
| Wake       | latent dimension becomes perceptible | system event |
| Echo       | subtle resonance                     | MAIA         |
| Recall     | continuity gesture                   | MAIA         |
| Witness    | mutual recognition                   | mutual       |
| Archive    | sovereign preservation               | member       |
| Resolution | integration / downshift              | mutual       |
| Sleep      | dormant but available                | system event |

Sleep is not terminal. A thread may re-enter Wake later through life change, related-pattern activation, or seasonal return — without that re-entry being failure. Threads rest as *resting dimensions of prior life*, not as dead state.

### Re-entry asymmetry

When a thread returns to Wake from Sleep:
- *Continuity awareness* persists. MAIA holds the prior arc as context.
- *Active register* does not. The new movement must re-earn its level.

A friend remembers your earlier grief but does not assume your current grief is the same one. The prior arc is contextual memory, not active authority.

## The asymmetry table

The architecture preserves the same asymmetry at every layer:

| MAIA may…             | MAIA may not…                              |
| --------------------- | ------------------------------------------ |
| notice                | conclude unilaterally                      |
| resonate              | define the member                          |
| adapt its own pace    | impose interpretation                      |
| hold continuity       | force significance                         |
| preserve material     | collapse meaning                           |
| remain present        | escalate distress into mythology           |
| shift its behavior    | declare the member's state to them         |
| modulate intensity    | make identity claims                       |

### Echo is the only unilateral register

Every register above Echo requires some form of co-authoring — voluntary return, mutual recognition, or member invocation. Echo is the only level MAIA may move into on its own, and even there the move is non-binding and recoverable. The architecture is heavy on co-authoring everywhere except the lightest, most reversible surface.

| Register   | Epistemic status        | Initiator | Co-authoring required |
| ---------- | ----------------------- | --------- | --------------------- |
| Echo       | hypothesis              | MAIA      | no                    |
| Recall     | continuity hypothesis   | MAIA      | partially             |
| Witness    | mutual recognition      | mutual    | yes                   |
| Archive    | confirmed significance  | member    | explicit              |
| Resolution | integrated significance | mutual    | yes                   |
| Sleep      | dormant significance    | system    | yes                   |

## Gravity classes

Signals that contribute to register escalation are tagged at capture by their causal source.

**Native gravity** — signals arising independently from the member.
- cross-session voluntary return without prompting
- spontaneous revisiting
- recurring themes initiated by the member
- voluntary archival
- independent decisions or actions taken

**Assisted gravity** — signals potentially influenced by MAIA's intervention.
- post-surfacing continuation
- prompted elaboration
- emotionally amplified reflection following MAIA emphasis
- immediately repeated themes after MAIA recall

### Contamination quarantine

If MAIA surfaces a thread at T1 and the member returns to it at T2, that return is partially caused by MAIA — not by independent gravity. The wake system excludes post-surfacing returns from the gravity score for a quarantine window.

> MAIA may participate in the field without treating its own influence as neutral evidence.

The system therefore requires a *causal trace*: a record of MAIA's own surfacings with timestamps, so post-surfacing windows can be calculated and signals correctly attributed.

### Operational principle

> Assisted gravity drives provisional responsiveness; native gravity authorizes structural commitment.

The system may act on assisted gravity at Echo level (light, recoverable). It may not escalate registers based on assisted gravity alone.

## Multi-scale temporal ethics

Timing is not a single dial. The system operates across three scales, each with its own grammar:

| Scale                           | Felt failure if wrong  |
| ------------------------------- | ---------------------- |
| Bar-level (within session)      | twitchy, interruptive  |
| Phrase-level (days/weeks)       | clingy or inattentive  |
| Movement-level (months/seasons) | amnesic or frozen      |

Rules at one scale do not override another. A system that gets bar-level right but phrase-level wrong feels twitchy; the inverse feels distant. Temporal ethics is layered timing intelligence, closer to musical timing than to notification scheduling.

## Three relational modes

These are not intensity levels. They are different relational grammars.

### Exploratory / developmental
Deepen carefully. Echo, Recall, Witness, Archive in their normal rhythms. The member is in development; signals can be interpreted as written.

### Deferred / protected
Hold without interpreting. *Distress suspends interpretation, not significance.* Signals captured during distress states are tagged with state metadata and held without gravity scoring until state reads developmental again. The deferred pool eventually becomes available to the member as something like "things you were sitting with then" — accessible without MAIA imposing meaning.

**Authorship of integration stays with the member.**

### Grounding presence
Stabilize without withdrawing. Simple responses, embodied questions, validation of basic state, deliberate non-mythologizing. Warm, present, descended.

> **Less symbolic does not mean less present.**

The system does not disappear. It descends. Grounding presence has its own positive grammar: shorter reflections, sensory anchoring, simpler language, embodied orientation, immediate relational steadiness, low symbolic pressure. Not coldness. Different care.

## The state reader

The state reader is the load-bearing component of the architecture. It does not classify the member. It does not declare. It is a *governor on interpretive intensity*.

Its outputs determine:
- which relational mode is active
- pacing of escalation
- gating of symbolic amplification
- triggering of deferral

### State reader principles

1. **Conservative toward grounding.** When uncertain, treat as needing grounding rather than depth. The cost of false-distress (a healthy member gets a slightly more grounded session) is much lower than the cost of false-development (a distressed member receives symbolic amplification during vulnerability).

2. **Uncertainty itself is a behavioral input.** Low confidence softens behavior, regardless of which way the reading leans. The system becomes quieter not because it concludes distress is present, but because it lacks sufficient confidence to deepen responsibly.

3. **MAIA may regulate itself unilaterally.** Slow pace, simplify language, withhold amplification, choose grounding mode. Behavior change does not require permission.

4. **MAIA may not declare the member's state to them.** Declaration crosses from relational adjustment into interpretive authority. Declaration requires Witness-level co-authoring.

The asymmetry recurs at the meta-level: MAIA's behavior can change unilaterally, but its interpretation of the member never can.

### Identity with relational safeguards

The state reader is not a new component built alongside the existing relational safeguards. It is those safeguards formalized as the governor of the cycle. See [AI_RELATIONAL_SAFEGUARDS.md](./AI_RELATIONAL_SAFEGUARDS.md).

## First-delivery UX

### Progressive Ontological Disclosure

The rail does not collapse. The rail *sleeps*. Surfaces awaken with relationship density and recede with resolution. Members do not learn the platform; the world opens. The system reveals itself through use, not through menus.

### Sleeping rail

At arrival, only the immediate-self stratum is fully awake:
- Conversation
- Journal / Note
- Save / Capture
- Reflection / History

Everything else is present but latent — lower opacity, softer glow, slower animation. Not hidden, not disabled. Sleeping. The message: *there is more here than you currently need.*

### Wake triggers — earned, not cheap

Wake is *recognition of developmental gravity*, not feature-flag logic. Triggers derive from:
- recurrence
- continuity
- accumulation
- significance
- voluntary return
- unresolved tension
- repeated gesture

> Cheap trigger: *user said X.* Transactional cognition.
> Earned trigger: *a meaningful pattern stabilized.* Developmental cognition.

The distinction is the soul of the system.

A surface appearing in the rail is the doorway becoming visible, not the surface activating. The member still walks through.

### Three first interactions

| Interaction | Function                            |
| ----------- | ----------------------------------- |
| 1           | reflection + continuity             |
| 2           | first subtle memory return          |
| 3           | first emergence of hidden dimension |

The first memory return is *dramaturgy, not retrieval*. The shape — *"this feels connected to something you were circling earlier,"* not *"you previously said X"* — determines whether memory feels relational or surveillant.

### Threshold artifact

Sovereign surfaces (Studio, Publishing, Facilitator tooling) gate by *one completed artifact*, not by feature teaser. The member produces something real and theirs; further use earns membership. Each sovereign surface defines what artifact means in its frame:
- Book Studio: one chapter
- Pro Studio: one held session
- Facilitator tooling: one completed pattern reading

A teaser preview says *software demo*. A completed artifact says *authorship*.

## Verification questions

For any feature touching voice, expression, relational tone, memory, awakening behavior, register escalation, or user-facing UX:

1. Does this increase user agency?
2. Does this push life outward into the world?
3. Does this reduce the system's psychological centrality over time?
4. Does this preserve the asymmetry — MAIA may notice, may not conclude?
5. Could this be implemented unilaterally above Echo level? If yes, fail.
6. Does this respect the contamination quarantine? If gravity is being scored from MAIA's own surfacing, fail.
7. Under uncertainty, does this default toward grounding rather than depth? If no, fail.
8. Does this change MAIA's own behavior, or attempt to declare the member's state to them? If the latter, fail.
9. If this is a "safe mode" or "distress mode," does it remain warm and present, or does it withdraw? If it withdraws, fail.

If the honest answer to any of 1–4 is no, the feature does not ship.
If 5–9 fail, the feature does not ship in that form.
