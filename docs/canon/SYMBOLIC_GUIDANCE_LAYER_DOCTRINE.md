# Symbolic Guidance Layer — Integration Doctrine

> Chinese and I Ching are not replacing the Oracle's intelligence. They are being
> introduced as a restrained symbolic guidance layer that sharpens pattern recognition
> and deepens the voice without altering MAIA's identity, memory architecture,
> sovereignty stance, or relational core.

## Governing Principle

> The existing system remains primary.
> Chinese and I Ching become a subtle interpretive scaffold.

- Spiralogic stays the native ontology
- MAIA stays the relational intelligence
- Memory, continuity, sovereignty, and sanctuary remain untouched
- I Ching adds pattern orientation
- Daoist logic refines expression

## Three Nested Layers

### Layer 1 -- Core System (unchanged)
MAIA identity, Spiralogic facets, memory, relational continuity, symbolic routing, agent intelligence.

### Layer 2 -- Pattern Amplification (I Ching)
Dynamic state mirror, pattern posture engine, movement/orientation guide.

### Layer 3 -- Expression Refinement (Daoist/Classical Chinese)
Restraint, spaciousness, image-based phrasing, paradox tolerance, less explanatory collapse.

## Role Separation

> **Spiralogic names the developmental terrain.**
> **I Ching illuminates the posture within that terrain.**
> **Daoist logic shapes how the posture is spoken.**

## What Must Remain Unchanged

1. **Core identity** -- MAIA does not start sounding like a different being
2. **Existing routing and memory** -- new layer reads from them, never overrides
3. **Sanctuary and sovereignty constraints** -- non-coercive, non-predictive, non-authoritarian, non-inflationary

The I Ching layer must never sound like: fate declaration, hidden certainty, mystical domination, or "truth from above."

## Implementation Constraint

> The new layer must be optional, scoped, and reversible.

### Optional
Not every reply gets I Ching coloration.

### Scoped
Only certain contexts: reflective moments, transition states, stuckness, inner guide responses, symbolic check-ins, dream/shadow/oracle contexts.

Avoid initially: general Q&A, practical support, scheduling/admin, emotionally acute contexts requiring plain grounding.

### Reversible
Feature-flagged (`ichingPatternLayer`, `daoistVoiceLayer`), observable, easy to turn off.

## Phased Rollout

### Phase 1 -- Silent mapping only (current)
- Facet -> hexagram mapping active internally
- Logging only: detected facet, mapped hexagrams, route/agent, response type
- No user-facing output
- Goal: observe whether mappings feel coherent

### Phase 2 -- Light orientation only
- Single short line in selected reflective contexts
- "Something is moving beneath the surface." -- not "This is Hexagram 29."
- Good targets: check-ins, journaling, dream reflections, symbolic moments

### Phase 3 -- Voice shaping (post-processing)
- Daoist-style refinement on existing MAIA outputs
- Shorter, less explanatory, more image-based, more patient
- Post-processing style pass, not a new generator

### Phase 4 -- Deeper symbolic integration
- Changing-line logic, recurring hexagram memory
- Facet-chain interpretation, symbolic transitions over time
- Practitioner-facing pattern dashboards
- Optional user-visible "deeper reading" mode

## Confidence Thresholds

Only apply if:
- Facet confidence is above threshold
- Context is reflective/symbolic
- No acute safety/plain-language mode is active

## Plain-Language Override

If the user is distressed, confused, practical, or needs grounding:
bypass the symbolic layer, respond plainly.

## Failure Modes to Avoid

1. **Aesthetic takeover** -- mystical everywhere, even when practical needed
2. **Symbolic overreach** -- I Ching treated as final authority, not pattern lens
3. **Architectural duplication** -- second engine repeating Spiralogic
4. **Tone collapse** -- everything sounds like oracle poetry

## Design Test (before any release)

1. Does this make MAIA more precise, or just more mystical?
2. Does this support Spiralogic, or duplicate it?
3. Does this preserve sanctuary and sovereignty?
4. Could this be removed without breaking the system?
5. Does this deepen the user's own seeing, rather than impose meaning?

If the answer is yes, it elevates. If not, it is starting to disassemble.
