# Rig Veda / Fire — exemplar lineage (Archetypal Grammar)

> The **first authored lineage** — the proof exemplar for MAIA's two-tier
> archetypal grammar. See [../ARCHETYPAL_GRAMMAR.md](../ARCHETYPAL_GRAMMAR.md) and
> [../MAIA_MULTI_ARCHETYPAL_INTELLIGENCE.md](../MAIA_MULTI_ARCHETYPAL_INTELLIGENCE.md).
>
> **Status (2026-06-05): Priest authored by Kelly** (the format-setting unit). The
> remaining Fire primitives and Rig Veda archetypes await authorship. When the
> lineage is complete, engineering encodes **only this lineage** as the proof
> primitive (`lib/spiralogic/archetypes.ts`) before the full grammar is expanded.
>
> Field schema: `primary element · related primitives (element-tagged) · function ·
> gift · distortion · held by (optional) · practice`. Only **`distortion` is
> required** (sovereignty-critical, clause 3 — how it harms when it possesses the
> field). **`held by` is optional & polymorphic** (`Primitive | Practice | Boundary
> | MemberMeaning`, also silence / non-action) — kept optional so it never becomes
> formulaic. Related primitives are relational (not renames) and may cross elements
> (the cross-element relation can be the counterweight that checks the distortion).

> **Field set (resolved 2026-06-06):** per-archetype = `function · gift · distortion ·
> restrained by · practice`. **`bounded by: Member Meaning` is a GLOBAL constitutional
> invariant** — inherited by all archetypes / guides / standing sources (like
> gravity), NOT authored per archetype. So each unit's holding question narrows to:
> *what restrains it before the constitutional floor (member sovereignty) must be
> invoked?* (Priest's `held by: Steward/Earth` and Prophet's open `held by` are
> **restraints** in this sense.) See canon § "The constitutional floor is a global
> invariant".

## Authoring frame (per unit — Kelly)

For each archetype, answer:
- **Function** — what does it *do* in the field?
- **Gift** — what does it make possible when rightly held?
- **Distortion** — how does it go wrong when it *possesses the field*? *(the load-bearing line)*
- **Practice** — what brings it back into right relation?
- **Held by** — optional; only if a holding force is clear (`Primitive | Practice | Boundary | MemberMeaning` / silence).

### Prophet — the constitutional test case (authoring prompt — Kelly)

The next authoring act is **vertical** (deepen Prophet fully), not sideways (more
archetypes). Answer, in order:

1. When vision is rightly held, what does it serve?      → `function` / `gift`
2. When vision is distorted, whom does it override?       → `distortion`
3. What must remain sovereign so vision does not become command?
4. What practice returns vision to relation?              → `practice`
5. What holds vision in right relation?                   → `held by`

Because Prophet's distortion is MAIA's own, these answers do not merely define an
archetype — they define a **restraint on the intelligence itself.** Until they are
answered, the rest of the grammar waits.
