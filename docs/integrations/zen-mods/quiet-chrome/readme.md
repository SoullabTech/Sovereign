# Quiet Chrome

A small mod that lets the browser frame recede, so your attention stays with the page you're working in.

It gently quiets the chrome around the web view:

- softens the top toolbar (a touch less saturation and contrast)
- dims the tabs you aren't looking at
- lets the address bar rest quietly, then return to full clarity the moment you focus it
- keeps the active tab fully legible at all times

That's the whole mod. No panels, no buttons, no new behavior — just a calmer frame.

## It matches your theme, it doesn't replace it

Quiet Chrome sets **no colors of its own**. It only lowers saturation, contrast, and opacity on top of whatever Zen theme you already use. Switch themes freely; this rides along and keeps quieting.

## Calm intensity

One setting, under the mod's preferences:

| Level | Feel |
|-------|------|
| **Soft** (default) | Barely there — just takes the edge off |
| **Medium** | A clearly calmer frame |
| **Deep** | The frame steps well back |

## Motion

The quieting settles in with a short, soft transition instead of snapping. If you have **reduced motion** turned on in your system, that transition is removed automatically.

## What it does *not* do

- It never reads, touches, or styles the content of any web page — **browser chrome only**.
- It adds no network calls, no tracking, no state, no extra features.
- It introduces no new animation beyond a settle on the things it already quiets.
