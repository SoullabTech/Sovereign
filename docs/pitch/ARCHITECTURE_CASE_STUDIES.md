# Architecture Case Studies — index

**What this is:** case studies whose subject is *the system*, not a person. Where the
[Case Study Library](./CASE_STUDY_LIBRARY.md) shows **what happens for a human being**
(transformation), these show **what happens inside the architecture** (operating
principle). Same form — a story — different subject.

**Why the split matters:** Sarah, in the guide standing-source study, looks like a
user story but isn't one. Her value is not that she changes. Her value is that she
holds still while *one variable* moves:

> **Same person. Same situation. Different standing source. Different foregrounding.
> Same sovereignty.**

That is an **architectural proof**, not a therapeutic outcome — so it belongs here,
cross-linked from the system docs, and **kept out of the transformation library** so
that library stays about people.

**Governed by:** [`docs/canon/MARKETING_CLAIM_DISCIPLINE.md`](../canon/MARKETING_CLAIM_DISCIPLINE.md)
— architecture studies declare **Layer / Center of Gravity / Failure Test** too, and
carry the extra duty of naming their **verification path** (the experiment that would
move a 🟡 Designed beat to 🟢 Observed).

### 1. The Guide as Operating Lens — *standing, not sovereignty*

- **Exemplar:** [`CASE_STUDY_GUIDE_STANDING_SOURCE.md`](./CASE_STUDY_GUIDE_STANDING_SOURCE.md)
  — Sarah's one concern rendered through No Guide / Taoist / Jungian / Vedic. Tense-marked:
  🟢 selection→injection + sovereignty guardrails · 🟡 attention-shift (improvised,
  not engine-driven) · 🔵 guide-aware memory + multi-source ecology.
- **Operating principle:** a standing source informs *what becomes salient* without
  becoming MAIA's identity or overriding the member's meaning.
- **Center of gravity:** Designed — the distinctiveness across guides is the payload,
  and it is improvised by the base model on a thin tradition payload, not produced by
  a built grammar (Phase 2, blocked on grammar authorship).
- **Verification path:** [`docs/specs/GUIDE_ABLATION_PROTOCOL.md`](../specs/GUIDE_ABLATION_PROTOCOL.md)
  + harness [`scripts/repro/wisdom-guide-ablation.ts`](../../scripts/repro/wisdom-guide-ablation.ts).
  The experiment that promotes 🟡 → 🟢: engage (lens shifts attention where it fits)
  **and** recede (lens disappears where it doesn't — the sovereignty test).
- **System docs:** [`MAIA_MULTI_ARCHETYPAL_INTELLIGENCE.md`](../canon/MAIA_MULTI_ARCHETYPAL_INTELLIGENCE.md)
  · [`GUIDE_ARCHETYPAL_STANDING_SOURCE_2026-06-05.md`](../architecture/GUIDE_ARCHETYPAL_STANDING_SOURCE_2026-06-05.md).
- **Status:** exemplar = intended-behavior, clearly labeled. Successor *(not yet
  written)* = **"Observed Behavior Under Taoist Guide vs No Guide,"** authored from
