## READ FIRST — Honesty Rails (these govern every scenario)

A case study is a capability claim. These rails keep us out of the Season-1 inflation trap (`docs/BETA_TESTER_INVITATION_UNIFIED_VOICE_2026-05-31.md`) and inside `docs/ANTI_FEATURES.md`.

1. **In-the-moment reflection is LIVE and demonstrable** — the three voices (Talk/Care/Note), within-session depth, elemental framing, Sanctuary Mode. Anchor scenarios here.
2. **Longitudinal "remembers your patterns over months" is the PROMISE, not yet the verified proof.** Some cross-session recall is live (prior moments can surface); full pattern-tracking over time is still being deployed/verified. Frame it as *"the relationship MAIA is built for,"* not *"what happens guaranteed today."* When in doubt, write the continuity beat in future/aspirational voice.
3. **Adjunct, never replacement** (Anti-Feature #4). Every practitioner/therapy scenario shows MAIA *supporting* the human relationship — never substituting for the clinician, the friend, or professional help.
4. **No authority inflation** (Anti-Feature #3). MAIA reflects, frames, and offers thresholds. It does **not** diagnose, rank, score, or pronounce. The client does the work; MAIA holds the mirror.
5. **Arc toward autonomy** (Sovereignty Invariants). The most distinctive AND most truthful case-study shape ends with the user *more* sovereign and MAIA *less* central. This is the moat competitors literally cannot tell. Make it the spine of every story.

## FAMILY A — Practitioners (Stewardship tier) · dual-actor, highest commercial value

These are the richest because there are **two users** (practitioner + client) — exactly the copywriter's "Fred is a therapist with a client" shape.

1. **The Psychotherapist** — Fred, depth/relational therapist. Client between sessions tends to lose the thread of insight. *Flow:* client reflects with MAIA (Care voice) between sessions, Sanctuary Mode for the rawest material; Fred uses his own MAIA to track his attunement, not to surveil the client. *Hook:* reduces clinician liability — MAIA reflects, never diagnoses. Ends with client carrying insight into session more ready.
2. **The Somatic / Bodywork Practitioner** — works with the nervous system. *Flow:* elemental + somatic language ("notice where the activation lives"); MAIA helps the client name body-states between sessions so the in-person work goes deeper/slower. *Live-anchored:* in-the-moment somatic reflection.
3. **The Coach (executive / life)** — client stuck between high-stakes decisions. *Flow:* Talk voice for quick real-time clarity; threshold-offering ("here's the choice you're circling") without telling them what to choose. Accountability without pressure (Anti-Feature #2).
4. **The Spiritual Director / Depth-Psych / Shamanic Practitioner** — dream, symbol, archetype, shadow. *Flow:* Note voice (witnessing) for dream capture; symbolic reflection that never claims interpretive authority over the person.
5. **The Group Facilitator / Retreat Leader** — pre- and post-retreat integration for participants. *Flow:* MAIA as the container that holds the opening *after* people go home, so the work doesn't evaporate.

## FAMILY B — Seekers (Presence → Continuity) · individual

6. **The Life-Transition Navigator** — divorce, grief, career pivot, empty nest. *Flow:* daily check-ins, Care voice; the transition becomes legible over time. Strongest *honest* continuity story once memory ships.
7. **The Daily Reflective Practice** — journaling/meditation companion. *Flow:* Note voice as witness ("reflects without interpreting"); the anti-engagement journaling app. Fully live today.
8. **The Therapy Adjunct** — already in therapy, uses MAIA between sessions. *Flow:* explicitly framed as adjunct (Anti-Feature #4); MAIA helps surface what to bring to the next human session.
9. **The Crossroads Decision** — one high-stakes decision worked over days. *Flow:* the decision returned to across multiple sittings; shows continuity value on a contained, verifiable timescale.
10. **The Shadow / Inner-Work Practitioner** — recurring pattern they're ready to meet. *Flow:* pattern *named back* gently, never pathologized; arc explicitly toward "you don't need me to see this anymore."

## Reusable scenario template (so each reads consistently)

```
TITLE — [Persona], [one-line situation]
WHO: name, role, the human stakes
SITUATION: the real problem (a feeling, not a feature gap)
USAGE FLOW:
  - Entry: how they arrive / which voice (Talk / Care / Note)
  - In the moment: what MAIA actually does (live capability)
  - Over time: the continuity arc (mark aspirational if not yet verified)
  - Privacy beat: where Sanctuary Mode shows up
PRACTITIONER SIDE (Family A only): how the pro uses it, separately, without surveilling the client
THE TURN: the moment of value — insight carried, not dependency formed
AUTONOMY ARC: how MAIA becomes less central by the end
WHAT'S TRUE TODAY vs DESIGNED: explicit line so the claim is honest
```
