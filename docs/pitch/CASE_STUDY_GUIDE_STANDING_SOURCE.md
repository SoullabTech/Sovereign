## Capability Ledger (read before the story)

The story renders three guides shaping the same conversation. Each beat sits in
one of three layers. **Tags inline below point back to this table.**

### 🟢 LIVE — true of the running build today

- **Guide selected → persisted → injected.** A member chooses a guide in the
  Wisdom Council picker; the selection persists server-side, survives across
  devices, and loads into MAIA's context on every text path (Phase 1 / 1.5,
  verified 2026-06-05/06). With no guide chosen, the block is simply absent and
  MAIA stays general.
- **Standing-not-sovereignty guardrails.** The injected block
  ([`buildWisdomGuideAddendum`](../../lib/wisdom/wisdomGuidePrompt.ts)) carries the
  three sovereignty clauses verbatim: *has standing, never sovereignty · does not
  possess the field · the member remains the final authority · do not force its
  concepts where they do not fit; let it recede.* This is in the code, not the
  brochure.

### 🟡 DESIGNED — intended behavior; produced today by improvisation, not by an engine

- **Guide shifts attention / salience.** The *intent* is that the guide changes
  what becomes salient. Today that shift is **improvised by the base model** from a
  compact, length-capped tradition payload — name + one-line teaching + archetype +
  mantra + a few principles — **not** selected by a built salience engine.
- **Tradition-specific noticing.** The depth in the Taoist / Jungian / Vedic
  renderings below is **base-model competence** triggered by naming the tradition,
  not output from a MAIA grammar. The engine that *would* make this structured and
  controlled — the two-tier archetypal grammar (elemental primitives → guide
  constellations, weights, computed standing) — is **Phase 2, and Phase 2 is
  blocked on grammar authorship**. Until it exists, the differentiation is real but
  **uncontrolled, unmeasured, and variable turn-to-turn**.

### 🔵 VISION — not built; directional

- **Guide-aware memory / retrieval.** The guide does **not** yet change which
  memories surface (Phase 3 retrieval boost — deferred).
- **Multi-source ecology.** Element + developmental thread + memory field + natal
  pattern + standing archetypes all holding standing at once, integrated without
  any one possessing the field (Phase 2–5 — deferred).
- **Archetypal standing field.** Dynamic computation of "what has standing now"
  from constellation ⊕ elemental ⊕ developmental affinities — design target, not
  runtime.

## Claim-discipline verdict (the instruments, applied)

**Center of Gravity:** The emotional payload of this story — *three guides produce
meaningfully different, tradition-true attention on one unchanged concern* — rests
on the **Designed** layer. The distinctiveness is the point, and the distinctiveness
is improvised, not engineered or measured.

**Failure Test:** Strip the Designed and Vision layers. What survives is: *a member
picks a guide; it persists and injects a standing-source block with sovereignty
guardrails; MAIA's voice is informed by it.* That survives as Live — but the
**story's distinctiveness does not survive**, because it lives entirely in the
Designed layer. → **Verdict: this is a Designed-layer story.** Not publishable as
Live. It travels **only** as an intended-behavior exemplar, exactly as titled.

**Anti-inflation note:** "injected ≠ influence." No ablation has compared a guided
run to a no-guide run on the same input. Until that exists, any sentence implying
the guides *demonstrably* diverge is over-claiming.
