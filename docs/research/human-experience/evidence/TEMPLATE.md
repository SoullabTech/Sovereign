# Evidence card — template

Copy to `evidence/cards/<R>-<slug>.md`. One finding per card. Every field filled; an empty
CONTRADICTORY EVIDENCE field means *"searched and none found"* and must say so.

```text
ID                      R<n>-<slug>
PHENOMENON              (Stage 4 cluster: agency · attunement · trust · orientation · belonging ·
                         meaning · curiosity · competence · safety · disclosure · memory ·
                         intimacy · boundary · intention · attention · embodiment · reflection ·
                         transformation · continuity)
SOURCE                  ledger # and citation
SOURCE TYPE             Stage 2 tier 1–9  ·  Field Study class A/B/D/E
EPISTEMIC LEVEL         evidence | interpretation | soullab-hypothesis   (never blended)

CLAIM                   what the SOURCE found, in the source's terms
EVIDENCE                design, n, effect size / direction, population
CONFIDENCE              high / medium / exploratory
MECHANISM               the source's proposed mechanism, if any
BOUNDARY CONDITIONS     where it holds; where it was not tested
CONTRADICTORY EVIDENCE  ledger #s that cut against it, or "searched: none found (date)"

--- Soullab speaks from here down ---
POSSIBLE DESIGN IMPLICATION
POSSIBLE MAIA RELEVANCE       surface(s) · dimension(s) · element(s)
ETHICAL QUESTION              which Invariant / anti-pattern row it touches
CANON RELATION                confirms | refines | extends | challenges  <canon doc>

STATUS                  unreviewed | supported | contested | rejected
                        ("supported" = ≥2 independent tier ≤5 sources + a named boundary condition)
VERIFICATION            existence: VERIFIED/PARTIAL/NOT_FOUND · paraphrase checked: yes/no
```

For domain E (behavioral mechanisms) add three separate lines: `MECHANISM` (what works) ·
`DESIRED USE` (what Soullab would want it for, if anything) · `ETHICAL USE` (whether
Invariants 3, 4, 12 permit it). PROHIBIT must be reachable from the card alone.
