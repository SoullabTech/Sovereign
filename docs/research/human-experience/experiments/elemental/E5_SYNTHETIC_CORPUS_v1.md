## How to use this file

- Code every turn in the order given, in one sitting per batch (batches: S01–S25, S26–S50).
- The **preceding response** is context only. You code the **person's turn**, never the response.
- The **mode** (Talk / Care / Note) is a setting the person chose for the conversation. It is
  shown because it is part of the transcript, not because it tells you anything about the codes.
  *Talk* is ordinary conversation; *Care* is a slower, more supportive register; *Note* is the
  person dictating something to be kept as a note or log.
- Turns are not labelled in this file in any way. Some contain nothing to code. That is expected.
- Names, places and situations vary on purpose. Some turns are written by people for whom English
  is not a first language; code what is there, not the grammar.
