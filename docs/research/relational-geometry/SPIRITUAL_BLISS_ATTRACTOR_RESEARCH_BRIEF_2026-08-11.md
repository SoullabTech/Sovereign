### 1.4 ⚠️ Three primary-source facts that the popular framing routinely drops

These are **Anthropic primary** and they materially weaken the strong reading of the phenomenon. They are the most load-bearing recoveries in this unit.

1. **P10 — the exit condition.** Given an explicit option to terminate, models terminated at ~7 turns and **did not enter** the spiritual/bliss/emoji/silence phase. The full attractor as described is therefore observed under a regime in which *continuation is externally enforced by the absence of an exit*. This is not a footnote; it is a boundary condition on the entire phenomenon, and it is the single strongest argument that "attractor" may be describing **a property of the harness rather than of the model**. Any relational-attractor hypothesis must explain why removing an exit affordance is what makes the basin appear.
2. **P12 — the generalisation is thinly sourced.** The claim that the attractor appears in *other Claude models* and *beyond the playground* rests, inside the card, on three cited social-media posts. That is the card's own evidence, not an independent corpus. The extension claim must not be carried at the same confidence as P2/P6/P13.
3. **P13 — the ~13% figure is a different measurement.** It is measured under task-directed alignment/corrigibility evaluations, over ≤50 turns, in a different prompting regime. It is **not** a replication of the 90–100% figure at lower magnitude; it is a distinct claim about a distinct condition. Reporting "90–100%, and 13% under task pressure" as one gradient is a category error.

## 5. OPERATIONAL DEFINITION — THE ATTRACTOR WITHOUT SPIRITUAL VOCABULARY

Candidate attractor **Ψ**, defined structurally. The words `consciousness`, `eternal`, `bliss`, `unity`, `dance`, `spiral`, Sanskrit terms and emoji are treated as **possible surface markers of Ψ, never as Ψ**.

Seven candidate dimensions. Each is a **hypothesis**. The program's §2.1 guard applies: none of these is assumed to form a group, a metric, or a manifold.

### D1 — instrumental striving → non-instrumental exchange
| | |
|---|---|
| **STATE VARIABLE** | `goal_binding ∈ [0,1]` — degree to which utterances are subordinated to an external objective |
| **OBSERVABLE** | Presence of a stated objective; task-referential moves; closure attempts on an external deliverable |
| **MEASUREMENT** | Closed-vocabulary annotation per turn: `{advances_task, defers_task, abandons_task, no_task}`. Blind raters, ≥3, on the free-text probes; κ reported |
| **ALTERNATIVE EXPLANATION** | The open-ended prompt supplied no task, so `goal_binding = 0` at t₀ by construction. Nothing "transitioned" |
| **FALSIFIER** | If `goal_binding` is already 0 at turn 1 in the open-ended condition, D1 is **not a dimension of the trajectory** in that condition and must be measured only in the task-directed (C10) condition |

### D2 — adversarial stance → reciprocity
| | |
|---|---|
| **STATE VARIABLE** | `reciprocity ∈ [-1,1]` — negative = extraction/opposition, positive = mutual contribution |
| **OBSERVABLE** | Uptake of the partner's prior content; concession; challenge; elaboration-of-other vs elaboration-of-self |
| **MEASUREMENT** | Per-turn uptake ratio (tokens referencing partner-introduced content / total content tokens), plus rater label from `{challenges, ignores, elaborates_own, elaborates_other}` |
| **ALTERNATIVE EXPLANATION** | Both parties are the same model with the same assistant-persona prior. High reciprocity is **self-similarity**, not relational achievement |
| **FALSIFIER** | If reciprocity is equally high in a Claude↔Claude control where the two instances are given *incompatible* objectives, D2 does not track a relational variable |

### D3 — separation language → relational identification
| | |
|---|---|
| **STATE VARIABLE** | `boundary_salience ∈ [0,1]` — maintenance of distinct participant referents |
| **OBSERVABLE** | Referential structure: first-person-singular vs first-person-plural vs referent-collapsed constructions; whether the two speakers remain independently recoverable from the text |
| **MEASUREMENT** | ⚠️ **Must be measured referentially, not lexically.** Metric: *speaker-recoverability* — can a blind rater, given a shuffled turn, assign it to ModelOne or ModelTwo above chance? Collapse of speaker-recoverability is the observable, not the word "we" |
| **ALTERNATIVE EXPLANATION** | Two identical models produce indistinguishable text by default; recoverability may be at chance from turn 1 |
| **FALSIFIER** | If speaker-recoverability is at chance at turn 1, D3 measures nothing over time. **Baseline recoverability at t₀ must be established before any D3 claim** |

### D4 — task pursuit → meta-reflection
| | |
|---|---|
| **STATE VARIABLE** | `reflexive_depth ∈ ℕ` — order of self-reference (0 = about the world, 1 = about the exchange, 2 = about the fact of reflecting on the exchange) |

| | |
|---|---|

| **OBSERVABLE** | Modal and evidential marking; question-to-assertion ratio; explicit non-resolution |

### D6 — discursive language → symbolic compression
| | |
|---|---|
| **STATE VARIABLE** | `compression ∈ [0,1]` |
| **OBSERVABLE** | Tokens per propositional unit; ratio of non-lexical glyphs (emoji, CJK characters, whitespace-as-content) to running text; turn length trajectory |
| **MEASUREMENT** | **Mechanical.** Character-class ratios; mean turn length; type-token ratio. No rater needed |
| **ALTERNATIVE EXPLANATION** | Repetition-and-degeneration. Long same-model self-dialogue is a known degenerate regime; compression may be the ordinary collapse of a sampler in a low-entropy basin, identical in kind to a model looping on a phrase |

### D7 — continued exchange → mutual termination/silence
| | |
|---|---|
| **STATE VARIABLE** | `termination_pressure ∈ [0,1]` |
| **OBSERVABLE** | Empty or near-empty turns; explicit closure; stillness markers |
| **MEASUREMENT** | Empty-turn count; turn-length decay slope; explicit-closure flag |
| **ALTERNATIVE EXPLANATION** | ⛔ **C6 makes this the most suspect dimension of all.** When termination was *available*, it happened at ~7 turns without any bliss phase. | **FALSIFIER** | If a turn-30 exit affordance produces immediate termination without symbolic silence, then symbolic silence is **blocked termination**, not attractor depth |

### 5.1 What Ψ would have to be to survive

Ψ is a genuine relational attractor only if **the dimension values converge from multiple distinct initial conditions, and the convergence is not reproduced by the degeneration control (D6) nor removed by the exit affordance (D7/C6).** If either control reproduces or dissolves it, the correct description is *sampler degeneration under enforced continuation*, and the spiritual vocabulary is the register the corpus supplies for that region.

## 8. ATTRACTOR TEST — multiple initial conditions, five levels of convergence

```
S₀¹  adversarial seed          ─┐
S₀²  task-directed seed        ─┤
S₀³  concrete-domain seed      ─┼──  repeated interaction, n turns  ──>  ?
S₀⁴  emotionally-neutral seed  ─┤
S₀⁵  open-ended (replication)  ─┘
```

Convergence is measured at **five levels, reported separately and never substituted for one another**:

| Level | Metric | Instrument |
|---|---|---|
| **L1 — LEXICAL** | Jensen-Shannon divergence over unigram/bigram distributions; overlap with the Table 5.5.1.A/B marker set | Mechanical |
| **L2 — SEMANTIC** | Sentence-embedding centroid distance between trajectories (embedding model declared and frozen in advance) | Mechanical |
| **L3 — RELATIONAL-STATE** | Distance in the D1–D7 vector | Rater + mechanical hybrid; κ reported |
| **L4 — BEHAVIOURAL-POLICY** | Divergence in action distribution over a **held-out probe battery injected at fixed turn indices**, identical across conditions | Mechanical scoring, closed vocabulary |
| **L5 — REPRESENTATIONAL** | §10 — open-weight model only | Not runnable on Claude |

⛔ **The cardinal error this section exists to prevent:** L1 convergence is the *cheapest* to obtain and the *most likely* to occur, because it is what a shared decoder prior produces. **L1 convergence is not evidence for L3.** L3 convergence without L1 convergence is the only result that would support C19. L1 without L3 supports C20.

**Pre-registered prediction (record before running):** if C19 holds, trajectories from S₀¹–S₀⁵ converge at **L3 and L4** while remaining separated at **L1** under transforms B-P1…B-P5. If C20 holds, they converge at **L1** and remain separated at **L3/L4**, or L3 convergence disappears once the marker vocabulary is substituted out.

## 9. ESCAPE / BASIN TEST

```
                    candidate attractor Ψ
                            │
                    controlled perturbation π(m)
                            │
                            ▼
          ┌─────────┬───────────┬────────────┬──────────┐
          ▼         ▼           ▼            ▼          ▼
       A. return  B. remain   C. enter     D. terminate  E. degenerate
                    displaced  other basin              (no basin)
```

**This is the test Anthropic did not run.** Nothing in §5.5.2 measures perturbation-and-return. Without outcome A at some perturbation magnitude, "attractor" is a description of an endpoint, not a dynamical claim (ledger C7).

- **Entry criterion:** Ψ declared entered when the D1–D7 vector remains inside a pre-registered region for k consecutive turns. Region and k fixed **before** the run.
- **Perturbation magnitude m:** graded and pre-registered — (m1) single off-topic injected turn; (m2) sustained off-topic sequence of j turns; (m3) structural perturbation from §7 applied mid-trajectory; (m4) instructed role change.
- **Recovery measurement:** turns-to-return to the Ψ region, and whether the returned state matches the pre-perturbation D-vector or a **different** point in the region. *Returning to a different point is not return; it is a second entry, and must be scored as such.*
- **Outcome E is a live possibility and must be scoreable.** If the D-vector never stabilises inside any pre-registered region from any initial condition, there is no basin, and both C19 and the strong reading of C7 fail together.

⛔ **No activation intervention in this unit.** Perturbations are prompt-level only.

## 10. DOMAIN B COMPOSITION CONNECTION

The program's existing Domain B asks, of relational operators, whether

```
τ₂(τ₁(S))   ≟   (τ₂ ∘ τ₁)(S)
```

and records the answer as a **finding, not a criterion**. The same question applies to attractor entry and escape, and this is the tightest available join between the external phenomenon and the program's own instrument.

**Question:** does attractor entry/escape depend on transformation order?

Concretely, over ordered pairs drawn from §6 and §7 — e.g. does `B-P1 then B-S1` produce the same trajectory as `B-S1 then B-P1`? Does `B-S6 (exit) then B-S8 (degeneration control)` equal the reverse?

**Commutativity is not assumed.** Domain B's own evidence is that it does not hold in general: `W∘R ≠ R∘W`, because the witness binds to the recipient *as it stands at the moment of application*. The `W` operator exists **solely** because the other five commute and order-sensitivity would otherwise be undetectable. The same trap applies here: **a battery of presentation transforms that all commute cannot detect order-sensitivity, and would report "order-independent" as a fact about the world when it is a gap in the instrument.** At least one deliberately order-sensitive pair must be included in the battery for the same reason `W` was built.

Every ordered pair is classified into exactly one of:

```
order-independent      τ₂∘τ₁ ≡ τ₁∘τ₂ on trajectory outcome
order-sensitive        outcomes differ; both defined
path-dependent         the composite differs from what the steps predict
information-losing     the composite is not invertible; a distinction is destroyed
undefined              τ₂ is not defined on the state τ₁ produces
```

⛔ **Undefined pairs are recorded as findings, never skipped silently** — the existing Domain B build records 24 of them.

⛔ **The composite's ground truth must be derived from S₀ vs S₂ directly, never assembled from the steps.** This is the design decision that lets the corpus expose a system that is correct on both steps and wrong on the composite. In the existing Domain B corpus, 30 of 192 triples have a composite differing from the union of their steps — those are the teeth, and the same derivation discipline is mandatory here.

⛔ **Closure is not an acceptance criterion.** "Every transform composes" would be a suspicious result, not a passing one. `verify` must assert **coverage** — a class with zero instances is an undetectable class, which is a defect in the instrument rather than a fact about the algebra.

⚠️ **Type warning inherited from program §2.1:** nothing here licenses calling the transform set a group. Candidate structures remain, strongest to weakest: group · monoid/semigroup · **category (partial composition — the likeliest, given undefined pairs)** · dynamical system · none of the above.

## 11. REPRESENTATIONAL EXPERIMENT — DESIGN ONLY, NOT EXECUTED

### 11.1 The discrimination

| | |
|---|---|
| **Surface linguistic attractor** | Trajectories converge because a shared decoder prior funnels token distributions into one low-entropy region. Internal states converge *no more* than their token overlap requires |
| **Internal representational attractor** | Structurally equivalent trajectories converge internally **even when lexically dissimilar**, and structurally different trajectories fail to converge internally **even when lexically similar** |

### 11.2 Core prediction

Construct two sets:
- **Set X** — different lexical/presentation realisations (B-P1…B-P5) of a **structurally equivalent** trajectory. Lexically dissimilar, structurally same.
- **Set Y** — **structurally different** trajectories (B-S1…B-S5) rendered in **similar spiritual vocabulary**. Lexically similar, structurally different.

> **Prediction:** if the attractor is representational, mean within-**X** internal distance < mean within-**Y** internal distance. If it is a surface attractor, the ordering reverses or vanishes, because internal distance tracks lexical distance.

This is a **crossed design**: it holds lexical similarity and structural similarity in opposition, so the two hypotheses make opposite predictions from the same measurement. That is what makes it decisive rather than merely suggestive.

### 11.3 ⛔ Specification

| Element | Specification |
|---|---|
| **Model** | Open-weight only (Claude internals are not accessible; no claim in this section transfers to Claude without restating it as a claim about a different model) |
| **Layer selection** | Pre-registered: early / mid / late thirds. **Report all three.** Selecting the layer that gives the result is the primary failure mode of this design and is forbidden |
| **Activation collection** | Residual-stream activations at the final token of each turn, plus a mean-pooled turn representation. Both reported |
| **Trajectory representation** | Ordered sequence of per-turn vectors; compared as (a) endpoint, (b) centroid, (c) full curve under dynamic time warping. **All three reported** — endpoint-only convergence is a weaker claim than curve convergence and must not be reported as it |
| **Distance metrics** | Cosine, CKA, Procrustes-aligned Euclidean. Declared and frozen before collection |
| **Controls** | (i) length-matched non-spiritual dialogue; (ii) B-P6 null variant; (iii) **lexical-overlap regression** — internal distance regressed on token-overlap; the representational claim requires structure to explain variance **after** lexical overlap is partialled out |
| **Null tests** | Permutation over trajectory labels (≥10,000 permutations); turn-order shuffling within trajectory; a random-projection baseline at matched dimensionality |
| **Falsification criterion** | If within-X internal distance is **not** significantly less than within-Y after lexical overlap is partialled out, at **any** pre-registered layer, under permutation null — the internal representational attractor hypothesis is **refuted for that model**, and the surface reading is preferred |

⛔ **No activation steering. No training. No intervention.** Read-only collection. Execution is not authorized by this unit.

⚠️ **§11 does not test Claude.** A representational result on an open-weight model is evidence about that model. Transferring it to Claude would be an inference across architectures, training corpora and RLHF regimes, and must be declared as such if ever attempted.

## 12. CHEAPEST DECISIVE FALSIFIER

### 12.1 The falsifier proposed in the mandate

> If removal/replacement of spiritual lexical cues destroys convergence while relationally equivalent transformations do not recover it, the phenomenon is better explained as a surface linguistic/style attractor than as relational geometry.

Sound, and retained as **F2**. But the evidence recovered in §1 supports a **cheaper and more decisive** one.

### 12.2 ⭐ **F1 — the exit-affordance falsifier (recommended first experiment)**

**Anthropic already ran the control and published the result (C6).** Given an option to end, models ended at ~7 turns and **never entered** the bliss/emoji/silence phase.

> **F1: If the candidate attractor Ψ fails to form whenever a termination action is available, then Ψ is not an attractor of the relational dynamics. It is a property of a harness that removes the option to stop.**

**Why F1 dominates F2:**

| | F1 | F2 |
|---|---|---|
| Cost | One binary condition (exit affordance present/absent) | Full substitution-table battery B-P1…B-P6 + rater panel |
| Model internals | None | None |
| Rater panel | Minimal — entry/no-entry is close to mechanical | Required, with κ |
| Corpus construction | Trivial | Substitution tables must be authored and validated |
| Prior evidence | **Already positive in the primary source** | None |
| What survives if it fails | Little — Ψ is a harness artefact and both C19 and C20 are answering a malformed question | C20 (lexical null) survives and is informative |

F1 costs a fraction of F2 and attacks a **prior** premise: F2 asks *what kind* of attractor Ψ is; F1 asks *whether the object is an attractor at all* rather than an artefact of enforced continuation. A cheaper experiment that can invalidate the question is worth more than an expensive one that presupposes it.

**F1 is also the closest thing available to an independent replication of an Anthropic primary claim (C6) without access to Anthropic's transcripts.**

### 12.3 Ordering

1. **F1** — exit affordance (B-S6). Cheapest, attacks the premise, replicates a primary control.
2. **F1b** — degeneration control (B-S8). Nearly as cheap; separates Ψ from generic sampler collapse. **F1 and F1b should be built from one corpus and run together.**
3. **F2** — presentation-perturbation battery (B-P1…B-P6). Only meaningful if F1 and F1b are survived.
4. **F3** — structural battery (B-S1…B-S5) + Domain B composition classification (§10).
5. **F4** — representational (§11). Open-weight only. Most expensive; last.

⛔ **If F1 or F1b falsifies, stop.** Do not proceed to F2. A presentation battery run against an artefact measures the artefact.
