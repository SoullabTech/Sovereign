## 0. The question the surface answers

The House model and the memory graduation model are structurally the same problem, and the same corrective applies.

**The client Home does not answer:**

> ❌ *"What do we know about this person?"*

**It answers:**

> ✅ **"What helps this person orient themselves here today?"**

The naive form of every one of these systems is *more retained → more intelligent → better continuity.* The corrective, across all three layers:

| Layer | Failure mode | Corrective |
|---|---|---|
| Memory | retaining everything destroys retrieval | retain what helps the next decision |
| Product | exposing everything destroys relationship | reveal what supports the human |
| Governance | recording everything destroys authority | preserve evidence without confusing existence with decision |

> ⭐⭐⭐ **Continuity is not accumulation.** *Better curation → better orientation → better continuity.*

A client does not want *everything that has ever happened with me.* They want **what matters now, in the right context, with the right ownership.**

## 1. The active surface test

Applied to **every item on a screen** — a card, a band, a label, a nav entry, an empty slot.

1. **Why is this here now?**
2. **Who authored it?** *(content authorship)*
3. **Whose act put it here?** *(presence authorship)*
4. **Who has authority over it?**
5. **What human decision does it support?**
6. **What would happen if it were absent?**

> If the only available answer to (1) is **"because we have the data,"** it does not belong on the active surface.

**Relationship to the four screen questions** in [Design Principles §4](NOW_WHAT_DESIGN_PRINCIPLES_2026-08-03.md): questions 2 and 3 here *are* those questions — content vs. presence authorship, the distinction that catches relevance ranking, the third voice, and the rendered empty slot. This test adds three:

- **(4) authority** — separates *whose voice* from *whose call*. Attribution is necessary, not sufficient; a labelled claim is still a claim.
- **(5) decision support** — the anti-accumulation clause. An item that supports no human decision is inventory, not orientation.
- **(6) the counterfactual** — ⭐⭐⭐ **the new one, and the sharpest.** It is the only question that interrogates *absence*, which is where this lane's hardest open item lives.

## 2. Placement — five destinations, not two

| Destination | Admits | Test |
|---|---|---|
| **Home** | what orients *today* | passes all six; (5) answerable in one sentence |
| **Rooms** | the work itself, entered deliberately | passes all six, but (1) is *"because I came here for it"* |
| **Archive** | completed, reachable, not occupying decision space | settled; **path back stays visible** |
| **On invitation only** | material whose surfacing must be a member act | (3) has no valid answer unless a person asked |
| **⛔ Never** | items where **presence *or absence* leaks** | fails (6) — see §3 |

The fourth row is the graduation rule's product-side twin: *completed work remains reachable through lineage but does not occupy active decision space.* **Archive is not forgetting. Compression is not deletion. Silence is not absence.**

⚠️ **The graduation move must not become a hidden authority layer.** A system that silently decides *"this is old, therefore irrelevant"* has performed an interpretation — the same failure as *"these writings show a pattern."* The safe sequence is: **preserve the record → know the surface's current purpose → move settled material off the active surface → keep the path back visible.** Recency is not relevance, and the system does not get to rank.

## 3. The fifth category — where presence *or* absence reveals too much

This is the one that cannot be resolved by better labelling, and this lane has already done real work on it. **Nothing here is new; it is collected so the placement question inherits it.**

- **E-3 ruled: private sovereignty is silent.** An empty labelled band is *not* silent — `What Senja is carrying: [private unless shared]` tells Larry there is material he is not being shown. Withheld-ness acquires a permanent position on his screen. ([Design Direction §1.2](NOW_WHAT_DESIGN_DIRECTION_LARRY_2026-08-03.md))
- **Withdrawal must leave no shadow.** A withdrawn item must be **unreconstructible** — not merely hidden — including by position, count, or spacing. A timeline is exactly where a removed item leaves a visible gap. ([§1.4](NOW_WHAT_DESIGN_DIRECTION_LARRY_2026-08-03.md))
- **A MAIA observation about the member's private material must never render on the practitioner's surface** — that is surveillance with attribution attached. ([§1.3](NOW_WHAT_DESIGN_DIRECTION_LARRY_2026-08-03.md))

**The design consequence:** render only what exists. A section that is *present when there is something and simply absent when there is not* gives absence no slot to occupy. State the boundary **once, in the relationship's terms** — so the practitioner learns the rule from the platform's honest description of what they can and cannot see — **never per-band, never per-screen.**

⚠️ This **relocates Q-P2; it does not close it.** Q-P2 remains the hinge question of the lane, and Q-P1 (one component with a viewer parameter is where projection re-enters) and Q-P3 (nav sized to what exists) remain open alongside it.

## 4. The caution that governs this document

The symmetry between the memory system and the product architecture is elegant. **Elegance is a failure mode.**

> The test is **not** *"does this mirror our philosophy?"*
> The test is **"does this survive contact with real users and real decisions?"**

Two readings of the symmetry stay open, deliberately: it is either good evidence the thesis generalizes, or good evidence to be suspicious of how satisfying it is. **Nothing here should be ratified on the strength of the pattern being neat.** The six questions earn their place by catching real items on real screens — and if they do not, they are wrong and should be replaced.

### The preservation question — open, and it is the next legitimate one

> **Does this need preservation as a durable design artifact, or should it stay a working synthesis until the parent principles resolve?**

Not every useful synthesis earns durability. The transition, if it happens:

```
working synthesis → relationship to the parent principles ruled → (if needed) durable artifact
                  → design authorization → implementation
```

⭐⭐⭐ **If this document is absorbed and retired, two things must survive it** — everything else here restates work that already lives in the parent documents:

1. **Q6 — *what would happen if it were absent?*** The only question in the set that interrogates absence. Traditional product thinking asks *why should we show this* and *how useful is it*; Q6 asks **what harm occurs if it appears, what changes in the relationship because it exists, and whether silence is the more respectful behavior.** That is a different optimization function, not a stricter version of the same one.
2. **`on invitation only` and `never` as legitimate placement states.** Most systems have a visibility model (`visible / invisible`); a relational system needs **presence conditions**. ⭐⭐⭐ **`never` is a design state, not a missing feature** — the same claim as *what a coach cannot see is not a gap in the product.*

Everything else — presence authorship, the rendered-slot problem, withdrawal shadows, the third-voice bar — is **already recorded in the parent documents** and must not be treated as originating here.

> The hard part is not deciding what to show. It is making sure that what we do not show cannot be inferred from the shape of what we do.
