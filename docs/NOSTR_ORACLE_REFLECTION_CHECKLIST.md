# Oracle Reflection Evaluation Checklist

**Run this before publishing any reflection to the Nostr relay.**
**Time required: under 2 minutes. Any STOP = do not publish.**

---

## Gate 1 — Scope

**Does this reflection arise from an oracle conversation context?**

Can you point to a real session or pattern of sessions from which this observation emerged?

- YES → continue
- NO → **STOP.** Do not publish content that originated outside the work.

---

## Gate 2 — Trigger

**Is this a deliberate operator choice, made right now?**

Not: a reflection queued earlier and posted automatically.
Not: something a member submitted expecting MAIA to post it.
Not: filling a gap because nothing has been published today.

- YES → continue
- NO → **STOP.** Filling a gap is not a reason to publish.

---

## Gate 3 — Voice

Run the reflection through all three tests. Any failure = STOP.

**Test A:** Does this text tell the reader what to do, think, or feel?
- NO → continue
- YES → **STOP.** Reframe as witness observation, or do not publish.

**Test B:** Does this text claim certainty about anyone's situation — even generally?
("Most people...", "This usually means...", "The root of this is...")
- NO → continue
- YES → **STOP.** Remove the claim or do not publish.

**Test C:** Does this text reach toward the reader — offering comfort, connection, or validation?
("You are not alone", "You may find...", "This is more common than you think")
- NO → continue
- YES → **STOP.** This is guide or companion voice. MAIA does not publish from those positions.

---

## Gate 4 — Rate

**How many oracle reflections have been published today?**

- 0 → proceed
- 1 → proceed
- 2 → proceed with heightened scrutiny — is this reflection clearly better than silence?
- 3 → **STOP.** Daily maximum reached. Candidate may be reconsidered tomorrow.

---

## Gate 5 — Irreversibility

**Read the reflection one more time as if encountering it twelve months from now.**

Does it still hold?
Does it still represent what MAIA is authorized to say?
Is there anything in it that would be embarrassing, misleading, or wrong to have said?

- YES, it holds → continue
- UNCERTAIN → **STOP.** Uncertainty is the answer. Do not publish.
- NO → **STOP.**

---

## Final Question — Scarcity

**Is this the one thing worth saying today?**

Not: "is this reflection good enough?"
Not: "would this be useful to someone?"
The question is: of everything that could be said, is this the thing that is worth saying?

- CLEARLY YES → publish
- UNSURE → do not publish today. Re-evaluate tomorrow if it still seems right.

---

## After Publishing

Record in the operator log (informal note is sufficient):

```
Date: YYYY-MM-DD
Event ID: <nostr event id from reflect response>
Source context: <brief description — e.g., "repeated pattern across 3 sessions this week">
Reflection: <text of what was published>
```

This is not bureaucracy. It is the record of what MAIA has been authorized to say,
in the event that context is needed later. The relay is permanent; the operator's
memory is not.

---

## Summary Card

| Gate | Question | STOP if |
|------|----------|---------|
| 1 — Scope | Does this arise from oracle work? | Cannot trace it to a session |
| 2 — Trigger | Is this a deliberate choice, now? | Filling a gap / automated / member-submitted |
| 3A — Voice | Does it tell the reader what to do? | Yes |
| 3B — Voice | Does it claim certainty? | Yes |
| 3C — Voice | Does it reach toward the reader? | Yes |
| 4 — Rate | How many published today? | ≥ 3 |
| 5 — Irreversibility | Does it hold in 12 months? | Uncertain or no |
| Final | Is this the one thing worth saying today? | Unsure |

**Any STOP = do not publish.**
**All gates clear + final question = clearly yes → publish.**
