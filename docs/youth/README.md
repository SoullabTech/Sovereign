## Governing Principles

These documents implement the MAIA Oath for youth contexts:

- **Consent first.** No teen uses the system without guardian consent and their own assent.
- **No content leakage.** Incident logs, guardian outreach, and reviews use metadata only. Never content.
- **Supported sovereignty.** Privacy of experience, visibility of wellbeing.
- **Humans step in.** When safety fires, a real person responds same-day.
