## D-SL-1 — Gate §14 circularity · **RESOLVED**

The circularity is resolved by distinguishing two states that Gate §14 previously conflated:

```
PRE-IMPLEMENTATION CANDIDACY
        ≠
IMPLEMENTATION CLOSURE
```

⛔ Gate §14 **must not** require executable evidence from a boundary that does not yet exist, as a
precondition for implementing that boundary.

### Before implementation

All conditions **logically provable without implementation** must PASS.

A condition whose proof *specifically requires the proposed boundary* may remain
**`PARTIAL — IMPLEMENTATION-BOUND`**, provided all four hold:

1. the blocking evidence **cannot** exist without implementation;
2. **no contradictory evidence** is present;
3. the condition is **explicitly listed as a mandatory closure proof**;
4. implementation scope is **bounded to the minimum boundary necessary to test it**.

### At implementation closure

Every implementation-bound condition must be **executed against the delivered boundary**.
⛔ The slice may **not** be classified complete while that condition remains unproven.

> **Implementation may create the evidence boundary.**
> ⛔ **Implementation may not use its own existence as evidence of PASS.**

### For Condition 3 specifically

```
PRE-IMPLEMENTATION:  PARTIAL permitted
SLICE CLOSURE:       PASS required
```

⛔ **Do not weaken "proven" into "argued."** This is a **sequencing correction, not a lowering of the
gate.** Gate 5 is likewise implementation-bound under D-SL-3.

## D-SL-2 — H index vs `authority_scope` · **RESOLVED — `authority_scope` FIRST**

**Approved order:**

```
authority_scope
  → executable authority proof
  → H index
  → subsequent Super Learner indexing / learning surfaces
```

**Reason.** The H index *organizes* knowledge. Before expanding organization, the system must be
capable of representing **the jurisdiction under which a claim may govern** — otherwise indexing can
increase retrieval or salience **before** authority boundaries are explicit.

⛔ **This order must not imply that `authority_scope` becomes a universal ranking dimension.**
It remains **one independent axis among**: provenance · epistemic status · **authority_scope** ·
corpus_weight · temporal standing · evidence.

⭐ The H index **must consume or preserve that distinction — never collapse it.**

## D-SL-3 — Gate 5 sovereignty defect · **RESOLVED — remediate within the `authority_scope` lineage**

Remediate Gate 5 **as part of** the `authority_scope` implementation lineage.
⛔ **Do not create an unrelated predecessor architecture solely to repair it** — the existing
sovereignty failure is one of the reasons `authority_scope` exists.

### ⭐ Representation is not remediation

A schema, type, or module *capable of expressing* member/practitioner sovereignty is **insufficient**.
Gate 5 remains incomplete until **behaviour** proves all seven:

1. founder/system framework authority **cannot** override member-owned experience outside its scope;
2. practitioner interpretation **cannot** become member fact merely by being authored by a practitioner;
3. claims of different authority scopes may coexist **without silent merge**;
4. overlapping authority scopes **invoke the approved adjudication behaviour**;
5. **corpus weight does not buy jurisdiction**;
6. **confidence does not buy jurisdiction**;
7. **retrieval salience does not buy jurisdiction**.

### Current state — recorded, not upgraded

```
CASE E MODULE PROOF:          PASS
LIVE / INTEGRATED SOVEREIGNTY: UNPROVEN
GATE 5:                        PARTIAL
```

⛔ **Do not upgrade Gate 5** until the relevant **real consumer path** exists and executes the proof.

## D-SL-4 — First Super Learner Alpha slice · **APPROVED — KEEP / `is_breakthrough`**

Approved: **KEEP / breakthrough memory**, canonical concept `is_breakthrough`, as **Super Learner
Alpha Slice 1**.

⭐ **This approval is SEQUENCED, not immediate.** ⛔ Do not begin implementation while the current
`authority_scope` lane is active or unresolved. The slice may begin **only after**:

1. the `authority_scope` implementation boundary is **settled**;
2. its current governance state is **known**;
3. **no overlapping claim / worktree authority conflict** exists.

### Why `is_breakthrough` is approved

Existing evidence already supports the mandatory proof classes **without speculative infrastructure**.
The slice must preserve and test:

| # | Property | Requirement |
|---|---|---|
| 1 | **Source heterogeneity** | Material spans six source classes. ⛔ The implementation must not assume a single source type. |
| 2 | **Correction / supersession** | A real founder correction exists: `Stage 4 → Stage 3`. The superseded claim must remain **historically recoverable** while losing current governing standing. ⛔ Do not delete the earlier claim merely because it is superseded. |
| 3 | **Scope** | Preserve *"governs description, not disposition."* A claim may govern one domain without governing another. ⛔ Do not translate scope into a universal authority/rank score. |
| 4 | **UNKNOWN vs ABSENT** | **Mandatory** — see below. |
| 5 | **No graph dependency** | ⛔ The first alpha proof must not require the graph merely because future architecture may use one. Prove with the smallest necessary substrate. ⛔ Do not activate graph infrastructure as incidental scope. |

### ⭐ The UNKNOWN / ABSENT pair — the principal reason this candidate is approved

**Derived ABSENT candidate:** `is_breakthrough = true` observed on **0 of 142**, where the search is
exhaustive and its coverage is known. That may support `ABSENT` **only with the required evidentiary
contract**.

**UNKNOWN candidate:** `surface_count = 0` was explicitly ruled *"not evidence in either direction."*
It therefore remains `UNKNOWN`.

⛔ **Do not treat zero as absence without a valid search/coverage proof.**

> A system that sees `0` and concludes *absent* is doing database arithmetic. A system that asks
> whether the search domain and coverage **license** absence is beginning to reason about what the
> evidence permits. That distinction is the alpha test.

### The question the slice must answer

> **Can JARVIS faithfully represent and reason about whether a breakthrough memory is present,
> absent, unknown, superseded, scoped, and supported across heterogeneous source material — without
> collapsing those distinctions into one truth score?**

⛔ It is **not**: *can JARVIS build the whole Super Learner?*

### Required proofs before the slice closes — K1–K8

| # | Proof | Passes only when |
|---|---|---|
| **K1** | PRESENT | A properly evidenced breakthrough claim is represented as present. |
| **K2** | DERIVED ABSENT | Exhaustive `0 of N` evidence produces derived ABSENT **only** when the full absence contract is present. |
| **K3** | UNKNOWN | A zero-like signal **without** adequate search coverage remains UNKNOWN. |
| **K4** | CORRECTION | A later founder correction supersedes an earlier claim **without erasing** the earlier historical record. |
| **K5** | SCOPE | A claim governing *description* does not automatically govern *disposition* or another scope. |
| **K6** | SOURCE HETEROGENEITY | The result does not depend on all evidence sharing one source class. |
| **K7** | AUTHORITY | Authority scope is preserved **independently** of evidence quantity, corpus weight, confidence, or source count. |
| **K8** | NON-COLLAPSE | ⛔ No single scalar truth/confidence/rank score substitutes for the required independent axes. |
