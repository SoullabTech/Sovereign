## Evidence

### The failure class is not naturally confined to lifecycle mechanisms

C4's **first empirical application came from outside the chain**, within the hour of being ruled.

A memory-index compaction was proposed to fix a real problem (`MEMORY.md` at 21.9KB against a 24.4KB
limit). The obvious repair — shrink the index — would have passed the stated metric while destroying
reachability. Measured: **1241 memory files, 860 reachable from the index, 381 unreachable, depth to 8
hops.** All 143 direct links resolve; the map is locally accurate and globally incomplete.

The repair was stopped by asking the C4 question: *does the proposed repair address the failure class, or
create a new one?* A smaller index over more unreachable knowledge is the same failure class — something
real becoming unfindable — wearing the costume of a fix.

⭐ The memory store is **not** a governance-lifecycle mechanism. Under a narrow reading of C4, the
criterion would not have applied here at all. It applied, and it worked.

⚠️ **What this evidence does NOT establish:** an ownership model for applying C4 outside the lifecycle
domain. Value demonstrated ≠ process established.

### ⚠️⚠️ The structural cost of breadth — an obligation with no owner in view

C4 defers ownership of the test to Layer 3. That dissolved cleanly under an assumed-narrow scope:
Layer 3 selects the lifecycle instrument, and the instrument carries the test. **Owner arrives with the
instrument.**

But **Layer 3 is chartered only for the `ratified → recorded → verifiable` gap.** Under broad C4 the
obligation reaches every mechanism in the system, where Layer 3 has no jurisdiction and will never assign
an owner. Broad C4 is therefore durable, constitutional, and **structurally ownerless outside its origin
domain** — not unowned *yet*, but unowned with no process in view.

> *A principle can be true and still be premature if the system has no legitimate path for fulfilling it.*

Two failures to avoid: **under-scoping** — discarding evidence because it arrived outside the original
room · **over-scoping** — creating a universal obligation without a holder.

## RULING

### ✅ RULED 2026-07-29T22:20:45Z — **OPTION 2**

**C4 scope: BROAD, ratified.** C4 applies as written — any mechanism created to address any failure class
must be tested against recreating that failure class. Not confined to the lifecycle gap.

**⚠️ CARRIED FORWARD AS AN EXPLICIT OPEN QUESTION — the ownership gap:**

> **Who owns the C4 test for mechanisms outside the `ratified → recorded → verifiable` domain, and by
> what process?**

**Unresolved by design, and recorded rather than left undocumented.** Layer 3 is chartered only for the
lifecycle gap and cannot assign this owner. Any broader application needs its own path.

**Why not narrow:** the evidence exceeded the original boundary — C4's first empirical application came
from outside the chain and worked. Narrowing would discard a demonstrated result and turn it into an
exception requiring explanation.

**Why not broad-unexamined:** the breadth would hold anyway, leaving a constitutional obligation with no
holder and **no record that anyone noticed**. Option 2 keeps both truths on the record.

**Constraint preserved:** *owner arrives with the instrument.* Layer 2 defines the obligation · Layer 3
assigns ownership only where it has jurisdiction · any broader application needs its own path.
