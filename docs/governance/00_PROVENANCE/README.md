# 00_PROVENANCE — preserved primary sources

Primary material, held **unchanged**, with a source note for each item.

## What belongs here

A file enters only if it is a **source**, not a reading of one: a recording, a transcript, a document authored by the
person it concerns. Every Soullab analysis, summary, synthesis, deck or spec belongs elsewhere — those are derived,
and the whole point of this directory is that the distinction stays visible.

## The rule

**Unchanged means unchanged.** No cleanup, no speaker inference, no excerpting, no correction of transcription
errors, no summarisation, no reformatting for readability. A preserved source that has been improved is no longer a
source; it is one more derived document wearing a source's name. If something in it is wrong, the source note says
so — the file does not change.

Every item carries a source note recording: **how it was produced, by whom, from what, and when.**

## Why this directory exists

`docs/governance/LARRY_SOURCE_AND_CUSTODY_SITTING_AGENDA_v1.md` records a real prior failure: an interview was
conducted, and only speaker-labeled highlights survive — the raw recording and transcript are not held. Every later
document that responded to that material was therefore responding to a summary while reading as though it responded
to the source.

The same pattern recurred on 2026-09-02 with the Tiger 21 presentation
(`docs/design/now-what/reconciliation/NW_D02_TALK_DERIVATION_REVIEW_2026-09-02.md`).
