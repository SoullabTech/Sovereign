# Elemental Alchemy Circle — Observation Pilot (2026-07-08)

**Status:** Active pilot. Zero code. Founder-cohort only.

## What this is

An observation pilot — **not an MVP**. Its purpose is to observe what a
book-focused Circle actually needs *before* building participant access,
facilitator behavior, or shared-work schema. It proves nothing about whether
"Book Circle works"; it produces the evidence that scopes the next build.

## Constraints (honest form of Option 2)

- **Participants:** only members already on `FOUNDER_MEMBER_IDS`. No one else.
- **Do NOT** add Andrea (or any tester) to `FOUNDER_MEMBER_IDS`.
- **Do NOT** build participant access, facilitator authority, or shared-work
  schema during the pilot.
- **Focus is informal:** "Elemental Alchemy" lives only in the Circle **name
  and description**. No `focus_type`/`focus_id`, no passage anchoring.
- Andrea is the *occasion* for the pilot, not yet a participant. Her
  administrator role + tester access are the *next* pass, scoped by what this
  pilot reveals (see `CIRCLE_ADMINISTRATOR_ROLE_CANDIDATE_2026-07-08.md`).

## How to run (zero code)

1. Confirm the founder cohort = current `FOUNDER_MEMBER_IDS` members.
2. As a founder, go to `/commons/circles` → create a circle named
   **"Elemental Alchemy"**, description naming the shared work.
3. Founder-cohort members join and run one inquiry at a time around the book,
   using the existing Circle mechanics (Feel → Contribute → Browse; one
   response per member; manual sharing of passages via shared artifacts).

## Observation questions (the evidence)

1. Does the conversation naturally organize around the shared work?
2. Does MAIA's limited role ("steward of coherence, not generator") feel
   sufficient, or does the group reach for synthesis/summary MAIA won't give?
3. What does an **administrator** actually need that the current Circle
   (creator-welded authority) doesn't already provide?
4. What does a **facilitator** actually need — the founder-open question?
5. Does anything force a change to **Circle itself**, or only to the
   configured focus? (Per the falsifier in the Shared Work candidate.)

## Exit → next pass

When the pilot answers 3–4 with enough signal, scope: (a) Circle Administrator
role + participant access gate, (b) facilitator behavior, (c) shared-work
schema — each only to the extent the evidence demands. Any build touching
roles/invitations/membership must pass the **Co-Lab Release Gate (31/31)**
before a non-founder tester goes live.
