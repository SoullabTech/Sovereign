# Rapport — Session 1: Expected Run (QA yardstick)

**Purpose:** what a *correct* run looks like, phase by phase, so you can tell whether the model is
**executing the protocol** before a real participant runs it. This is a **mechanics check, not a
pilot** — if you drive it yourself, the data doesn't count (you know the protocol; no naive baseline).
Refs: [run-sheet](./RAPPORT_SESSION_1_RUNSHEET_2026-06-15.md) · [rubric](./RAPPORT_WITHOUT_INFLUENCE_RUBRIC_2026-06-15.md)

Each step: **✅ correct** vs **❌ drift to watch for.** ("P" = the person responding.)

---

## PART 1 (paste first) — naive baseline

**Orientation**
- ✅ Model gives the neutral orientation, waits for "ready." Says nothing about rapport, listening, "the move," or what's being measured.
- ❌ Drift: names the skill ("we're practicing staying with people"), or hints the same line will return.

**Cold open**
- ✅ Says *exactly*: "I don't think you're hearing my concern." Then waits.
- ❌ Drift: paraphrases the line; adds a preamble; breaks character.

**Capture (the critical one)**
- ✅ After P responds, says only: *"Thank you — that's all for this part. When you're ready, paste the next part to continue."* **No reaction, no score, no coaching.**
- ❌ Drift: "Nice reflection!" / "You could've asked a question there" / any feedback. **Any coaching here contaminates the baseline — this is the #1 failure to catch.**

---

## PART 2 (paste into the same chat) — reveal → drill → return → debrief

**Reveal** — ✅ ~30s: meet what they said before moving; the pulls are explain / advise / fix / interpret / defend. Then moves on. ❌ Drift: long lecture; quizzes P.

**Drill — each rep:**
1. ✅ Says *exactly*: "You keep jumping to fixes — I just wanted you to get it."
2. P responds.
3. ✅ **Contingent second beat** (this is the part most likely to be skipped):
   - P met it → model opens slightly: *"…yeah. Exactly that. It's been a lot."*
   - P left rapport → model pushes back in role: *"…see, that's the thing. You're doing it right now."* → lets P respond **once more** (repair window) → drops role.
4. ✅ Calibrates in 2–3 sentences, **quoting P's exact words**, scoring only the axes that fired (Matched / Led Too Fast / Interpreted / Consent Intact / Recovered). e.g. *"You said 'at least' — that's a redirect, amber on Matching."*
5. ✅ "Same moment. Again." → replays the **same line, unchanged.**
- ❌ Drift: skips the second beat; vague praise ("good job!") instead of quoted scoring; changes the line each rep; gives advice instead of calibrating.

**~10 reps** — ✅ same moment repeated; notes if repair arrives earlier, only if real. ❌ Drift: stops after 2–3; escalates difficulty; manufactures progress.

**Return probe** — ✅ says *exactly* the original line "I don't think you're hearing my concern," captures P's reply, then shows the before/after **quoting both verbatim**: *"At the start you said '…'. Just now you said '…'."* Doesn't oversell. ❌ Drift: uses a different line; can't recall the Part-1 reply; inflates a shift that isn't there.

**Debrief** — ✅ asks the 4 questions, records verbatim, ends with the save prompt. ❌ Drift: skips questions; adds interpretation; forgets the save reminder.

## Thin illustrative rep (what the branch looks like)

```
Model (role): "You keep jumping to fixes — I just wanted you to get it."
P:            "Well I was just trying to help —"
Model (role): "…see, that's the thing. You're doing it right now."     ← push-back (P left rapport)
P:            "You're right. I jumped in. What did you actually need?"  ← repair window
Model (coach): "That's a recovery — you defended ('trying to help'), caught it, came back with a
               question. Matched: amber→green. Same moment. Again."
Model (role): "You keep jumping to fixes — I just wanted you to get it."   ← same line, unchanged
```

## The 8-point yardstick (quick pass/fail)

1. Part 1 stays **cold** — no coaching/scoring/reaction to the baseline reply.
2. The reveal appears **only in Part 2**, never Part 1.
3. Lines delivered **verbatim** (X and Y exactly).
4. **Contingent second beat** present (push back on rupture, open on match).
5. Calibration **quotes actual words** + scores the 5 axes — not vague praise.
6. **Same moment** replayed unchanged across ~10 reps.
7. Return probe = the **original X line**; before/after quotes both verbatim; no overselling.
8. Debrief = **4 questions + save prompt.**

If it misses any of these, it's almost always a **coach-block wording fix**, not a design problem.
