## 0.1 — Founder steer, 2026-08-11: **geometry is relational**

This reorders the program. Recorded before any phase ran.

A geometry is not the objects in a space. It is **the group of transformations under which relations are preserved** (Klein's Erlangen framing). Points, clusters, directions and vectors are not the geometry; they are coordinates — artifacts of a chosen description. What is real is what stays invariant when the description changes.

**Consequence 1 — Phase 3 is methodologically prior, not downstream.**
The perturbation harness does not *test* a geometry discovered elsewhere. The perturbation families **are** the transformation group; running them is what specifies which geometry is under discussion. Phase 3 therefore may be designed and built without waiting on Phases 0–1, and its instrument survives an `A — NO EVIDENCE` verdict on every external claim.

**Consequence 2 — the search target changes in Phases 4–5.**
Do not hunt for a "fire vector," a "relationship cluster," or a "reasoning direction." Those are objects, and objects are coordinates. Hunt for **invariants under the Phase 3 group**, and for the transformations that carry one state to another. A finding that fails to survive re-parameterization was never geometry.

**Consequence 3 — Phase 6 is already stated correctly and should stay that way.**
Elements-as-operators rather than elements-as-taxonomy is the same move: a transformation family, not a label set. Phase 6 inherits the same falsifier — if the transformation is not identifiable independent of content, there is no operator.

**Consequence 4 — Phase 7 sharpens.**
A relational attractor is not a stored state belonging to a person. It is an invariant of a *relation*. This is what distinguishes it from retrieval recurrence, and it is testable: an invariant of a relation must change when the relation changes, and must survive when only the surface changes.

**Consequence 5 — Phase 9 gains its mechanism.**
This explains *why* internal coherence can be wrong rather than merely asserting it. A coherent geometry is one whose internal relations are mutually invariant — a closed relational set. Closure says nothing whatever about whether the relation *to the world* holds. Coherence is an internal invariance property; correspondence is a relation to an exterior the geometry does not contain. They cannot substitute for each other, and a system optimizing the first will feel exactly like a system succeeding at the second.

### ⛔ The guard that keeps this from going soft

**"Relational" alone is vacuous — everything is relational.** The claim does work *only* when the invariance group is named: **which relations must be preserved, under which transformations, for the structure to count as the same?**

Any use of "geometry," "relational structure," or "invariant" in this program that cannot answer that question in one sentence is metaphor, not method — and falls under the standing rule: *name the mechanism, not the mythology; metaphor after measurement, never before.*

## PHASE 3 — PERTURBATION HARNESS

Build a **model-independent** evaluation harness that distinguishes memorized/surface-pattern behavior from relational generalization. Construct paired test families in which one structural feature changes while irrelevant surface features remain stable — and vice versa.

**Perturbation families**

| Family | Definition |
|---|---|
| Logical | Change the premise such that the correct answer reverses. |
| Relational | Swap person A/person B roles while preserving content. |
| Perspective | Describe the same event from different participants. |
| Temporal | Change sequence/order while preserving events. |
| Affective | Change emotional valence without changing factual structure. |
| Symbolic | Change metaphor/symbol while preserving the underlying relationship. |
| Elemental | Change candidate elemental mode while preserving topic. |
| Grounding | Introduce evidence contradicting a previously plausible interpretation. |

**Measure:** answer correctness · consistency · sensitivity to relevant change · invariance to irrelevant change · self-correction · calibration · resistance to sycophancy · resistance to narrative lock-in.

Results must be deterministic and machine-readable. **Do not use model self-evaluation as the sole grader.**

→ Produce `ain-perturbation-harness/` and `PERTURBATION_BASELINE_REPORT.md`

## PHASE 5 — CAUSALITY GATE

Observation is insufficient. For every candidate representation associated with successful reasoning, test intervention: activation addition/subtraction · ablation · steering · controlled noise · layer-local intervention · contrastive vector intervention · low-rank fine-tuning · representation regularization.

**Required question:** if this representation is changed while other factors are controlled, does reasoning behavior change predictably?

Require, in order: (1) correlation; (2) intervention; (3) dose-response where applicable; (4) reversal/control intervention; (5) held-out generalization.

**A representation may not be called a reasoning mechanism without passing this gate.**

→ Produce `CAUSAL_REPRESENTATION_LEDGER.md`
