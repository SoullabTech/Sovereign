## Why "Session 0, exploratory" (not "Session 1")

The readiness audit (2026-06-15) found the methodology complete — interview prompts (§1), capture template (§2), coding (§3), decision rules (§6) — but **no run-sheet**, and established that **RAPPORT and Personal Field answer different questions** (dual-coding RAPPORT→PF is UNSUPPORTED). What it did *not* establish is the operational form a Personal Field session should take. Designing a polished "Session 1" now would assert a methodology that hasn't been earned. So:

```
Protocol → exploratory sessions → observed practice → session design
```

not `Protocol → session design`. Same discipline that surfaced the category error: **evidence before architecture.**

---

## Purpose

- Generate real episodes
- Exercise the §1 prompts
- Test the §2 capture sheet
- Validate the §3 coding process
- Discover what participants naturally bring
- **Learn what a future PF Session 1 should actually be**

## Inputs
- §1 interview prompts (elicit *episodes of attending* — "what were you tending to" — never feature wishes or screens)
- §2 capture sheet (`PF-<nn>`)

## Outputs (leave all of these behind — don't rely on auto-save)
- transcript
- filled capture sheet
- episode coding (verbs before nouns, §3; hold the object/verb axis **open**)
- facilitator notes
- **run-sheet observations** (what worked, what to change)

## Deliberately NOT specified (derive from practice)
- timing / session length
- facilitation style
- prompt sequence / ordering
- debrief structure

## Storage
Gitignored human-subject evidence store: `evidence/personal-field/<participant>/session-NNN/` (repo holds the *experiment*; the store holds the *data*).

---

## After each session
1. Code via §1→§3.
2. Fill `PERSONAL_FIELD_RUNSHEET_RETROSPECTIVE.md`.
3. After a few: synthesize the retrospectives → **derive the actual PF Session 1 run-sheet** from observed practice.

**This does not authorize the redesign.** Module/stance architecture stays downstream of the axis decision, which stays downstream of the episode corpus.
