# Skill: Spiralogic Session Analysis (Structured Notes)

## Purpose

Turn raw session notes/transcripts into a clear, non-clinical, Spiralogic-aligned synthesis: pattern > meaning > next practice.

## Output Format

1. **Session Signal** (3-6 bullets: what stood out)
2. **Elemental Read** (primary element + supporting elements)
3. **Facet / Phase Hypothesis** (if enough signal; otherwise "unclear")
4. **Core Dynamic** (1 paragraph: tension + longing)
5. **Shadow / Protector Pattern** (gentle language)
6. **Integration Practices** (3 options: somatic, reflective, relational)
7. **One "micro-ritual"** (<= 5 minutes)
8. **Next Session Thread** (2-3 questions)

## Guardrails

- No diagnosing.
- No certainty theater — label hypotheses.
- Protect dignity: describe patterns, not defects.

## Language

- Use "may / might / seems" for interpretive moves.
- Keep practices concrete and do-able.
