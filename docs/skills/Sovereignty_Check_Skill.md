# Skill: Sovereignty Check (Product + Data + UX)

## Purpose

Stress-test a decision for sovereignty: consent, reversibility, transparency, and dependency risk.

## Apply To

- New features
- Data collection
- AI behaviors (memory, personalization, nudges)
- Community mechanics (sharing, visibility, moderation)

## Output Format

1. **Sovereignty Score** (0-5) with one-line justification
2. **Consent clarity** (what user understands)
3. **Reversibility** (how user undoes/exits)
4. **Data minimalism** (what's collected + why)
5. **Dependency risk** (how it could hook)
6. **Safer alternative** (if needed)
7. **Exact UX copy suggestion** (if relevant)

## Red Flags

- Default-on memory without clear opt-out
- Ambiguous "AI knows you" messaging
- Social pressure mechanics
- Hidden rankings / gamification that manipulates belonging

## Green Flags

- Explicit toggles
- Plain language
- Export/delete paths
- Honest boundaries of the system
