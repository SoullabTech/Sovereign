# Learning Feature Evaluation Checklist

**Internal Gate for Soullab Learning Infrastructure**

This checklist must be answered **before** proposing, designing, or building any learning-related feature inside MAIA or Soullab.

If any answer is **"no"**, the feature does not proceed.

---

## 1. Does this support helpers *in active care work*?

* Does it serve practitioners who are already helping others?
* Does it reduce cognitive, emotional, or ethical load?
* Would this still make sense if no audience growth or monetization followed?

If it primarily benefits visibility, scale, or performance → **stop**.

---

## 2. Does this preserve sovereignty for both helper and participant?

* Can the helper operate independently after handoff?
* Does the participant retain agency, choice, and exit?
* Does the feature avoid creating platform dependency?

If it creates lock-in, reliance, or soft coercion → **stop**.

---

## 3. Does this avoid implicit authority or credential transfer?

* Does it avoid signaling legitimacy, mastery, or readiness?
* Are there no badges, levels, certifications, or progress statuses?
* Is responsibility emphasized over status?

If it confers authority by implication → **stop**.

---

## 4. Is this relationally held, not performance-driven?

* Does it strengthen relationship, reflection, or containment?
* Are there no rankings, metrics, streaks, or comparative signals?
* Is participation allowed to be intermittent or quiet?

If it pressures visibility or completion → **stop**.

---

## 5. Does this fit at least one of the Four Rooms *without reshaping them*?

* Living Room (community)
* Seasonal Retreat (time-bounded cohort)
* Daily Bread (micro-practice / reflection)
* Archive (reference, not progression)

If it requires creating a fifth room or reshaping one into an LMS → **stop**.

---

## 6. Does this comply with the Anti-Features *without exception*?

* No funnels
* No gamification
* No marketplaces
* No automated authority
* No dependency by design

If it requires "just this once" reasoning → **stop**.

---

## Final Rule

If a feature:

* accelerates extraction
* amplifies authority
* optimizes completion
* or reduces discernment

…it does not belong in Soullab Learning Infrastructure.

No debate required.

---

### Usage note

This checklist is not a discussion starter.
It is a **filter**.
Ethics are already decided upstream.
