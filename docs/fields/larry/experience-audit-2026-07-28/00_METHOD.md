# Now What? — Experience Architecture Audit
**Commissioned 2026-07-28 · Method: reveal first, decide second**

## What this is

A structured investigation of the `Now What?` surface as *lived experience*, not as code quality.
Eleven commissioned audits, run in two phases. Phase 1 reveals. Phase 2 decides.

**Phase 1 investigators may not recommend anything.** Naming an absence is an observation;
proposing to fill it is a recommendation. Only the first is authorized in Phase 1.

## Standing disciplines for every file

1. **Observations separated from interpretations.** Two labeled sections, never blended.
   An observation quotes copy or cites `file:line`. An interpretation is inference and is
   labeled as such.

2. **`built ≠ wired; wired ≠ surfacing; surfacing ≠ verified`.** No mechanism may be
   described at a tier above its evidence. A table with zero readers is BUILT, not WIRED.
   A read behind a disabled flag is WIRED, not SURFACING.

3. **"Cannot determine from code" is a valid finding** and is preferred over speculation.

4. **Empty states are first-class.** What a user with zero data sees is the real
   first-run experience, and is frequently not what the code reads like.

5. **This is Larry's field, not a category product.** `Now What?` is read against its own
   intent (`FLOURISHING_NOW_WHAT_FIELD_CONCEPT.md`), not against an executive-coaching
   benchmark. Comparative claims require a named comparator.

## Known risk in Phase 2

The Opportunity Report is the inflation seam. A ranked list of ten opportunities is exactly
the artifact that converts Cat-1 *preserved direction* into implied Cat-6 *live capability*.
Phase 2 must therefore mark every item with its artifact category and what it would actually
require — and must distinguish opportunities the evidence supports from opportunities the
evidence merely permits.
