# Instrument Review

Part of the [Design Review Guides](./README.md) collection — not canon.
Operationalizes the standing commitment that MAIA is an instrument, not an
application.

## Purpose

Determine whether the interface disappears into the relationship.

## Test

Walk the experience from first arrival to leaving.

Whenever the member becomes aware of the instrument itself: **stop.**
Record:

- What happened?
- Why did attention leave the conversation?
- What part of the system demanded awareness?
- Was it necessary?

Whenever the instrument disappears: **record why.**

## Questions

- Did anything ask the member to think about software?
- Did anything make them manage the interface instead of their attention?
- Did anything feel like a feature instead of a conversation?
- Did anything call attention to itself?
- Where did trust deepen?
- Where did trust weaken?

## Rule

The highest compliment is not

> Beautiful interface.

It is

> I forgot there was an interface.

Do not optimize for efficiency. Optimize for disappearance. The best
interface is the one the member no longer notices because their attention
has returned to themselves.
