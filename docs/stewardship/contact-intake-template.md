# Contact Intake Template

A working form. Fill in when a tester / practitioner / member makes contact that might warrant attention. The purpose is to slow the path from raw contact to implementation cognition — to metabolize before routing.

Not every contact requires this form. Use it when the contact carries energetic intensity, proposes a change, surfaces friction, or feels architecturally relevant.

Suggested location for completed intake records: `docs/stewardship/intake/YYYY-MM-DD-short-slug.md` (gitignored if records contain identifying information).
