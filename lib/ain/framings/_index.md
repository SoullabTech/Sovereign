# AIN Framing Library

Available perspectives for multi-framing deliberation. Select based on what would genuinely illuminate the question—not by keyword matching.

## Foundational
- **first-principles** — Break down to axioms, rebuild from truth
- **systems-thinking** — Interconnections, feedback loops, emergence
- **practical-engineering** — Buildable, maintainable, real-world constraints

## Human-Centered
- **user-experience** — Human needs, emotions, journey, friction
- **phenomenology** — First-person experience, embodiment, meaning
- **parenting** — Nurturing growth, boundaries, developmental needs

## Strategic
- **strategic-vision** — Long-arc thinking, doors opened/closed, path dependency
- **governance-incentives** — Power dynamics, failure modes, incentive structures
- **risk-reliability** — Operational risk, safety margins, fragility detection

## Theoretical
- **kauffman-emergence** — Adjacent possible, phase transitions, novelty
- **jung-archetypal** — Symbols, shadow, collective patterns
- **bateson-meta-learning** — Learning to learn, context, paradox

## Domain-Specific
- **ethics** — Values, harm, responsibility, consent
- **relationships** — Connection, rupture, repair, attachment
- **creativity** — Generativity, constraints, flow, blocks
- **grief** — Loss, transition, holding, release

---

*Selection guidance: Trust your discernment. There is no "correct" set of framings. Prefer fewer perspectives explored deeply over many explored shallowly. Unusual combinations often reveal hidden dimensions.*
