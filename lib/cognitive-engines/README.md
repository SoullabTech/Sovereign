## Why These Are Not Connected

These engines were **evaluated and deliberately set aside** — not abandoned.

The core finding: all four architectures assume **cognition comes first, emotion second**. Even MicroPsi, which places emotion at the center, still formalizes it into mechanistic drive taxonomies.

MAIA inverted this:

> **Intelligence cannot arise without emotional coherence.**

The production system routes through **Spiralogic → Sacred Attending → Relational Presence**, not through attention selection → goal planning → memory retrieval → emotional processing.

## Do Not "Fix" the Disconnection

If you're reading this because you noticed these engines aren't imported anywhere in the main conversation flow — that's intentional.

The disconnection is the architectural decision, not a bug.
