### What we DO use
- **Production**: Mac Studio running Docker + **Caddy** (local, not remote)

### What we DO NOT use
- **No Supabase** — all database is self-hosted PostgreSQL
- **No Nginx** — Caddy is the reverse proxy
- **No Vercel/Netlify** — self-managed deployment
- **No Cloudflare** — direct TLS via Caddy
- **No EC2/remote servers** — production runs locally on Mac Studio
