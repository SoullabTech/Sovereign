# Bases Setup Guide

This document explains how to use Bases with your MAIA data.

## Journal Base

Columns:
* date
* element
* facet
* mood
* intensity

Sort:
* date descending

## Checkin Base

Columns:
* dominant_element
* fire
* water
* earth
* air
* aether

Sort:
* date

## Reflection Base

Columns:
* theme
* element
* confidence

Sort:
* confidence descending

## How to Create These Bases

1. In Obsidian, navigate to the folder containing your exported files
2. Select "Create Base" from the context menu
3. Choose the appropriate folder
4. Configure the columns as shown above
