# Hermetic — Source Index

A composite folder for the Hermetic / Western esoteric strand as transmitted
through the modern (20th–21st-c.) articulation of the **Seven Hermetic
Principles**. The genuinely ancient Hermetic corpus — the *Corpus Hermeticum*
(2nd–3rd c. CE) and the *Asclepius* — is **not represented** here. What this
folder holds is therefore **all interpretive modern synthesis**, and must be
labelled as such at every layer.

## Notes in this folder

- [[Use Frame]] — how MAIA holds the Hermetic field
- [[Seven Principles]] — *interpretive modern synthesis* (the Kybalion, 1908)
- [[Dhadwar — Inner Alchemist Handbook]] — *interpretive modern synthesis* (further removed)

## What this folder is missing (deliberately)

- **The *Corpus Hermeticum*** — primary ancient Hermetic source, not yet ingested.
- **The *Asclepius*** — primary, not yet ingested.
- **Renaissance Hermetism** (Ficino, Bruno) — not yet ingested.

If MAIA ever speaks "Hermetism" with the weight of a tradition, those primary
sources should land first. Until then, this folder is best read as
*"the seven-principles framework as it is transmitted in the modern West"* —
which is real, useful, and **not the same as** ancient Hermetism.

## Use boundary

This corpus is **retrieval / lens material**. It must not be:

- Quoted as if it were ancient Hermetism
- Flattened into Daoist, Buddhist, or Christian frameworks
- Used as a self-help system imposed on a member
- Treated as initiatory

It may be:

- Cited when a member is asking specifically about the Kybalion or the
  modern "seven principles" framework
- Used to provide vocabulary (correspondence, polarity, rhythm) when a
  member is already in that idiom
