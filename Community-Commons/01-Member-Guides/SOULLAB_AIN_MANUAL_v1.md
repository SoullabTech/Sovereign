# Soullab AIN Manual (v1)

*A guided way to do real inner work with MAIA—without needing to know what to ask.*

Soullab isn't "ask an AI questions." It's **enter a living inquiry**—and let MAIA hold the thread with you: pattern, feeling, image, meaning, choice. Deepwander gets one thing very right: **people love prompts** because they dissolve the blank-page freeze. Soullab's twist is that prompts aren't the product—**they're the doorway** into elemental/alchemical self-psychonavigation.

---

## 1) What this is (in one breath)

Soullab AIN is a **guided introspection experience** that supports all levels—from "I'm new to inner work" to "I live in archetypes and shadow integration."

You can enter through:

* **Daily Check-in** (fast + gentle)
* **Soul Prompts** (curated doorways by element + depth)
* **Freeform** (just speak/type and let MAIA find the thread)

---

## 2) Your three best ways to begin

### A) Daily Check-in (best for newbies)

Use when: you don't know where to start, you're overwhelmed, or you want consistency.

What happens:

1. Choose an emotional state (mapped to an element)
2. Choose intensity (Whisper → Overwhelming)
3. Add a note (optional)
4. MAIA starts the session from *your actual weather today*

**Why it works:** it anchors the whole session in lived reality, not abstraction.

---

### B) Soul Prompts (best for direction + depth)

Use when: you want an evocative starting point.

What happens:

* You choose **Fire / Water / Earth / Air / Aether**
* You choose depth (Seeker → Practitioner → Alchemist)
* You pick a prompt
* It enters your chat framed as:

> "I'd like to sit with this question: ____"

So MAIA **guides you through it**, instead of answering it like an interview.

---

### C) Freeform (best for advanced + intuitive)

Use when: you already know what's alive.

Start with:

* "Something's happening in me and I don't have language yet…"
* "I had a dream—can you help me stay with the images before interpreting?"
* "I'm at a threshold and I can feel two opposing pulls."

## 3) Soul Prompts (how to use them well)

### Where to find Soul Prompts

* **In the chat input**: click the **tools (+)** menu → **Soul Prompts**
* **In the Lab Tools drawer**: **SOUL PROMPTS & SESSION**
* **Full library page**: `/labtools/prompts` (browse everything)

### How to use prompts (the "Soullab way")

Prompts are not "questions to ask MAIA."
They're **questions you enter**, so MAIA can guide your reflection.

Try this simple rhythm:

1. **Answer from the body first** ("Where do I feel that?")
2. **Name the image** (not the concept)
3. **Track the polarity** (what two truths are both here?)
4. **Choose one small next act** (integration > insight)

## 5) Session Arc Indicator (what it's for)

Soullab sessions have an arc. Naming it reduces confusion and "did I do this right?" energy.

Phases (felt sense):

* **Arriving** (settling, orienting)
* **Descending** (going beneath the surface)
* **Gathering** (pattern, insight, truth)
* **Ascending** (integration, choice, next step)
* **Emerged** (closure, continuity, carry-forward)

**How to use it:**

* If you feel scattered: return to **Arriving** (breath + body + one sentence truth)
* If you feel stuck: ask "What's the **tension** I'm avoiding naming?"
* If you feel complete: move to **Emerged** (simple integration action)

## 6) Session Synthesis vs Session Recap (two different gifts)

### Session Synthesis (the "alchemy" card)

This is the *meaning-making* layer:

* Patterns noticed
* Tensions held (A ↔ B)
* Invitation forward (a real next step)
* (Optionally) saved into developmental memory

Use when: the session felt important and you want the "what was that?" distilled.

### Session Recap (the "map" card)

This is the *tracking* layer:

* Duration, themes explored
* Elemental balance snapshot
* Breakthrough markers (when present)
* Save to journal / download

Use when: you want continuity and trackable progress over time.

## 11) FAQ (tiny but important)

**"Why did it post the prompt as my message?"**
Because prompts are meant to be *entered* as a living inquiry. The system frames it so MAIA guides you through it, not answers it like a Q&A.

**"Do I have to use prompts?"**
No. Prompts are training wheels and doorways, not a requirement.

**"I'm advanced—will this feel basic?"**
Not if you use the depth levels + synthesis/recap. The system is designed to scale: the *entry* is simple; the *work* can be profound.
